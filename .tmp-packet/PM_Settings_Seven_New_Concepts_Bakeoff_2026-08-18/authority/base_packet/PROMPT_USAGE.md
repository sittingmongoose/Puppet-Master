# Prompt Usage

Use `IMPLEMENTATION_PROMPT.md` once.

The receiving platform will generate its normal plan from that prompt. Approve or reject that plan in the platform. Do not send a second Build prompt; the same implementation prompt remains the authority after approval.

After the work is complete, use `AUDIT_PROMPT.md` in a separate high-quality audit thread.

No other prompt file in this packet is intended for direct use.
