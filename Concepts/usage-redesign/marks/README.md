# Usage provider marks

Jared, 2026-10-02: "yes use the real provider logos". Every provider row, legend, group header, chart series key and
account card on the Usage page shows the provider's official mark from this pack. Free Models and Local model server
show neutral UI icons, not marks.

- `src/js/06-marks.js` gives the page `window.PMU_MARKS`. Its header comment documents the API: `idFor`, `src`, `img`,
  `html` and `refresh`.
- `marks/sources.json` maps each PM provider id and legacy Usage name to a mark id. For every downloaded file it records
  the source URL, retrieval date, SHA-256, licence and trademark note, surface variants, crop and optical scale.
- `marks/out/` holds the artwork exactly as it is embedded.
- Generated by `~/PM-Experiments/usage-redesign-20261001/marks-work/tools/pm-emit.mjs`, which runs after `build.mjs`
  (the AI Account Center marks-v2 build with only the variant list and paths changed). Never hand-edit 06-marks.js;
  rebuild it.

## Rules

1. **Official artwork only.** Every mark comes from the provider's own brand kit, press kit, logo pack, product-logo CDN or
   product site. When a product has no mark of its own, its publisher's mark stands in for it, never a redrawn
   imitation:
   - Codex shows the OpenAI Blossom.
   - Muse Code and the Meta Model API show the Meta symbol.
   - The Qwen plans show the Qwen Cloud symbol.
2. **Never recolour, filter, tint, outline, shadow or redraw a mark.** That includes the NieR look and every theme
   transform: NieR's ink-only rule does not apply to marks. The only edits made to an SVG are dropping the XML prolog and
   comments, setting the root `viewBox`, `width` and `height` (the crop to the visible bounds plus a 0.75% hairline), and,
   for a lockup, dropping the wordmark elements that lie wholly outside that crop. Each lockup crop was verified
   pixel-identical.
3. **No discs, plates, tiles or badges behind a mark.** The only plates allowed are the ones a provider publishes as its
   app icon. Two marks use one:
   - Kimi Code: the docs app icon, which Jared chose in the AI Account Center on 2026-10-01.
   - xAI API: console.x.ai's own icon. The bare symbol is 2.56:1 and its strokes merge at 16 px.
4. **Light and dark variants.** `data[id]` is the artwork for dark surfaces, or the only artwork when one serves both.
   `data[id + '-light']` exists only where the provider publishes a light-surface version. In this pack those are
   OpenAI, Cursor, Qwen, Z.ai, OpenCode, Anthropic, Copilot, Grok and xAI. `surface: 'auto'` picks the light artwork when
   `html[data-theme$="-light"]` matches (NieR parchment is `basic-light`). Call `PMU_MARKS.refresh()` after a theme
   change.
5. **Optical scale.** Draw each mark contained (`object-fit: contain`) in a square box of side S at S x `meta.scale`,
   centred. `img()` and `html()` do this with padding. The method is AAC's, unchanged:
   `scale = (ref / inkBox) ^ 0.25`, where inkBox is the alpha-weighted share of the box the mark covers. The reference
   is AAC's (the Meta symbol), so copied AAC scales keep their values. Marks lighter than the reference clamp to 1, and
   app-icon plates use 0.9.
6. **Trademarks.** Every mark is a trademark of its owner. Each one is used only to identify that provider's service on
   an account and usage screen, unmodified, never as our own branding and never in a way that suggests endorsement. The
   SpaceXAI (xAI, Grok) guidelines require the logos "exactly as provided ... without any alteration or adjustment". The
   per-mark notes are in `sources.json`.
7. **Unknown providers.** `idFor()` returns null and `img()` returns null, so the caller falls back to its label. Never
   substitute another provider's mark.
