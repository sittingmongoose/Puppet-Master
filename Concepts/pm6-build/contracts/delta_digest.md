# Repo delta digest — what changed in Plans since PMConcept4 was authored (GUI-relevant)

All items below are contract/spec additions defining what the GUI must depict and wire to (not implemented behavior). Concept controls should carry the command ids in `data-command` attributes where natural.

## Canon adjudications (locked; concept must respect)
- Toolkit = Slint 1.17.1 native workbench (winit/Skia, Rust). No Tauri anywhere.
- Storage canon: event log = seglog, KV = redb, search index = tantivy; sqlite forbidden; `active-agents.json` = debug mirror only.
- platform_specs retired as capability SSOT → provider/model capability snapshot (Models_System SSOT).
- GitHub = API-only (api.github.com), gh CLI forbidden; auth = OAuth device-code flow, no client secret; scopes repo/read:user/user:email/read:org (+workflow/admin:repo_hook in matrix). Tokens in OS keyring; never display raw tokens.
- Settings = 19-tab canonical registry (18 visible + retired "Tiers" alias registry row — search/compat only, NOT a visible tab). Terminal IS a tab. Catalog/Sync/SSH/Debug = subsections under Settings > Advanced.
- Activity Bar = 5 enumerated groups: work (Orchestrator, Run Graph, Planning Wizard) / project (File Manager, Search, Source Control) / automation (GitHub Actions, Docker Manager, Testing) / communication (Chat, Agents, Notifications) / system (Settings, Usage, Runtime Artifacts). Ctrl+1..8 binds first 8 visible side-panel items.
- Dashboard default = exactly 4 widgets: widget-orchestrator-progress, widget-active-lanes, widget-recent-results, widget-custom-metrics. Reorder = full drag-to-reorder + edge resize + grid snapping (F3-275).
- Tier vocabulary retired everywhere (seam/package/lane/node).
- No fabricated `*.command_applied` events; every control maps to a real domain event or explicit route-open/no-persist dispatch.
- Universal UICommandResponse envelope; closed error codes (invalid_route, unknown_command, invalid_args, permission_denied, blocked_state_required, stale_projection, handler_unavailable, internal_error); closed disabled-reason codes (unsupported, not_configured, unauthorized, unreachable, degraded, partial_capability, blocked_state_required, stale_projection, permission_required).
