# Addendum (2026-07-09): PM173 web/browser/research changes + 158→159 Plans delta

Supplements delta_digest.md and spec_briefs.md. These landed AFTER Wave 1 started; all remaining builders must honor them. Full source reports: scratchpad handoff + `Downloads/PM173_GUI_Impact_Handoff_Report.md` (do not need to re-read; this addendum is the distilled contract).

## Global
- Web/browser/research abilities are GENERAL assistant abilities: reachable via slash commands, palette, natural language, autonomous agent judgment, subagents, Goal Runtime, PRD Builder, Planning Wizard, Orchestrator. Everything converges on one PM-owned **WebOperation / BrowserAction dispatcher**. Never imply "/web is the only way".
- Command namespace: **cmd.chat.web.*** (search/fetch/extract/research/crawl/map). `cmd.web.*` and `cmd.browser.run_code|evaluate` are retired compatibility/diagnostic lineage — never show as active.
- Canonical field is **operation_input** (never `web_input`); `operation_input_preview` is display-only.
- Six locked operation-card active labels: `Searching Web: <query>` · `Reading Site: <url>` · `Extracting Site: <url>` · `Researching Web: <task>` · `Crawling Site: <url>` · `Mapping Site: <root_url>`.
- Long-running web ops need visible states: queued/awaiting-approval → running w/ progress ("Crawling Site: 14/25 pages", "Researching Web: reading source 3/6") → provider fallback/degraded → partial result → canceled/failed(reason)/completed w/ evidence. Never look "done" while running.
- Operation cards show provenance: invocation_source + agent_reason plain-English line ("Agent searched web because freshness was required."), provider/effective adapter + fallback path, permission scope + approval result, cache state, cost/credit warnings, source count + `/sources` drawer, Runtime Artifact links. Large payloads lazy-load from refs — never dump extractions into the transcript.
- Approval scopes: websearch/webresearch may be `*`-scoped; webfetch/webextract host-scoped (`https://host/*`); webcrawl/webmap visible origin/root + caps. Denied cards use blocked_reason_code + allowed_action_ids vocabulary.
- Browser: PM native browser / **Site Reader is primary** (Playwright = fallback lineage only, never label as default). Browser evidence drawer w/ tabs Page / Actions / Console / Network / Screenshots / Sources; Open + Watch actions; session identity; browser commands map to real events (browser.session.created/state_changed/takeover_state_changed, browser.context_captured/shared, runtime_artifact.created).
- Research/deep-research = first-class visible runs: ResearchRun identity, source-selection receipts, read receipts, citations from actually-read sources (never bare snippets), synthesis steps, provider-native vs PM-composed path disclosure, partial evidence on cancel.
- source_confidence enum is only high|medium|low|unknown.
- Governance: `Concepts/pm6-build/**` is now git-tracked by other agents and referenced by Plans/usage-feature.md as source-lineage material — do NOT plan on deleting it; keep README.md in place; never commit from this build.
