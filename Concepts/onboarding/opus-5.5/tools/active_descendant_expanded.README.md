# Expanded descendant comparison

`rail_concept_descendants.test.mjs` executes the shipped FILES_DATA, SOURCE_DATA and DOCKER_DATA through open A rows, B drill-page bodies, C index/Lens builders, real shared menu builders and every PMR.button variant. It reads allowed descendant features from active_descendant_rules.json. Its branch counters must all be positive. `selector_builder_coverage.test.mjs` additionally executes the later continuous Settings index and resource-roster builders. `--sample=<builder name>` isolates a regression while the default retains every sample.

The browser companion `active_descendant_expanded.check.mjs` extends the original guard's state/force model using `rail_expanded_states.mjs`. It compares the original/replacement querySelectorAll sets for every rule and variant, before and after the guard's forced states, and adds explicit global PMR hover/current/selected states for rules13/14. It visits both source engines, every A view, the B descriptor graph (including siblings, per-area context and lazily built sections), every C view/index entry/Lens plus identity/footer Lens controls, and every original D panel/tab. Every disclosure is opened by its real handler. A mutation observer recognises handlers that replace the row rather than changing its old DOM node. Detail pages/portals keep their real ancestry.

The published page contains D, not A/B/C. Generate the authoritative review-only profile with:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 Concepts/onboarding/opus-5.5/tools/rail_expanded_prep.py --out <local-scratch>/review.json
browser-check run Concepts/onboarding/opus-5.5/tools/active_descendant_expanded.check.mjs --config Concepts/pm7-tools/browser-check/browser-check.config.mjs --host windows --set page=<build-URL> --set bundle=<local-scratch>/review.json --set out=<local-scratch>/comparison.json --out <local-scratch>/run
```

Follow the campaign's host gate and admission rules in the same command before this browser start. The prep file adds no fixture DOM and replaces no builder. Its two access hooks expose the existing A/C panel instances; B already exposes its Stack. Data, class writers, event handlers and nesting remain the real source's.

Output retains every visited state and its per-rule original/replacement counts, missing class features and element samples, raw SVG/BR gaps, extra matches, coverage and errors. A colour-only raw SVG/BR gap may use the lead's inherited-equivalence qualification: state and statically check both the inherited-property/source-of-value condition and the competing-declaration condition for each group. The companion independently reinstates the old declaration and compares every such element's computed colour/text-fill under the forced states. Those differences fail too. Non-inherited declarations always require a direct selector. The built declarations must be checked against the companion's declaration map; adding another property requires updating that map and the qualification.

All rewritten rules must match at least once. Omitted rules must match nothing. A missing class is not waived because its text happens to be legible. Raw inheritance qualifications and deliberate differences in the separate all-parts computed-style swap belong in the report, with their source evidence.
