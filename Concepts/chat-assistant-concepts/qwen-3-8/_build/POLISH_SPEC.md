## §A — `PMAnim` API (S-P0a implements EXACTLY these names; spine subagents code against them)
`window.PMAnim = {`
- `reduced()` → bool.
- `flip(els, mutate, opts={})` → measure `getBoundingClientRect` of all els (batch read), call `mutate()`, then for each el FLIP via `el.animate([{transform:translate(dx,dy)},{transform:'none'}], {duration:opts.duration||420, easing:opts.ease||'var(--ease-snap-spring)'})`. If `reduced()` just call `mutate()`.
- `staggerIn(els, opts={})` → for each child i, `el.animate([{opacity:0,transform:'translateY('+(opts.rise||12)+'px)'},{opacity:1,transform:'none'}], {duration:opts.duration||320, delay:Math.min(i*(opts.step||35), opts.cap||280), easing:'var(--ease-snap-spring)'})`. If reduced, set final style (opacity 1, transform none) immediately, no animate.
- `springTo(setter, from, to, opts={})` → rAF mass/stiffness/damping solver (stiffness 170, damping 18, mass 1; clamp dt to 1/30); `setter(value)` writes a transform/number; settle when |v|<.1 && |x-to|<.5. If reduced, `setter(to)`.
- `crossfadeNum(cellEl, newText, opts={})` → clone firstChild, append new, WAAPI old out (opacity1→0, translateY 0→-.6em, 180ms ease-in, remove on finished) + new in (opacity0→1, translateY .6em→0, 220ms var(--ease-snap-spring)); `cellEl` must use `font-variant-numeric:tabular-nums` + a fixed grid/min-width to avoid jitter. If reduced, `cellEl.textContent=newText`.
- `morphClip(el, fromInset, toInset, opts={})` → `el.animate([{clipPath:'inset('+fromInset+')'},{clipPath:'inset('+toInset+')'}], {duration:opts.duration||420, easing:opts.ease||'var(--ease-gentle-overshoot)'}); el.style.clipPath='inset('+toInset+')';` on finished call opts.onDone. If reduced, set clipPath toInset + onDone() after 0ms.
- `pop(el, opts={})` → add class `pmq-pop` once; remove on `animationend`. If reduced, no-op.
- `strike(el)` → add class `pmq-strike` once (the ::after sweep). Under reduced the universal zeroing makes the ::after jump to its `to` (full line) → instant strike, acceptable.
`}`
