## Resolved in this workspace (second pass)

These were prototype-fixable and are now fixed and, where automatable, asserted (matrix 2,616 → 2,620, all green):

- **T5 Condenser measure cap** (GAP-021): `max-width: 72ch` on T5 bodies; re-audit 73 ch at 1200 px (was 144 ch).
- **Popup bottom clamp** (`popups.js`): `place()` hard-clamps `top` so `top + height <= viewport - 8`; the search popup re-places after its results lay out. W4 search at 820 px: bottom 759 (was 825).
- **Hit-target sizes** (audit WARN): W8 strips and message hover actions now `min-height: 24px`; re-audit finds zero sub-22 px controls at 520 px.
- **Pop-out drag/resize** (known-limitation → implemented): drag grip + resize handle; horizontal resize clamps 520–1200 px and feeds the chat width; vertical free (360 px floor); resets on re-dock. Asserted in `functional`.
- **Markdown / diagram rendering** (GAP-012): safe renderer `_shared/markdown.js`; ```mermaid → sandboxed-bridge placeholder; additive thread-13 showcase; asserted in `functional`.
- **Typed command intents** (GAP-001/002/007/009, prototype side): `_shared/commands.js` emits `cataloged`/`uncataloged` intents for thread switch, goal actions, questionnaire, lens, draft restore, search, editor/browser open; exposed via `__pmChatState().recentCommands`; asserted in `functional`. The catalog itself is not re-owned.
- **Total-elapsed row** (GAP-019): two messages diversified; asserted.
- **Editor-tab handoff** (GAP-014): fake dashboard now shows a faithful panel (title/kind/path + "owned elsewhere" note).
- **Code quality**: removed a no-op line in `store.send`; `prevMsg` now advances through grouped runs.
