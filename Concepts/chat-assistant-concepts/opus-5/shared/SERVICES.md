# Shared service API — Opus 5 (frozen)

Every service is a global object registered on `window`, exposed to modules through `ctx.services`.
Implement the exact signatures. If you need a change, report it — do not edit this file.

Global name → `ctx.services` key:
`PMXPopup`→popup · `PMXScroll`→scroll · `PMXSearch`→search · `PMXLens`→lens ·
`PMXQuestionnaire`→questionnaire · `PMXDrafts`→drafts · `PMXRuntime`→runtime ·
`PMXActivity`→activity · `PMXGoals`→goals · `PMXSurfaces`→surfaces ·
`PMXEditorHost`→editorHost · `PMXMotion`→motion · `PMXIcons`→icons · `PMXToast`→toast

Non-service globals used by `compose.js`: `PMXShell`, `PMXComposer`, `PMXHeaderTools`,
`PMXThreadHistory`, `PMXHoverRow`, `PMXMoreInfo`, `PMXSelectors`, `PMXData`, `PMXListWindow`, `PMXUtil`.

---

## PMXMotion  (`shared/motion.js`)
```js
reduced()                      // true if stage data-motion=reduced OR prefers-reduced-motion
onChange(fn)                   // fires when the reduced flag flips; returns unsubscribe
snapToEnd(el)                  // cancel in-flight transitions/animations, force final computed state
collapseTo(el, open, opts)     // animate height to/from auto. opts:{collapsedHeight, duration, onDone}
                               // uses interpolate-size when supported, else measured scrollHeight
condense(el, buildSummary, opts)// height+content morph: old content out, summary in, height settles
swapText(el, text)             // in-place text replace with no container jump
enter(el)                      // play the standard enter for a newly inserted node
exit(el, onDone)               // play the standard exit, then call onDone
```
Every function must reach the identical final state when `reduced()` is true, with zero partial frames.

## PMXPopup  (`shared/popup.js`)
```js
attachRoot(overlayRootEl, ctx) -> { destroy() }   // called once per composition
open(spec) -> handle
  // spec: { anchorEl, build(host, api), width, kind:'menu'|'list'|'panel', submenuOf }
  // api:  { close(), resize(), setContent(html|node), host }
close(handle)
closeAll(exceptHandle)
isOpen(handle)
current()                                          // the single active overlay, or null
```
Behavior locked by canon: click activation only; corner-origin sprout from the anchor's nearest
corner; animated open and close; measured in-place height animation with spring overshoot when
content size changes; submenus; single-overlay mutual exclusion; viewport-aware placement;
reduced-motion final state. Escape and outside-click close.

## PMXScroll  (`shared/scroll.js`)
```js
attach(scrollEl, opts) -> ctl
ctl.captureAnchor()            // -> { msgId, offsetWithinMessage } | null
ctl.restoreAnchor(token)
ctl.isNearBottom()
ctl.stickIfAtBottom(mutateFn)  // decides BEFORE mutating, then re-pins if it was at bottom
ctl.preserveAcross(el, mutateFn) // corrects scrollTop by the height delta of el (above-viewport safe)
ctl.jumpTo(msgId, opts)        // opts:{highlight:true} — temporary highlight class pmx-jump-hit
ctl.onAwayChange(fn)           // for jump-to-latest affordance
ctl.destroy()
```
Transcript containers set `overflow-anchor: none`; corrections are explicit.

## PMXListWindow  (`shared/listwindow.js`)
```js
create(containerEl, opts) -> lw
  // opts: { getItems(), renderItem(item, i), estimateHeight, overscan:10, keyOf(item) }
lw.setItems(items) / lw.refresh() / lw.ensureVisible(key) / lw.measuredRange() / lw.destroy()
```
Renders viewport + 10 overscan with top/bottom spacers and a measured-height cache.

## PMXData  (`shared/data.js`)
```js
load() -> Promise<data>          // merges demoData.json + demoDataExtension.json
data.threads                     // normalized, recency derived from last message sentAt
data.threadById(id) / data.messagesFor(id) / data.storedCount(id)
data.scriptedReply(threadId, cursor)
data.visibleSlice(threadId, loadedFrom)  // honors initialVisibleMessageCount + loaded range
fmt.time(iso) / fmt.date(iso) / fmt.duration(seconds) / fmt.label(enumString)
```
`fmt.label` maps internal enums to prose: `waiting_for_parent` → `Waiting for parent`.
All timestamps stored UTC, rendered in viewer locale.

## PMXSearch  (`shared/search.js`)
```js
index(data)                                  // over CANONICAL full text, incl. collapsed + unloaded
query(text, {scope:'current'|'all', threadId}) -> results[]
  // result: { threadId, messageId, snippet, matchStart, matchEnd, insideCollapsed, lensState }
openPopup(anchorEl, ctx)                     // uses PMXPopup, two scope controls at top
```
Human search always reads canonical history. Selecting a result never changes Lens state.

## PMXLens  (`shared/lens.js`)
```js
mode(threadId) / setMode(threadId, 'mute'|'focus'|'subcompact'|'off')
toggleSelect(threadId, msgId) / selection(threadId) / clear(threadId)
apply(threadId)                              // Subcompact only; enforces 25 per operation
stateOf(threadId, msgId) -> 'muted'|'focused'|'subcompacted'|'source'|null
effectiveHistory(threadId)                   // agent-side view: muted out, focused first, subcompact summarized
MAX_PER_APPLY = 25
```

## PMXQuestionnaire  (`shared/questionnaire.js`)
```js
activeFor(threadId)            // oldest unresolved, or null
queueFor(threadId)
answer(qid, questionId, value) / skip(qid, questionId) / unskip(...)
goTo(qid, index) / next(qid) / prev(qid)
canSubmit(qid) -> {ok, missingRequired[]}
submit(qid) / cancel(qid)
isComposerLocked(threadId)     // true while a questionnaire is active
```

## PMXDrafts  (`shared/drafts.js`)
```js
get(threadId) / setText(threadId, text) / addAttachment / removeAttachment
commitRevision(threadId)       // bounded + deduplicated; not every keystroke
revisions(threadId) / restoreRevision(threadId, index)
clear(threadId)                // explicitly distinct from send
archiveOnSend(threadId)
```
Questionnaire freeform drafts live in the questionnaire slice, never here.

## PMXRuntime  (`shared/runtime.js`)
```js
send(threadId, text)           // appends exactly as entered, then plays the scripted sequence
stop(threadId)                 // ends working sequence, records stopped result, keeps Worked for
isActive(threadId)
composerButtonState(threadId, draftText) -> 'send'|'stop'
onTick(fn)                     // worked timer
liveStatus(threadId)           // current one-line action text, or null
```
Never interprets user text. Cursor advances through `scriptedReplyIds`, cycling.

## PMXActivity / PMXGoals / PMXSurfaces
```js
PMXActivity.groupFor(msg) / PMXActivity.stages(group) / PMXActivity.condenseLabel(group)
PMXGoals.forThread(threadId) / PMXGoals.can(goal, action) / PMXGoals.act(threadId, action)
  // actions: view, expand, collapse, edit, pause, resume, stop, clear, tasks, subgoals, evidence
PMXSurfaces.activeFor(threadId) -> { goal, todo, subagents, diffs, activity }  // any subset, may be empty
PMXSurfaces.yieldForQuestion(threadId, on)   // temporary yield; underlying state continues
```

## PMXEditorHost
```js
openArtifact(artifact, ctx) / openBrowser(session, ctx) / tabs() / focus(tabId) / close(tabId)
```
Routing only. Never redesigns editor, browser, or file-explorer internals. The inline shortcut
stays in the thread and needs no open/active state on the message.

## PMXIcons
```js
get(name, size) -> SVGElement    // inline SVG only, currentColor, no emoji, no icon fonts
```
Names: copy, edit, info, send, stop, search, lens, ring, more, chevron-down, chevron-right,
chevron-up, pin, archive, trash, export, branch, plus, close, check, dot, play, pause, square,
alert, file, folder, globe, terminal, sparkle, layers, clock, user, robot, thread, attach, mic.

## PMXUtil
```js
el(tag, attrs, children) / frag() / on(el, ev, fn) -> off / debounce / throttle / rafBatch
esc(text) / uid(prefix) / clamp(n, lo, hi) / fmtBytes
```
`el()` sets textContent for strings — never innerHTML with data. This is how the no-emoji and
no-underscore policies stay enforceable.
