## Reproduce

From this concept directory, with Python Playwright, `/usr/bin/chromium`, Node,
and (for record) Xvfb/ffmpeg already available:

```sh
python3 build.py
python3 tests/b18-completion/run.py handlers --outdir /external/fresh-handlers
python3 tests/b18-completion/run.py surfaces --outdir /external/fresh-surfaces
python3 tests/b18-completion/run.py record --outdir /external/fresh-recordings
python3 tests/b18-completion/run.py regressions --outdir /external/fresh-regressions
```

Use fresh external output directories. `handlers.py --case NAME` can reproduce one
named case without rewriting prior results. Tests execute complete generated HTML,
not a test-only application. Each receipt binds actual HTML and driver hashes.
The independent `bytes.cjs` tests the shipped decoder and SHA-256 against Node crypto,
including the full 16 MiB file limit; it does not mirror the implementation.

`tests/b18/freeze.py` records ordinary source files and link metadata without following
symlinks. It does not authorize deletion of tracked dependency links. The guarded
installer leaves unlisted links untouched and refuses a linked target or target ancestor.

Build the actual deliverables with `tests/b18-completion/package/build_packages.py`
using the APPLIED B18 baseline directory. Independently test the resulting guarded ZIP
with `tests/b17/installer.py` and `tests/b18/package/check_unrelated_link.py`; test the
actual cumulative ZIP with `tests/b18-completion/package/check_cumulative.py`.
Read the separate final verification report for executed results, rather than inferring
a pass from the presence of source, a README, or a checkpoint.

## Scope and limitations

- Session-local execution/data and explicit demonstration clock, not background timers
  after closing the page, durable server storage, real-origin recovery or multi-host work.
- A folder means all files the browser actually selected. No OS symlink traversal,
  empty-directory topology, filesystem watching, inaccessible-file enumeration, or
  automatic native path resolution is claimed. An unretained live path refuses.
- Bounds: 16 MiB per file, 32 MiB per selection, 256 members. A selection exceeding a
  bound refuses wholly. No malware/secret scan is fabricated. Previews are bounded at
  64 KiB; downloads preserve all retained bytes.
- Scheduling new file inputs uses the ordinary composer. Editing a pending schedule
  retains its existing snapshot; selecting replacement files requires a new schedule.
- The Crew uses the existing local calculation adapter and required Plan leaves. It
  is not a general provider-backed concurrent Crew executor or arbitrary side-effect
  recovery proof. Options without a real local adapter remain explicitly unavailable.
- No new production command, EventRecord, native handler, WorkNode or governance write.
- Full original historical requirement wording and full FinalGUISpec body were not
  recovered in this continuation. Coverage is grouped current-owner and bounded
  runtime evidence, not a formal 47/47 original-clause closure claim.
- The B17 native print-dialog check remains human/uninstrumented-browser work.
- Native Windows/macOS installer behavior, hostile concurrent filesystem races and
  crash-atomic multi-file installation are not established by Linux installer tests.
- All ten protected animation source files are preserved. Recordings and selected frame
  reviews do not establish universally smooth 60 fps or native device performance.
