# Demo trigger catalog

Open **Demo Studio** in the upper-right of the concept. It is the control surface for
reproducing the important assistant situations without waiting for a live model.
**Reset** restores the entire lab to its stock state.

## Component exploration

- Select any of the eight curated recipes.
- Change any of the seven component-family selectors independently.
- Switch among all eight PMConcept7 themes.
- Component changes preserve the active thread and current demonstration state so
  variants can be compared directly.

## Working Animation

Choose one of the eight takes, then use **Start**, **Pause**, **Step**, **Complete**,
and **Reset work**. After completion, open **History** or **Evidence**.

The sequence demonstrates preparing, thinking, permitted thought stream, file
exploration, web search, web fetch, browser control, Bash, live subagents, editing,
application control, browser testing, validation, artifact rendering, and completion.

The eight takes are: Reference Morph, Orbit, Step Stack, Tool Ribbon, Progressive
Receipt, Workbench, Agent Stage, and Calm Stage.

## Questions and decisions

Triggers are provided for:

- preparing and opening a paged questionnaire
- required-answer validation
- skipped and queued questions
- durable close and later return
- explicit cancellation and submission
- Plan and Deep Plan review
- plan revision feedback
- permission approval or denial
- conflict resolution

These surfaces appear in flow above the Chat Activity Bar and push the transcript
upward rather than covering it.

## Artifacts

The artifact gallery and deterministic triggers cover:

- Mermaid source and render
- interactive dashboard
- interactive chart
- data explorer with filtering
- architecture map
- interactive quiz
- periodic-table capability explorer
- flowchart
- generated image
- browser/test evidence
- document/report
- Plan and Deep Plan
- stale artifact version
- renderer error, source fallback, and retry

Every artifact can open in the file editor workspace. Generated images expand there;
file changes open their exact fixture path and modified range.

## Assistant systems

Dedicated threads and triggers cover:

- ordinary text-only conversation
- BSD evaluation, intervention, silence, suppression, timeout, unavailable, and quota states
- Context Lens Focus, Mute, Subcompact preview/apply/cancel, and provenance receipts
- Crew and child-agent lifecycle
- live read-only child-agent threads
- Goal replanning, pause, block, stop, and clear
- offline outbox and reconnect replay
- attachment progress and unsupported routing
- tool failure and checkpoint recovery
- provider route/auth/quota/no-model situations
- message arrival away from the bottom of the transcript
- archived-thread search and restore
