Puppet Master · Settings redesign bakeoff · Qwen 5.8

Four concepts, one contract

Final-packet build (2026-08-08). Each concept answers the same packet with a different information architecture: how the search-centric home establishes hierarchy, how destinations read as places rather than filters, how the workspace navigates, and how managers relate to ordinary settings. Every concept ships the full product contract: hash deep links with back/forward, persistent demo state, lazy manager hydration, differentiated search result types, the complete Provider/Account/Model/Installation manager with 17 fixtures, eight themes, reduced motion, and squeezed layouts. No ranking is implied.

Shared under all four

  • One demo dataset: 10 canonical destinations (general, notifications, appearance, models, context, behavior, permissions, code, extensions, system), every setting row covering default / recommended / inherited / auto / not-configured / managed / custom / unavailable / effective-differs / restart-required / changed-elsewhere states.
  • Provider register with all 17 packet fixtures: Anthropic CLI (OAuth, exhausted usage), Anthropic API key, OpenAI (PM-direct OAuth, update available), Gemini CLI (two installations, selected + shadowed), Codex CLI (signed out, rolled-back update), Antigravity (explicit Install card), OpenCode external server (managed externally + unknown-owner installation), local server (scheduled-idle update), Mistral free tier (full six-state vocabulary).
  • Search returns seven visibly distinct result types (setting / manager / action / status / diagnostic / setup / unavailable) and tolerates typos; Enter deep-links with a focus wash.
  • Persistent demo state per concept (localStorage), hash routing with working back/forward, lazy manager hydration, receipts for every simulated action, a demo tray with 10 scenarios, and Reset demo data.
  • All eight themes, reduced motion, quiet surrounding shell with rail and assistant panel toggles. The Media destination is retired; continuation settings moved into the Provider manager.

How to test

  • Use the Hub width slider (role: page) — recommended widths 760, 900, 1280, 1700, 2200, 2500.
  • Open the Demo tray (bottom right) inside a concept to toggle theme, reduced motion, scenarios, left rail, and assistant panel.
  • Squeezed widths collapse workspace navigation into drawers; no label clips.
Concept pages are standalone; the shared scripts live in _shared/. Findings, impact register, and test report sit beside this index. This set deliberately preserves divergence — do not average the four into one design.
