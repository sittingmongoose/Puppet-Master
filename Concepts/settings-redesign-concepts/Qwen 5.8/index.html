Puppet Master · Settings redesign bakeoff · Qwen 5.8

Four concepts, one contract

Each concept answers the same packet with a different information architecture: how the search-centric home establishes hierarchy, how destinations read as places rather than filters, how the workspace navigates, and how managers relate to ordinary settings. No ranking is implied.

Atlas — Directory 01

Settings as a map of places. A full-width directory of destinations, a document workspace with a persistent table of contents, and managers as separate rooms.

Search
Crowning field that morphs the directory into grouped results
Navigation
Left TOC, sliding active marker, controlled jump + scrollspy
Managers
Providers, Assistant Memory, MCP
Motion
Cartographic continuity — origin-aware travel
Open Atlas

Deck — Command center 02

Settings as operations. A command field first, status modules with live readouts, a status board, and console-style managers with a sticky subcategory strip.

Search
Command palette with grouped dropdown results
Navigation
Horizontal tab strip synced to scroll, auto-centering
Managers
Providers, Crew, Terminal
Motion
Staged console — layout settles before text reveals
Open Deck

Ledger — One document 03

Settings as one continuous readable document. Numbered chapters, hairline entries, managers embedded as appendices, and a margin outline with a sliding ink marker.

Search
Underlined ledger search rendering an annotated contents list
Navigation
Margin outline with ink marker; section numbers throughout
Managers
Providers, Context & Instructions, Skills/Plugins/Tools
Motion
Ink & paper — near-still, fastest timings
Open Ledger

Spoke — By intent 04

Settings organized by user intent into wings, with a floating launcher for search and master-detail split views for managers: inventory left, inspector right.

Search
Persistent rounded launcher over home and workspace
Navigation
Right-edge progress ticks with scrollspy; drawer when squeezed
Managers
Providers, Personas, Media
Motion
Orbital — depth via scale, inspector slides from its edge
Open Spoke

Shared under all four

  • One demo dataset: 10 destinations, ~100 settings covering default / recommended / inherited / auto / not-configured / managed / custom / unavailable / effective-differs states.
  • Provider register: Anthropic (two accounts incl. CLI-owned OAuth profile and exhausted usage), OpenAI (PM-direct OAuth), Gemini CLI (authenticated but invocation failed), Antigravity CLI (not installed), local keyless server, Mistral free tier (needs setup), plus models.dev and Free Coding Models continuous catalogs.
  • Search, deep-link focus, scrollspy with jump lock, exposure levels, spellcheck suggestions (never autocorrect), simulated receipts for actions that cannot truly operate.
  • All eight themes, reduced motion, quiet surrounding shell with rail and assistant panel toggles, and a demo tray for scenarios (attention / calm / refreshing / exhausted).

How to test

  • Use the Hub width slider (role: page) — recommended widths 760, 900, 1280, 1700, 2200, 2500.
  • Open the Demo tray (bottom right) inside a concept to toggle theme, reduced motion, scenarios, left rail, and assistant panel.
  • Squeezed widths collapse workspace navigation into drawers; no label clips.
Concept pages are standalone; the shared scripts live in _shared/. Findings, impact register, and test report sit beside this index. This set deliberately preserves divergence — do not average the four into one design.
