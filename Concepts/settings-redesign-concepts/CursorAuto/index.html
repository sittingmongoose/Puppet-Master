Four ways to rebuild Settings

Four genuinely different information architectures over one shared settings system: the same demo data, the same eight themes, the same state rules — four different answers to search, navigation, managers, and motion.

This gallery is a comparison surface, not a ranking. Open each concept in the ConceptHub to exercise width, theme, and reduced-motion controls.

Concept 01

Harbor

Pier-desk IA. Harbor search first, at most a few tide notices, then berth cards. Workspace is pier slips beside a cargo document. Managers are drydocks and lockers.

  • Pier-desk search reshapes the berth directory
  • Slip scrollspy with docking transitions
  • Providers + Memory + Terminal (LSP opens with full checklist)
Motion: docking — berth origin to workspace, settle before text.
Open Harbor
Concept 02

Score

Cue-sheet IA. Hero cue search, cue notices, then movement plates. Workspace is a single-column score with a top rehearsal-mark rail and a light side index. Managers are ensemble cast and instruments.

  • Hero cue search morphs into ranked cue sheets
  • Rehearsal-mark rail tracks scroll position
  • Providers + Personas + MCP
Motion: cueing — marks ink in; page-turn between movements.
Open Score
Concept 03

Switchboard

Operator patch-bay IA. Destinations are labeled jacks with readiness text+icon. Workspace is a patch sheet beside the jack strip. Managers are patch bays; ordinary settings hang as policies.

  • Docked operator search (/) with jack tickets
  • Lit jacks track the viewport (no color-only meaning)
  • Providers + Context & Instructions + Skills/Plugins/Tools
Motion: patching — jack acknowledge, brief route line, no endless pulse.
Open Switchboard
Concept 04

Archive

Archival retrieval IA. Home is a finding-aid desk. Destinations are collection guides. Workspace is one box’s folders with a running header. Managers are special collections with the same retrieval grammar.

  • Finding-aid search with call-number hits
  • Folder outline + document; sticky running header
  • Providers + Crew + Media
Motion: retrieval — one folder open, then stillness.
Open Archive

One shared system underneath

  • Shared demo dataset (shared/data/pm-settings-demo.js): 11 humanized categories, 129+ settings, providers covering required connection states, managers, spellcheck, notices, recents.
  • Shared engine (shared/lib): fuzzy search + deep links, scrollspy/jump, pub/sub store with honest simulated receipts, ConceptHub bridge.
  • All eight themes and reduced motion. No emoji, no category pills, no colored left-accent status borders.
