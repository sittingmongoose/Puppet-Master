# Concept Coverage and Fixtures

## Four-concept collective coverage

Every concept must include:

```text
Full surrounding shell
Settings Home
Search and result navigation
Full Settings Workspace
Left category/subcategory navigation
Scrollspy and deep link
Provider/Account/Model/Installation manager
Representative ordinary setting rows
Loading/empty/error/unavailable/managed states
All-theme support
Reduced motion
Impact register
```

The four concepts collectively prove the complete manager grammar.

## Provider fixtures

Include:

1. CLI found, authenticated, ready.
2. CLI found, not signed in.
3. Multiple installations; one selected, one shadowed.
4. Unknown installation owner, manual-only.
5. Explicit Install from official source.
6. Update available; Ask first.
7. Update scheduled when idle.
8. Verification failed and rollback succeeded.
9. Claude CLI OAuth profile.
10. OpenAI PM-direct OAuth.
11. API key connection.
12. OpenCode external server.
13. Free Models row requiring underlying setup.
14. Usage details unavailable but provider ready.
15. Catalog refresh with last-known-good state.
16. Account priority/fallback and requested/effective difference.
17. Fast/Normal and effort capability variation.

## Functional expectations

At minimum:

- Search, navigation, jumps, scrollspy, disclosures, add/edit/remove flows, provider refresh, installation selection, notices, previews, test-send fixtures, import preview, and rollback fixtures work.
- Values persist within the concept demo.
- No control is decorative.
- Focus, keyboard, and pointer interactions are coherent.
- Manager loading does not block the entire Settings workspace.
