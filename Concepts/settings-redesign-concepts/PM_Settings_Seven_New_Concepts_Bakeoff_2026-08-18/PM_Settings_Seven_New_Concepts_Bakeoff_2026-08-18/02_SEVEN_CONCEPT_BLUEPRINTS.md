# Seven Concept Blueprints

Each reference board shows six anchor screens. The implementation must extend beyond those screenshots into a complete Settings system.

## Concept 05 — A1 Directory / Take 1

Reference: `01_A1_Directory_Take_1_LAYOUT_RECONSTRUCTION.png`

Core qualities:

- crisp, quiet directory-first Home;
- large universal search above content;
- one compact attention block;
- two-column major destination cards at wide widths;
- domain page composed from clear destination rows;
- integrated provider list/detail workspace;
- exact search landing highlighted within a form;
- copy transaction shown as a focused review flow.

Differentiate it through a confident spatial directory and simple card-to-workspace expansion. Do not let it collapse into Take 3's broader dashboard/card treatment.

## Concept 06 — A1 Directory / Take 2

Reference: `02_A1_Directory_Take_2.png`

Core qualities:

- editorial, list-led Home rather than a card dashboard;
- a narrow, stable major-domain rail;
- large single-column destination rows with concise descriptions;
- compact anchored search dropdown;
- provider roster and restrained detail sheet;
- nested subnavigation that remains visibly inside Settings;
- quiet, focused copy dialog.

Preserve its ease of reading and deliberate vertical rhythm. Avoid decorative status blocks and excessive empty space.

## Concept 07 — A2 Compendium Workspace / Take 1

Reference: `03_A2_Compendium_Workspace_Take_1.png`

Core qualities:

- Settings Home plus a first-class `All Settings` compendium;
- faceted, searchable, readable long-tail index;
- domain pages that combine overview, key settings, and related managers;
- manager as an integrated list/detail workspace;
- exact search result landing with contextual explanation;
- copy preview with counts, additions, replacements, unchanged rows, and detailed diff.

This concept should be the strongest answer to thousands of settings without turning ordinary browsing into a table wall.

## Concept 08 — A1 Directory / Take 3

Reference: `04_A1_Directory_Take_3.png`

Core qualities:

- bright, spacious Puppet Master directory;
- search and attention at the top;
- fewer, larger domain cards with strong icon/title/purpose hierarchy;
- domain overview made from unmistakable manager destinations;
- provider summary with high-value status cards and explicit quick actions;
- exact credential result highlighted in place;
- full-width copy flow with selectable categories.

Keep its broad, approachable composition distinct from Take 1's denser directory and Take 2's editorial list.

## Concept 09 — Rethemed Tome Tabs

Reference: `05_Tome_Tabs_LAYOUT_ONLY_RETHEME_REQUIRED.png`

Borrow only:

- persistent edge tabs or chapter tabs for major domains;
- layered page depth and stable page location;
- broad central reading canvas;
- clear domain tabs plus manager-local tabs;
- list/detail manager composition;
- stepwise copy flow.

Do not use parchment, brass, gears, medieval/fantasy copy, book ornament, skeuomorphic paper, or sepia. Re-express the layout using Puppet Master's current theme materials, typography, spacing, icons, menus, and motion.

## Concept 10 — Rethemed Command Suite

Reference: `06_Command_Suite_LAYOUT_ONLY_RETHEME_REQUIRED.png`

Borrow only:

- command-index navigation;
- strong keyboard-first movement;
- multi-pane left-to-right drill-down;
- compact but legible data tables;
- direct path/status visibility;
- exact setting editor beneath or beside context;
- transactional copy panels.

Do not make a fake terminal. Do not default to green monochrome, CRT effects, code-only labels, or monospace body text. Render it as a polished Puppet Master command workspace with normal human language and theme tokens.

## Concept 11 — Rethemed Tabbed Organizer

Reference: `07_Tabbed_Organizer_LAYOUT_ONLY_RETHEME_REQUIRED.png`

Borrow only:

- category tabs resembling a well-organized file system;
- layered sheets/pages that preserve location;
- compact Home categories and recent changes;
- domain-level tabs and related-manager strip;
- provider roster with detail tabs;
- exact deep-link result nested in the same page stack;
- copy categories and source project in adjacent panes.

Do not use literal paper, folders, binder rings, staples, parchment, or office-supply decoration. Translate the organization model into Puppet Master tabs, panels, glass/friendly/retro/basic surfaces, and modern motion.

## Differentiation gate

The seven concepts must differ in at least:

- Home composition;
- primary navigation geometry;
- deep-navigation model;
- manager list/detail composition;
- exact-result reveal behavior;
- narrow-width transformation;
- motion metaphor;
- density and typography rhythm.

A color or material swap is not a distinct concept.
