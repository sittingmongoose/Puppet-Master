# Foundry — plan-owner delta (kimi-k3)

## Owners with direct impact

- **FinalGUISpec** — the engineering bench is a third verified composition:
  resource tables + detail drawer + toolbar/health-strip manager grammar.
- **LSP** — registry requires catalog/provenance, requested/effective
  attachment, host/environment, limits, logs, and verification; remote
  degradation is surfaced, never hidden.
- **Formatters** — detected / not found / disabled are typed states with
  install guidance; test action receipts with timing.
- **Commands** — custom commands carry shell-safety validation; dry run
  provably never sends work to an agent.
- **UI Command Catalog** — commands/shortcuts/resources candidates are new
  (canon has no `cmd.commands.*`, `cmd.shortcuts.*`, `cmd.mcp.server.*`,
  `cmd.lsp.server.*`, `cmd.formatter.*`); see the delta register.
- **MCP / Skills / Plugins / Tools** — one catalog with domain headers;
  five-state inventory (installed/enabled/available/selected/invoked);
  trust drives update policy.
- **File Manager** — transient/unavailable reasons are required content,
  never an empty tree.
- **Testing** — capability matrix per scope; managed cells name the policy.
- **Release/updates + Binary Locator** — shared installation grammar
  applies to developer tools exactly as to provider CLIs.
