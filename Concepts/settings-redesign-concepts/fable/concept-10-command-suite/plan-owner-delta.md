## 2. Supersessions demanded

1. **Managers are not slides.** Conductor exposes no previous/next-manager navigation; managers are reached through their owning domain pane and search only. Any plan text describing manager carousels is superseded.
2. **Modal editors.** The exact-editor-in-context pattern (editor beneath the row, Back closes it, deep link `#/setting/<id>` reproduces it) supersedes any surviving modal-dialog editing language for ordinary settings.
3. **Index-position search routing.** Selection routes by immutable rid/dest only; the legacy index-position bug class cannot recur in this composition and must not survive in plans.

## 3. Boundary confirmations

- **Project-only.** The path bar carries Project identity as context; no scope selectors exist anywhere; legacy scope metadata appears only as impact-analysis prose in the Details drawer.
- **Copy is a transaction, not a link.** Both projects stay independent after apply; the receipt records both directions; no sync affordance exists.
- **Provider CLIs are acquired explicitly.** Setup lives behind a user click on the official source for the exact selected host/environment; sign-in is a separate step; unknown ownership stays manual-only and refuses with its reason.
- **Truthful ops.** Determinate progress renders only when the op supplies a real denominator; everything else is an indeterminate phase sentence.

## 4. Known limits (honest)

- Roster item actions map to the shared trigger registry where a trigger exists (install-select/update/repair); verify/rollback per-item render honest simulated receipts.
- The nine deferred shells expose no actions by contract; their objects (hosts, clients) land by data-object-id for search.
