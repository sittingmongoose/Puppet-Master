Static · real app

Inside PMConcept7 itself

Loads the real PMConcept7.html and swaps its text wordmark for this logo at runtime. PMConcept7 is not edited. Change themes with its own theme menu and the logo follows. Needs the page served over http (the Concept Hub does this).

Static · app icon

Dock, taskbar and launcher

The tile follows the theme, and every theme's tile can ship as an alternate app icon. At 24 px and below the tile is dropped and the mark stands on its own, because a tile at that size shrinks Pip to a smudge.

Static · states

Pip reports status with its face

Six expressions, each drawn three times: vector for large sizes and pixel sprites at 16 and 24 px. They replace colored badges in the tray, notifications and the chat avatar. Everything except Working is static.

Every theme

Ten themes, one character

Each theme family changes material, not identity. Friendly gets pastel cheeks and a soft tile. Glass gets a glossy head and a rimmed glass tile. Basic stays flat with one accent. Retro becomes a pixel sprite with stepped motion. NieR turns machined and ink-only, with square eyes, angled brace points and a corner-bracket frame. Click a row to switch the page to that theme.

Small sizes

Real pixels, magnified

Each size rendered at its true pixel count, then enlarged without smoothing. 16 and 18 px use hand-placed sprites; 20 to 40 px use a heavier vector cut; above that, full detail. Retro uses sprites at every size.

Construction

How it is built

One generator, pm-logo.js, draws every asset on this page and every download, so the preview and the files cannot drift apart. It returns plain SVG strings and needs no browser, so a build script or the Slint app can call the same code.
