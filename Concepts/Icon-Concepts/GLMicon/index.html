Puppet Master — Icon Lab

The full icon system for Puppet Master, portability-tested for Rust + Slint 1.17.1 across macOS, Windows, Linux, and web. Theme-matched static marks, browser-animated loaders, three tray glyph variants, and ready-to-ship app-icon bundles (.icns / .ico / hicolor / web).

PORTABILITY Slint can't play SVG-internal animation — it rasterizes SVGs via resvg as a single static frame (true on desktop AND the wasm/web target). So: the 8 static SVGs are the portable truth (drop into @image-url(...) as-is). The 8 animated SVGs animate in browsers and are authored so their frozen t=0 frame is still a complete logo — meaning they degrade gracefully to a static mark in Slint. For real Slint loading motion, animate the Image element (animate transform-rotation) rather than the SVG.

Tray glyph variants — pick one

The full PM+puppet-strings mark is illegible at 16px, and macOS needs a monochrome template image (OS reads the alpha channel only). Three simplified glyphs are shown below at real tray sizes, rendered on both light and dark menubar backgrounds. The mac template row shows the auto-tinting silhouette; color is for Windows/Linux. Shown in the friendly-dark accent; every theme has its own accent-colored color set under build/<theme>/tray/.

Recommendation: the PM Monogram reads most reliably at 16×16. Simplified Mark is the best compromise if you want to keep the puppet motif in the tray. Puppet + String is expressive but its thin string and small eyes lose detail at 16px — better at 22px+ (Linux).
