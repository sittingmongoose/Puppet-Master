Platform exports — Slint 1.17 app (macOS / Linux / Windows)

Everything below is produced client-side from the theme selected here. Slint renders SVG statically (resvg — CSS-in-SVG animation is ignored), so in-app loading uses the native .slint components.

App icon

Multi-size single files: .ico (16–256, PNG-in-ICO) for Windows, .icns (16–1024 incl. @2x) for the macOS bundle, plus the scalable SVG for Linux hicolor/scalable.

Linux hicolor PNG set

Eight PNGs (16, 24, 32, 48, 64, 128, 256, 512) delivered as sequential downloads — your browser may ask once to allow multiple files. They install under hicolor/<size>/apps/.

Tray icons

macOS menu bar wants a monochrome template (black + alpha, capital-T Template filename → AppKit auto-adapts to light/dark). Windows/Linux dark taskbars use the white twin, Windows tray also accepts the theme .ico.

Slint loading components

Native re-creations of the motions for in-app use (animation-tick() + layered images tinted via colorize). Copy the .slint file plus the layers/ SVGs into your project. Bar Draw is web-only — its dash-draw effect has no honest Slint equivalent. Shimmer Sweep and String Pulse are native redesigns, noted in their file headers.

Regenerate everything with python3 generate.py (drift check: --check). All 18 SVGs also live on disk under icons/; Slint components under slint/. No emoji anywhere per project rule F3-417 — every glyph on this page is an inline SVG.
