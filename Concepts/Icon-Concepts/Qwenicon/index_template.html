Puppet Master logo kit — 8 themes × 8 animations, Slint-ready statics, tray & app icon exports.

Static icons are pure presentation-attribute SVG (no CSS), so they render identically in browsers and in Slint 1.17's resvg backend on macOS, Windows and Linux. The loaders below are CSS-animated for web surfaces; every one of the 8 animations can be paired with every one of the 8 themes — 64 downloadable combinations. In Slint, motion is driven natively (see slint/pm-loading-icon.slint). Re-generate with python3 build.py.

Platform & Slint notes

  • Slint 1.17.1: static icons use fill attributes only — resvg (Slint's SVG renderer) ignores <style>/CSS, so round-1 class-based icons would have rendered black. Fixed.
  • Loading in Slint: resvg is a static renderer; CSS animation never runs there. slint/pm-loading-icon.slint ships a pulsing PmLoadingIcon and a spinning PmLoadingSpinner built from the static SVGs with Timer + animate (syntax verified against the 1.17 language reference).
  • Cross-platform: everything is plain SVG text; PNG exports render client-side via canvas in any modern browser on macOS/Windows/Linux. No fonts, no external assets, works from file://.
  • App icon: the 512 px tile PNG is your app-icon source for icns/ico/png pipelines.
  • Tray: glyph-only transparent PNG for Windows/Linux notification areas; black template PNG for the macOS menu bar (template image). Tray icons are static by design — no animation.

Image {
    source: @image-url("../static/pm-icon-friendly-dark.svg");
    opacity: bright ? 1 : dim;
    animate opacity { duration: period; easing: ease-in-out; }
}
Timer {
    interval: period;
    running: true;
    triggered() => { bright = !bright; }
}
