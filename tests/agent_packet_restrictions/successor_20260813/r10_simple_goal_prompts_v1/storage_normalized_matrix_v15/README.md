# Storage normalized matrix V15

Fresh 24-row, two-pass native Goal matrix. This package is mutable prelaunch source and carries zero qualification credit until every frozen row has independently passed and the complete prefix has replayed.

The route order is GLM fallback max, Cursor auto, Muse xhigh, DeepSeek max, Gemini high, six Codex App routes, and Qwen xhigh; pass 2 repeats the same order. Row 1 is the spend/harness gate. Once it passes, an individual provider/model failure is permanently consumed at zero credit and does not suppress later rows. Source, authority, dependency, snapshot, evidence-tree, or post-PASS custody failures create a matrix HOLD and stop the suffix.

OMP rows use one `/goal` prompt, one Ctrl-D, a normal process exit, fresh isolated runtime paths, advisors off, `goal.continuationModes=[]`, and `recap=false`. Only GLM receives the pinned four-file profile and private request/response capture. Other OMP rows receive the exact three-file profile and no private HTTP configuration. Cursor's two aggregate-result location checks are the only route-scoped location exception; all lifecycle checks remain.

Codex rows use a fresh native App Goal and one ordinary prompt beginning `Create a goal that`. The raw task must contain exactly one `create_goal`, exactly one successful `update_goal` complete, no ordinary tools or retries, and a final assistant response joined to the task-complete event. PM_RESULT candidates are extracted only from authoritative assistant text. Their location relative to the Goal call is surface-dependent and does not affect semantic scoring.

Both the 28-file runtime dependency tree and the 6,097-entry Plans/scripts input snapshot are materialized read-only from pinned Git objects under fresh `/tmp` roots. Runtime code has no working-tree or live-Plan fallback. The dependency root is reverified before preflight, subject dispatch, replay, and final output, then removed on exit.

Commands:

- `python3 controller.py lint`
- `python3 controller.py verify-prefix`
- `python3 controller.py run <ordinal> --max-seconds 3600`
- package-local Codex request/ingest commands declared by `controller.py`
- `PYTHONDONTWRITEBYTECODE=1 python3 selftest.py`
- `PYTHONDONTWRITEBYTECODE=1 python3 -O selftest.py`

No provider/model call is performed by the selftests. V14 PASS evidence is retained only as canary lineage; MiMo dev11 remains a consumed 429 failure and is only the reason for the row-1 GLM fallback.
