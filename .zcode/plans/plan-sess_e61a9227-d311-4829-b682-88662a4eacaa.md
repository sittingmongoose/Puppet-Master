# Follow-up fixes for Concepts/TestPMConcept.html settings

All edits in the build sources (`Concepts/pm7-tools/settings_tome_source.py`, `systems_integration_source.py`), then rebuild via `build_pm7.py` and visually verify every item in the browser (screenshots across themes/widths).

## 1. #2 — remaining left color banners (found the culprits)
- **`.side-link.active::before` / `.domain-link.active::before`**: a 2px glowing accent bar on the LEFT of every active settings-rail item (the "Settings Home / CHAPTERS" list). This is the banner you're still seeing. Remove it; the existing tinted-pill background already marks the active item.
- **Source Control manager**: `.sh-hit:hover` paints a colored left strip — remove the border-left color shift, keep the background tint.
- **`.drawer`**: accent-tinted left border → neutral `var(--k3-line)`.
- Plus a full visual sweep of every workspace (light+dark, wide+narrow, drawers/menus open) to catch any straggler strips and remove them.

## 2. #4 — remove the accent dot
Drop the dot span (markup + CSS); the changed state keeps only the "Modified" chip.

## 3. #6 — vertical text inside managers when narrow
Real cause: `.resource-name` (e.g. "Claude Code") has no nowrap and gets squeezed to word-per-line stacking by the header buttons at narrow widths (`.resource-name-line` even gets `flex-wrap: wrap` in the narrow block). Fix: titles stay on one line with ellipsis — `.resource-name`/`.resource-sub` (nowrap + ellipsis + min-width:0, name-line nowrap), same for `.panel-title` (and min-width:0 on its flex parent) and `.library-item-name`. Text can never stack vertically again.

## 4. #7 — rosters still scroll on wide monitors
Found it: K3 has `@media (min-width:1440px) { .workspace-block .resource-roster { position: sticky; max-height: calc(100vh - 120px); overflow: auto; } }` — on wide windows the left roster becomes its own scroll region again (my earlier check ran at exactly 1440 viewport, just under the trigger). Fix: rosters are always `position: static; max-height: none; overflow: visible`, so the panel grows to fit and only the settings document scrolls. Also drop my earlier redundant container-query block.

## 5. #8 — remove the "Important distinction" box
Remove that whole panel-card (title, subtitle, "Inspect model capabilities" button, and the alert-strip text) from the Providers & Accounts overview.

## 6. Whole-screen refresh on setting change
`toggle-setting`, `set-setting`, `step-setting`, `toggle-multi-setting`, `move-setting-item`, `reset-setting` all call `rerender()` → `renderApp()` rebuilds the entire shell (rail, topbar, tabs, stage). Add `refreshSettingRow(id)`: re-render just that one setting row via `renderSettingRow` and swap it in place (state save + toast unchanged). Falls back to the old soft render only if the row can't be found or the detail inspector is open for that setting. (Typing and select changes already update in place.)

## 7. Square corners for retro themes only
For `retro-dark`/`retro-light` only, scoped to `#panel-settings`: zero the radius tokens plus a curated element sweep — the middle-left panel boxes (`.page-index-card`, `.page-index-title`, `.local-nav`, `.index-link`), manager chrome (`.manager-page`, resource panes, `.panel-card`, `.stat-card`, `.route-card`, `.data-table`, library grid, `.setting-list`, `.workflow-step`), standalone settings chrome (`.topbar`, `.workspace-tabs`, `.project-pill`, `.rail-search`, `.side-card`, `.rail-project`, `.domain-link`/`.side-link`, `.page-header`), and controls (`.btn`, `.icon-btn`, inputs/selects, `.segmented`, `.stepper`, `.chip-select button`, `.toggle`, dialogs, drawers, popovers).
