## Layer 0 — shared motion engine

1. **Origin-aware stage transitions** (packet: "Establish spatial origin"). New `M.captureOrigin(el)` records the clicked control's position as `--pm-origin-x/y` on the stage; `S.swapStage` entrances then radiate from that point (transform-origin + origin-directed offset; the zoom variant scales from the origin). Wired to: destination panels (01), regions (02), stack item heads (03), channels/landmarks/search picks (all).
2. **`M.spring(el, opts)`** — small critically-damped rAF spring on transform. Used for: Atlas pin drop-settle, tilt/magnetic return, Stack reorder flight overshoot, minimap thumb follow.
3. **`M.pointerGlow(root, sel)`** — delegated pointermove writes `--mx/--my` per card → cursor-following radial light (CSS); tilt ≤1.5° on `.cr-dest`/`.at-region` (rotateX/Y from pointer offset); magnetic press on buttons (scale-dip + spring return); chevron micro-rotate on hover. Gates: `matchMedia('(hover:hover) and (pointer:fine)')`, reduced-motion off, rAF-throttled, transform-only.
4. **Theme-scaled motion** — `--pm-motion-scale` per theme family (friendly/glass 1, retro .8, basic .85) multiplying the `--t-*` duration tokens (CursorAuto parity, ours stays token-driven).
5. **Micro-choreography** — toast: icon slide + label fade in, exit slides down; chip settle (one-shot scale) on value change; sprout badge pop on count change (one-shot); search-input one-shot focus breathe on ⌘K.
