L012496:   - which major surface/tab/panel should become visible
L012497:   - which project/workspace context should be activated

L012499:   - panel widths
L012500:   - floating window coordinates
L012501:   - icon order
L012502:   - full project-state snapshots
L012503:   - incidental shell preferences
L012504:
L012505: ### Recommended boundary
L012506: - Canonical routing may carry enough view intent to answer:
L012507:   - what object
L012508:   - in which broad destination surface
L012509:   - in which project/run/thread context
L012510: - Persisted shell state remains responsible for:
L012511:   - how the side panel is docked/floated
L012512:   - which workspace tab/window currently hosts the content
L012513:   - restoring per-project layout and remembered local UI state
L012514: - If a route needs a panel or tab visible, that should be expressed as destination intent, not as raw shell-state restoration payload.
