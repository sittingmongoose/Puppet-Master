L003214: ### Recommended action classes
L003215: - Strong recommendation:
L003216:   - classify actions by both `confirmation level` and `reversibility`
L003217: - Candidate confirmation levels:
L003218:   - `none`
L003219:   - `light`
L003220:   - `strong`
L003221:   - `hard_gate`
L003222: - Candidate reversibility classes:
L003223:   - `immediate_undo`
L003224:   - `compensating_action_only`
L003225:   - `non_reversible`
L003226:
L003227: ### Working interpretation
L003228: - `none`
L003229:   - safe navigation/focus actions
L003230:   - low-risk presentation actions
L003231:   - no user-data or live-runtime mutation
L003232: - `light`
L003233:   - moderate-impact actions where accidental activation is plausible
L003234:   - short confirm or inline affordance is enough
L003235: - `strong`
L003236:   - actions that may discard local state, remove artifacts/worktrees, revoke accepted state, or materially change live execution
L003237:   - should show scope and consequence clearly
L003238: - `hard_gate`
L003239:   - actions that must go through a canonical approval/blocked flow and cannot be bypassed by generic UI confirmation
L003240:   - examples already exist in HITL and explicit remote-side-effect safety flows
L003241:
L003242: ### Reversibility direction
L003243: - `immediate_undo`
L003244:   - UI can offer a direct undo/revert path within a practical window
L003245:   - example class: reversible local presentation/layout actions, some editor-level reverts
L003246: - `compensating_action_only`
L003247:   - no true undo, but a later action can change the system back or restore equivalent behavior
L003248:   - examples:
L003249:     - acknowledge/dismiss concern
L003250:     - reopen after revoke
L003251:     - restore from safe point / restore point
L003252:     - recreate a pruned worktree lane only via new runtime action, not true undo
L003253: - `non_reversible`
L003254:   - action destroys or mutates durable/live state in a way that is not directly undoable
L003255:   - examples:
L003256:     - removing a worktree directory
L003257:     - pruning evidence
L003258:     - deleting records/skills/files when no protected restore path exists
L003259:
L003260: ### Recommended action-family mapping
L003261: - `none`
L003262:   - open/focus/navigate/deep-link
L003263:   - open evidence/history/ledger/source control
L003264:   - tab-local filter/sort/search changes
L003265: - `light`
L003266:   - acknowledge minor concern
L003267:   - dismiss non-blocking advisory
L003268:   - switch focused run
L003269:   - open resolution thread
L003270: - `strong`
L003271:   - pause/cancel live run
L003272:   - start fresh attempt
L003273:   - retry from safe point
L003274:   - remove/prune/archive worktree
L003275:   - clean workspace / clean all worktrees
L003276:   - prune evidence
L003277:   - revoke promotion / seam completion
L003278:   - merge/split concerns
L003279:   - delete run if that remains allowed at all
L003280: - `hard_gate`
L003281:   - approve/reject HITL boundaries
L003282:   - graph patch application when it changes canonical graph generation
L003283:   - remote-side-effect actions with explicit non-bypassable policy
L003284:   - any approval path whose allowed actions are defined by runtime blocked/HITL contracts rather than generic UI choice

L003287: - `light` confirm should show:
L003288:   - action name
L003289:   - target object

L003291:   - action name
L003292:   - target object(s)
