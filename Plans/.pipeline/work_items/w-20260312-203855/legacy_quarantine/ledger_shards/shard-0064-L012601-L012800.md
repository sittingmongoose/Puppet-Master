L012664: - The shell already persists substantial per-project state and is supposed to restore it consistently.
L012665: - At the same time, several route actions clearly need to force a change in destination context:
L012666:   - `Show in Usage`
L012667:   - `Open in Source Control`
L012668:   - `Resume Wizard`
L012669:   - `focus_thread_usage`
L012670:   - `View in Usage` from Orchestrator Ledger
L012671: - The clean rule is:
L012672:   - route activation overrides remembered state only when required to satisfy the requested destination/object/context
L012673:   - otherwise it should reuse persisted shell state and local destination defaults
L012674:
L012675: ### Recommended override policy
L012676: - MUST override:
L012677:   - target object identity
L012678:   - destination surface when the action explicitly names a different surface
L012679:   - scope required to make the target meaningful, such as `project_id`, `thread_id`, `focused_run_id`, or an explicitly requested panel/tab
L012680: - MAY reuse persisted state for:
L012681:   - panel docking/floating realization
L012682:   - destination-local subview when not specified by the route
L012683:   - local filters/sort/layout where they do not hide or distort the requested target
L012684: - MUST NOT reuse persisted state when doing so would:
L012685:   - land on the wrong object
L012686:   - hide the requested target behind the wrong tab/subview
L012687:   - silently keep the user on a stale run/thread/project context
L012688:
L012689: ### Concrete examples
L012690: - `cmd.artifacts.show_in_usage`
L012691:   - must open/focus Usage in the correct project/thread/run scope
L012692:   - may reuse current Usage layout/filter chrome if it still reveals the requested usage target
L012693: - `cmd.orchestrator.open_in_source_control`
L012694:   - must land in Source Control with the relevant run/worktree/repo context available
L012695:   - may reuse remembered Source Control subview only if it still exposes the requested target clearly
L012696: - `Resume Wizard`
L012697:   - must override to the wizard surface and the correct wizard/step context
L012698:   - must not preserve unrelated current primary-view context just because it was last open
L012699: - `cmd.chat.focus_thread_usage`
L012700:   - must focus the thread Usage detail surface for that thread
L012701:   - may reuse side-panel docking/floating realization
