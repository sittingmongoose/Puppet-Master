## Installation

Extract the package into the latest repo root, then run:

```bash
python3 scripts/pm-install-prd-planning-wizard-ledger.py --dry-run
python3 scripts/pm-install-prd-planning-wizard-ledger.py

python3 scripts/pm-bootstrap-ledger-validate.py \
  Plans/ledgers/v2/pldg-20260618-001-prd-planning-wizard

python3 scripts/pm-plan-index.py validate
python3 scripts/pm-shard-plans.py --check
```

Then start a new Codex Goal thread using:

```text
Plans/ledgers/v2/pldg-20260618-001-prd-planning-wizard/prompts/compile_ledger_to_plans.md
```
