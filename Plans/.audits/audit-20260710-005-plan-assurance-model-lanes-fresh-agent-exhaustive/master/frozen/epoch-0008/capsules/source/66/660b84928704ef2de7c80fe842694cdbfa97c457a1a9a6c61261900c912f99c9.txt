L00001830	## 5. Validation And Acceptance
L00001831	
L00001832	Goal Runtime implementation is acceptable only when:
L00001833	
L00001834	- all Goal Runtime PlanUnits include `gui_related: true|false`;
L00001835	- invisible internal goals, visible Assistant Chat goals, and Orchestrator Goal runtime flows share one lifecycle/state model;
