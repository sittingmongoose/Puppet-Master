L00000045	
L00000046	Settings resolution is always described on three axes:
L00000047	- `source`: where a candidate value came from (`manual_override`, `persona_preference`, `surface_default`, `scope_policy`, `config_default`, `provider_default`).
L00000048	- `request`: the value explicitly requested for this run or child run.
L00000049	- `execution`: the value actually handed to the selected provider/runtime after capability checks, worktree assignment, and policy gating.

L00000057	2. scoped owner policy for the active execution unit (`run`, `seam`, `package`, `node`, `overseer`, or delegated subagent)

L00000059	4. surface or stage default
L00000060	5. project or global config default
L00000061	6. last-used state where the surface explicitly permits it
