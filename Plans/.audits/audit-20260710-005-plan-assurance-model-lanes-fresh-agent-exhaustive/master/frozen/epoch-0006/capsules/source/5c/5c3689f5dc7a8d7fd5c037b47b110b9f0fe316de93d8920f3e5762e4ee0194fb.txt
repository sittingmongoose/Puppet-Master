L00001106	- `5` = verbose, teaching-oriented, high-context explanation.

L00001110

L00001112	1. user preference setting,
L00001113	2. mode overlay,
L00001114	3. explicit per-thread override.
L00001115

L00001117	- plan mode → `4`
L00001118	- ask mode → `3`
L00001119	- agent mode → `2`

L00001121	Rules:

L00001123	- `talkativeness` maps to system-prompt instructions that control response length, amount of explanation, and expected detail level,
L00001124	- some model families follow terse instructions more reliably than others, so PM MAY adjust the instruction mapping per model family while preserving the same user-visible scale.
L00001125	
L00001126	`talkativeness` is a Persona instruction-layer control rather than a transport sampling knob.
L00001127
