L00001591	### 11.3 Prompt Content Checking & Context Compilation
L00001592	
L00001593	**Problem:** Agents may include destructive commands in their prompts, not just CLI args. Additionally, context files may contain destructive commands that get compiled into the final prompt.
L00001594	
L00001595	**Context Compilation Flow:**
L00001596	
L00001597	1. **Initial Prompt:** `ExecutionRequest.prompt` contains the base instruction
L00001598	2. **Context Files:** `ExecutionRequest.context_files` contains file paths to include
L00001599	3. **Context Compilation:** Platform runners call `append_prompt_attachments()` to merge context files into prompt
L00001600	4. **Final Prompt:** The compiled prompt (with context) is sent to platform CLI
L00001601

L00001633	
L00001634	FileSafe must check the **compiled prompt** (after context compilation), not just the original prompt. This ensures:
L00001635	- Destructive commands in context files are caught
L00001636	- File paths in context attachments are validated
