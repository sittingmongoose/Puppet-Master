L00000644	## 3. Natural-language slot extraction grammar
L00000645	
L00000646	This section defines the deterministic, regex-based mini grammar for extracting structured parameters from user natural-language prompts. The extraction pipeline runs before `media.generate` is called and produces the request envelope fields (§2.2).
L00000647	
L00000648	ContractRef: ToolID:media.generate, PolicyRule:Decision_Policy.md§2
L00000649	
L00000650	### 3.1 Pre-processing

<<< AUTHORITATIVE_CORE canonical_document_lines=651-1048 >>>
L00000651	
L00000652	- Keep `raw` (original user text) and `s_lower` (normalized lowercased copy).
L00000653	- If a trailing controls block exists (the prompt ends with `(...)` or `[...]` and the block contains at least one control token), split `body` + `controls` and parse controls first; remove the block from the prompt before creative-prompt cleaning.
L00000654	- If the trailing block contains unmatched delimiters, control keys with empty values, or unsupported control names, ignore the malformed control token rather than failing the full request. The cleaned creative prompt still proceeds through deterministic extraction.
L00000655	
L00000656	Controls-block regex:
L00000657	```
L00000658	(?is)^(?P<body>.*?)(?:\s*(?P<bracket>\(|\[)\s*(?P<controls>[^)\]]{1,400})\s*(?:\)|\])\s*)$
L00000659	```
L00000660	
L00000661	Control token gate (at least one must match inside the captured controls):
L00000662	```
L00000663	\b(model|aspect|ratio|size|resolution|duration|voice|format|bpm|seed|negative|quality)\b
L00000664	```
L00000665	
L00000666	### 3.2 Kind detection
L00000667	
L00000668	- **Prefix form** (highest priority):
L00000669	  ```
L00000670	  (?is)^\s*(?P<prefix>image|video|tts|music)\s*:\s*
L00000671	  ```
L00000672	- **Keyword-based** (if no prefix match):
L00000673	  - `image`: `\b(image|picture|photo|logo|poster|thumbnail|cover)\b`
L00000674	  - `video`: `\b(video|clip|animation|broll|b-roll)\b`
L00000675	  - `tts`: `\b(tts|text to speech|read aloud|say this|voiceover|voice-over)\b`
L00000676	  - `music`: `\b(music|song|beat|instrumental|soundtrack)\b`
L00000677	- **Verb fallback** — only if the above are unambiguous (single kind match).
L00000678	
L00000679	### 3.3 Deterministic precedence
L00000680	
L00000681	Controls-block key/values override everything. Then, in order:
L00000682	
L00000683	1. `model_override`
L00000684	2. `count`
L00000685	3. `aspect_ratio`
L00000686	4. `size` / `resolution`
L00000687	5. `duration`
L00000688	6. `format`
L00000689	7. `voice` / `style`
L00000690	8. `quality`
L00000691	9. `seed`
L00000692	10. `bpm`
L00000693	11. `negative_prompt`
L00000694	
L00000695	### 3.4 `model_override` extraction
L00000696	
L00000697	Keyword form:
L00000698	```
L00000699	(?is)\b(?:using|with|via|use|model)\s*(?:[:=]\s*)?(?P<model>@?[a-z0-9][a-z0-9._/\-\s]{0,80}?)(?=(?:\s*(?:,|;|\)|\]|\.$|$))|\s+\b(?:for|aspect|ratio|size|resolution|format|voice|duration|negative|quality|seed|bpm|variations?|versions?|options?)\b)
L00000700	```
L00000701	(?i)(?<!\w)@(?P<model2>[a-z0-9][a-z0-9._/\-]{1,64})(?!\w)
L00000702	```
L00000703	
L00000704	**Normalize model key:** lowercase; collapse spaces, underscores, and hyphens.
L00000705	
L00000706	**Resolution order:** alias → exact model id → exact displayName → else `MODEL_UNAVAILABLE`.
L00000707	
L00000708	**Canonical media model aliases** (e.g., "Nano Banana", "Nano Banana Pro", "Veo fast", "TTS flash", "TTS pro") are defined in `Plans/Models_System.md` [§6.8](Plans/Models_System.md#MEDIA-ALIASES) (SSOT). Do not restate the alias table here.
L00000709	
L00000710	ContractRef: ToolID:media.generate, ContractName:Plans/Models_System.md#MODEL-ID, ContractName:Plans/Models_System.md#MEDIA-ALIASES
L00000711	
L00000712	### 3.5 `count` extraction
L00000713	
L00000714	Digits form:
L00000715	```
L00000716	(?i)\b(?:(?:make|generate|create|give me|output|render)\s+)?(?P<count>\d{1,2})\s*(?:x\s*)?(?:variations?|versions?|options?|images?|pics?|pictures?|clips?|frames?)\b
L00000717	```
L00000718	
L00000719	Optional word forms (one through ten) follow the same pattern. Clamp to safe max (default 8). Last match wins.
L00000720	
L00000721	### 3.6 `aspect_ratio` extraction
L00000722	
L00000723	Numeric:
L00000724	```
L00000725	(?i)\b(?P<ar_w>\d{1,2})\s*:\s*(?P<ar_h>\d{1,2})\b
L00000726	```
L00000727	
L00000728	Named:
L00000729	```
L00000730	(?i)\b(?P<ar_named>square|portrait|landscape|vertical|horizontal|widescreen)\b
L00000731	```
L00000732	
L00000733	Mapping: `square` = `1:1`; `portrait` / `vertical` = `9:16`; `landscape` / `horizontal` / `widescreen` = `16:9`.
L00000734	
L00000735	### 3.7 `size` / `resolution` extraction
L00000736	
L00000737	Image keyworded:
L00000738	```
L00000739	(?i)\b(?:size|resolution|res)\s*[:=]?\s*(?P<size_px>512|768|1024|1152|1280|1536|2048|3072|4096)\s*(?:px|pixels)?\b
L00000740	```
L00000741	
L00000742	Image keyworded (k-form):
L00000743	```
L00000744	(?i)\b(?:size|resolution|res)\s*[:=]?\s*(?P<size_k>2k|4k|8k)\b
L00000745	```
L00000746	
L00000747	Video resolution:
L00000748	```
L00000749	(?i)\b(?P<vres>720p|1080p|1440p|2160p|4k)\b
L00000750	```
L00000751	
L00000752	Bare numbers are **not** treated as size unless they appear in a controls block or trailing comma controls.
L00000753	
L00000754	Deterministic assignment to envelope fields:
L00000755	- `size_px` populates `size`.
L00000756	- `size_k` populates `size` using `2k -> 2048`, `4k -> 4096`, `8k -> 8192`, and also populates `resolution` with the symbolic token.
L00000757	- `vres` populates `resolution` for `kind=video`; for `kind=image`, bare `vres` matches in creative prose are ignored unless provided in a keyed controls context.
L00000758	- If both `size_k` and `vres` are present in an image request, `size_k` is authoritative and `resolution` remains the symbolic `size_k` token.
L00000759	
L00000760	ContractRef: ToolID:media.generate, PolicyRule:Decision_Policy.md§2
L00000761	
L00000762	### 3.8 `duration` extraction (video/music only)
L00000763	
L00000764	Keyworded:
L00000765	```
L00000766	(?i)\b(?:for|duration|length)\s*(?P<secs>\d{1,3}(?:\.\d+)?)\s*(?:s|sec|secs|second|seconds)\b
L00000767	```
L00000768	
L00000769	Bare (only in controls block or trailing controls):
L00000770	```
L00000771	(?i)\b(?P<secs2>\d{1,3}(?:\.\d+)?)\s*(?:s|sec|secs)\b
L00000772	```
L00000773	
L00000774	### 3.9 `format` extraction
L00000775	
L00000776	```
L00000777	(?i)\b(?:format|output|export|as)\s*[:=]?\s*(?P<fmt>png|jpg|jpeg|webp|gif|mp4|mov|wav|mp3|flac|pcm16)\b
L00000778	```
L00000779	
L00000780	### 3.10 `voice` extraction (TTS)
L00000781	
L00000782	Voice ID:
L00000783	```
L00000784	(?i)\bvoice\s*[:=]\s*(?P<voice>[a-z0-9][a-z0-9 _\-]{0,32})\b
L00000785	```
L00000786	
L00000787	Voice style:
L00000788	```
L00000789	(?i)\bin\s+a[n]?\s+(?P<voice_style>[^,.;]{1,40})\s+voice\b
L00000790	```
L00000791	
L00000792	### 3.11 `quality` extraction
L00000793	
L00000794	```
L00000795	(?i)\b(?P<qual>draft|standard|high)\b
L00000796	```
L00000797	
L00000798	Optional phrase mapping (e.g., "quick draft" → `draft`, "high quality" → `high`).
L00000799	
L00000800	Deterministic guard: bare lexical matches from the regex above are candidate tokens only. `quality` MUST be set only when the match is in a controls block or a quality-keyword phrase (`quality: high`, `quality=standard`, `high quality`, `draft quality`); plain descriptive adjectives in the creative prompt MUST NOT set `quality`.
L00000801	
L00000802	ContractRef: ToolID:media.generate, PolicyRule:Decision_Policy.md§2
L00000803	
L00000804	### 3.12 `seed` extraction
L00000805	
L00000806	```
L00000807	(?i)\bseed\s*[:=]?\s*(?P<seed>\d{1,10})\b
L00000808	```
L00000809	
L00000810	### 3.13 `bpm` extraction
L00000811	
L00000812	```
L00000813	(?i)\b(?P<bpm>\d{2,3})\s*bpm\b|\bbpm\s*[:=]\s*(?P<bpm2>\d{2,3})\b
L00000814	```
L00000815	
L00000816	### 3.14 `negative_prompt` extraction
L00000817	
L00000818	Explicit:
L00000819	```
L00000820	(?is)\bnegative\s+prompt\s*[:=]\s*(?P<neg>"[^"]{1,200}"|'[^']{1,200}'|[^,;\n]{1,200})
L00000821	```
L00000822	
L00000823	Avoid-clauses (collect all):
L00000824	```
L00000825	(?is)\b(?:without|no|avoid)\s+(?P<avoid>[^,.;\n]{1,80})
L00000826	```
L00000827	
L00000828	Combine explicit + avoid list (dedupe, preserve order).
L00000829	
L00000830	### 3.15 Prompt cleaning
L00000831	
L00000832	- If a controls block is present: remove it from the creative prompt.
L00000833	- Remove only matched spans introduced by control keywords (`using`, `model`, `size`, `aspect`, `ratio`, `resolution`, `format`, `voice`, `duration`, `negative`, `quality`, `seed`, `bpm`).
L00000834	- Preserve remaining text as the creative prompt.

L00000854	
L00000855	### 4.2 Disabled item presentation
L00000856	
L00000857	Disabled capabilities are **visible** in the dropdown but rendered **greyed out**. A tooltip on hover shows the human-readable reason for the disabled state (using the copy strings from §5).
L00000858	
L00000859	Disabled rows remain keyboard-focusable so the same reason text is available on hover **and** focus. The dropdown uses standard listbox semantics (`role=listbox` / `role=option` or framework equivalent), and the disabled reason must be exposed to assistive technologies via the tooltip/description channel rather than color alone.
L00000860	
L00000861	ContractRef: ToolID:capabilities.get, Invariant:INV-003
L00000862	
L00000863	### 4.3 Banner/footnote
L00000864	When visible media capabilities are disabled because no eligible media generation provider route is configured for the resolved request/policy, the dropdown footer displays this banner/footnote:
L00000865	
L00000866	> **"Configure a media generation provider in Settings -> Providers."** Add a supported route such as OpenAI/Codex, OpenAI API key, MiniMax Image-01, Antigravity internal image generation where available, or Gemini Direct where available.
L00000867	
L00000868	Provider-specific helper links may point to the relevant dashboard or API-key page, but the surrounding copy MUST NOT imply Gemini is the default or only valid media source.
L00000869	
L00000870	ContractRef: ToolID:capabilities.get, Invariant:INV-003, ContractName:Plans/rewrite-tie-in-memo.md
L00000871	
L00000872	When multiple visible capabilities are disabled for the same missing-configuration reason, show the footer banner once and keep it pinned at the bottom of the dropdown while the list scrolls. The banner is supplemental guidance; per-item disabled reasons remain visible on hover/focus.
L00000873	
L00000874	ContractRef: ToolID:capabilities.get, ContractName:Plans/FinalGUISpec.md, ContractName:Plans/Multi-Account.md
L00000875	### 4.4 Cursor backend behavior
L00000876	When the active backend is Cursor:
L00000877	- image generation is enabled only if the Cursor route declares a verified generated-media route for image output
L00000878	- image input/tooling evidence alone does not prove generated-image support
L00000879	- video, TTS, and music remain disabled with `disabled_reason: BACKEND_UNSUPPORTED` unless Cursor later declares verified generated-media routes
L00000880	- Cursor does not create a separate Gemini account model
L00000881	- non-Cursor media follows the provider/model `generated_media_routes[]` taxonomy described in `### 2.4 Backend routing`
L00000882	
L00000883	ContractRef: ToolID:capabilities.get, ToolID:media.generate, ContractName:Plans/CLI_Bridged_Providers.md
L00000884	### 4.5 Click behavior
L00000885	
L00000886	Clicking an **enabled** capability item inserts a pre-authored assistant prompt into the chat composer. The prompt guides the user to describe their generation request with relevant parameters. See §5 for the exact prompt strings per capability.
L00000887	
L00000888	### 4.6 Per-message model override example
L00000889	
L00000890	A user may specify a per-message model override inline in their prompt. For example:
L00000891	
L00000892	> "Generate an image of a sunset over mountains using Nano Banana Pro"
L00000893	
L00000894	This triggers the `model_override` slot extraction (§3.4). The model `Nano Banana Pro` is resolved via alias → exact model id → exact displayName → else `MODEL_UNAVAILABLE`. The override applies only to this single generation request and does not change the model configured in Settings.
L00000895	
L00000896	ContractRef: ToolID:media.generate, ContractName:Plans/Models_System.md#MODEL-ID
L00000897	
L00000898	### 4.7 Runtime refresh behavior
L00000899	
L00000900	The capability picker refreshes after Settings or provider-state changes that affect capability evaluation (for example, adding an OpenAI/Codex subscription-backed route, saving an OpenAI API key, enabling MiniMax Image-01, enabling Antigravity OAuth/internal `gemini-3.1-flash-image`, saving a Gemini Direct API key, toggling a media capability off, switching providers, or recovering an MCP/provider bridge). Refresh MUST preserve composer text already typed by the user; only the picker contents and footer/banner state are recalculated.
L00000901	
L00000902	ContractRef: ToolID:capabilities.get, Invariant:INV-003, ContractName:Plans/FinalGUISpec.md
