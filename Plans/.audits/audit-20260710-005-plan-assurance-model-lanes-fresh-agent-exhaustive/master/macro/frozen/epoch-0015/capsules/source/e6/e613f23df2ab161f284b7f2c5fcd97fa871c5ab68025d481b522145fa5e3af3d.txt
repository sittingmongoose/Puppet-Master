L00000001	# Plan To Node Compilation
L00000002	
L00000003	> **Compliance:** This document follows `Plans/DRY_Rules.md` and references SSOT contracts in `Plans/Contracts_V0.md`. Naming: "Puppet Master" only. This document owns the PlanUnit-to-node-readiness boundary and the future compiler interface. It does not create WorkNodes.
L00000004	
L00000005	## 0. Scope
L00000006	
L00000007	This document defines the safe interface between canonical PlanUnits and executable build planning. The PlanUnit indexing phase still emits only a PlanUnit index and node-readiness report. Runtime PlanCompile may later materialize NodeSeed, WorkGraph, WorkNodeRequest, and WorkNodeRecord artifacts only through the explicit compiler, Executor intake, activation, and certification contracts below; generated index artifacts never create executable queues or final build tasks.
L00000008	
L00000009	ContractRef: ContractName:Plans/Plan_To_Node_Compilation.md, ContractName:Plans/Plan_Document_System.md
L00000010	
L00000011	## 1. Boundary
L00000012	
L00000013	The safe bootstrap flow is:
L00000014	
L00000015	```text
L00000016	ledger design atom -> PlanUnit -> PlanUnit index -> node-readiness report -> future NodeSeed / WorkNode compiler -> future native Goal Mode execution
L00000017	```
L00000018	
L00000019	The PlanUnit index phase ends at node-readiness reporting. It may analyze blockers, missing dependencies, validation coverage, risk, ambiguity, context scope, implementation surfaces, and gui_related routing inheritance. Runtime PlanCompile is a separate implementation surface: it can draft non-executable NodeSeed candidates, certify a WorkGraph draft, emit WorkNodeRequest records for Executor intake, and materialize WorkNodeRecord objects only after activation. The indexer itself does not create final WorkNodes or executable build tasks.
L00000020	
L00000021	ContractRef: ContractName:Plans/Plan_To_Node_Compilation.md, ContractName:Plans/Plan_Document_System.md
