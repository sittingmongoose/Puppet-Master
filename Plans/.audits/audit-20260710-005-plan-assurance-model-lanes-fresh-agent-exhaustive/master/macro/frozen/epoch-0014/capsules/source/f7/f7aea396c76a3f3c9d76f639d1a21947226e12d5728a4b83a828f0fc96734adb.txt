L00000052	## 1. Capability system
L00000053	
L00000054	### 1.1 Internal tool: `capabilities.get`
L00000055	
L00000056	`capabilities.get` is an internal tool that returns the full set of capabilities currently available to the running Puppet Master instance. The response includes **all** capabilities — both media capabilities and provider/tool capabilities — each annotated with enablement status, a machine-readable disabled reason (when disabled), and setup hints.
L00000057	
L00000058	ContractRef: ToolID:capabilities.get, ContractName:Plans/Tools.md

L00000354	
L00000355	`capabilities.get` is computed from the **current runtime registry snapshot** at call time. That snapshot MUST merge:
L00000356	- built-in internal tools from the canonical tool registry,
L00000357	- currently enabled MCP-discovered tools whose server/provider bridge is healthy for the active provider,
L00000358	- provider-exposed tools surfaced through the active backend,

L00000423	
L00000424	Deterministic `size` / `resolution` normalization for the request envelope:
L00000425	- If `kind=image` and `size_px` is matched, set `size` to the parsed integer and set `resolution` to `null` unless an explicit symbolic resolution token is also provided.
L00000426	- If `size_k` is matched, map `2k -> 2048`, `4k -> 4096`, `8k -> 8192` into `size`; also set `resolution` to the symbolic token (`2k`, `4k`, or `8k`).
L00000427	- If `kind=video` and `vres` is matched, set `resolution` to the parsed token (`720p`, `1080p`, `1440p`, `2160p`, or `4k`) and keep `size` as `null`.
L00000428	- Conflict rule: for `kind=image`, `size_k`/`size_px` controls are authoritative over `vres`; for `kind=video`, `vres` is authoritative for `resolution`. Within the same keyed family, last match wins.
L00000429	
L00000430	ContractRef: ToolID:media.generate, PolicyRule:Decision_Policy.md§2

L00000432	### 2.3 Per-request model override (`model_override`)
L00000433	
L00000434	The `model_override` field allows a user to specify a model for a single generation request without changing the persistent model configured in Settings. This is ephemeral — it applies only to the current `media.generate` invocation.
L00000435	
L00000436	Resolution order for `model_override`:
L00000437	1. **Alias mapping** — check registered model aliases.
L00000438	2. **Exact model ID** — match against known model IDs.
L00000439	3. **Exact displayName** — match against model display names (case-insensitive).
L00000440	4. **Else** — return `MODEL_UNAVAILABLE` disabled reason.
L00000441

L00000444	### 2.4 Backend routing
L00000445	Media routing resolves through concrete provider/model rows and their `generated_media_routes[]`, `media_input`, and `media_output` capability fields.

L00000452	- when the active backend is Cursor and `kind` is `video`, `tts`, or `music`, disable the capability with `disabled_reason: BACKEND_UNSUPPORTED` unless a verified Cursor route later declares that generated-media kind.

L00000577	  - `counting_semantics` states whether cache buckets are subsets of input totals, whether reasoning/thoughts are subsets of output totals, and whether `provider_total` is provider authoritative or derived; media rollups must not double-count inclusive provider totals.
L00000578	  - `media_units` is a media-specific quantity list such as generated image count, seconds of audio/video, frames, or provider media credits; it is not a token total, cost total, usage authority, or replacement for UF-085 buckets.
L00000579	  - Legacy import names such as `cost_is_estimate`, `input_tokens`, and `output_tokens` may appear only at provider/import boundaries or in source-lineage fixtures. They normalize to `cost_status`, `input_total`, `output_total`, canonical source/settlement fields, and UsageRecord identity before manifest persistence, GUI display, rollups, or accounting checks.
L00000580	- `error` (object | null): present on failure (see §2.6).
L00000581	
L00000582	ContractRef: ContractName:Plans/usage-feature.md, ContractName:Plans/Architecture_Invariants.md
L00000583	
L00000584	**Deterministic artifact layout:** Generated artifacts are written to `.puppet-master/artifacts/media/<request_id>/output_000.<ext>` (zero-padded index). A `manifest.json` is co-located alongside artifacts in the same directory, containing the full `artifacts[]` array plus `request_id` and generation metadata, enabling offline re-verification. No inline `data_uri` is returned.
L00000585	
L00000586	**Manifest contract and write ordering:** `manifest.json` MUST be a durable, self-sufficient index for the request directory and include at minimum: `schema_version`, `request_id`, `kind`, `engine`, `generated_at_utc`, `artifacts[]`, and the canonical UsageRecord bridge `usage` (when available). Implementations MUST write artifact files first, compute hashes/bytes from the final bytes on disk, normalize any legacy provider usage aliases to UF-085 fields, and only then write `manifest.json`. If the provider returns partial output and final artifact persistence fails, the call returns failure and MUST NOT leave a manifest claiming success for missing artifacts.
L00000587	
L00000588	**Generation supersession record:** When remediation or graph generation supersedes a media attempt, the result carries old generation, new generation, invalidated path refs, new path refs, surviving `/rejoined` path refs, and resulting concern, `/promotion/recovery`, or recovery implications so overlays and blocked actions disclose the final state without diffing addenda.
L00000589	
L00000590	ContractRef: ToolID:media.generate, SchemaID:pm.media.generate.result.v1, Primitive:ArtifactStore
L00000591	
L00000592	**Concurrent requests:** Multiple `media.generate` calls may execute concurrently as long as each uses its own `request_id` directory. No request may append into another request's directory. Retry behavior MUST allocate a new `request_id` rather than mutating a previous manifest in place.
L00000593	
L00000594	ContractRef: ToolID:media.generate, Primitive:ArtifactStore
L00000595	
L00000596	**Route-specific backend behavior:** When the response `engine` identity resolves through the shared requested/effective runtime snapshot to a concrete `provider_entry_id` and `media_route_id`, PM checks that route's `generated_media_routes[]` for the requested `kind`. Cursor image generation is not assumed from image-input/API-key proof; it requires a verified generated-media route. For unsupported kinds, the backend returns `error.code = "BACKEND_UNSUPPORTED"` or the more specific provider status/error state.
L00000597	
L00000598	On failure:
L00000599	```json
L00000600	{
L00000601	  "success": false,
L00000602	  "request_id": "req_20260301_a1b2c3d4",
L00000603	  "kind": "image",
L00000604	  "engine": {
L00000605	    "provider_entry_id": "resolved_provider_entry_id",

L00000607	    "generated_media_route_id": null

L00000643	<a id="SLOT-EXTRACTION"></a>
L00000644	## 3. Natural-language slot extraction grammar
L00000645	
L00000646	This section defines the deterministic, regex-based mini grammar for extracting structured parameters from user natural-language prompts. The extraction pipeline runs before `media.generate` is called and produces the request envelope fields (§2.2).
L00000647	
L00000648	ContractRef: ToolID:media.generate, PolicyRule:Decision_Policy.md§2
L00000649	
L00000650	### 3.1 Pre-processing
L00000651	
L00000652	- Keep `raw` (original user text) and `s_lower` (normalized lowercased copy).
L00000653	- If a trailing controls block exists (the prompt ends with `(...)` or `[...]` and the block contains at least one control token), split `body` + `controls` and parse controls first; remove the block from the prompt before creative-prompt cleaning.
L00000654	- If the trailing block contains unmatched delimiters, control keys with empty values, or unsupported control names, ignore the malformed control token rather than failing the full request. The cleaned creative prompt still proceeds through deterministic extraction.
L00000655	
L00000656	Controls-block regex:
L00000657	```
L00000658	(?is)^(?P<body>.*?)(?:\s*(?P<bracket>\(|\[)\s*(?P<controls>[^)\]]{1,400})\s*(?:\)|\])\s*)$
L00000659	```
L00000660	
L00000661	Control token gate (at least one must match inside the captured controls):
L00000662	```
L00000663	\b(model|aspect|ratio|size|resolution|duration|voice|format|bpm|seed|negative|quality)\b
L00000664	```
L00000665	
L00000666	### 3.2 Kind detection
L00000667	
L00000668	- **Prefix form** (highest priority):
L00000669	  ```
L00000670	  (?is)^\s*(?P<prefix>image|video|tts|music)\s*:\s*
L00000671	  ```
L00000672	- **Keyword-based** (if no prefix match):
L00000673	  - `image`: `\b(image|picture|photo|logo|poster|thumbnail|cover)\b`
L00000674	  - `video`: `\b(video|clip|animation|broll|b-roll)\b`
L00000675	  - `tts`: `\b(tts|text to speech|read aloud|say this|voiceover|voice-over)\b`
L00000676	  - `music`: `\b(music|song|beat|instrumental|soundtrack)\b`
L00000677	- **Verb fallback** — only if the above are unambiguous (single kind match).
L00000678	
L00000679	### 3.3 Deterministic precedence
L00000680	
L00000681	Controls-block key/values override everything. Then, in order:
L00000682	
L00000683	1. `model_override`
L00000684	2. `count`
L00000685	3. `aspect_ratio`
L00000686	4. `size` / `resolution`
L00000687	5. `duration`
L00000688	6. `format`
L00000689	7. `voice` / `style`
L00000690	8. `quality`
L00000691	9. `seed`
L00000692	10. `bpm`
L00000693	11. `negative_prompt`
L00000694	
L00000695	### 3.4 `model_override` extraction
L00000696	
L00000697	Keyword form:
L00000698	```
L00000699	(?is)\b(?:using|with|via|use|model)\s*(?:[:=]\s*)?(?P<model>@?[a-z0-9][a-z0-9._/\-\s]{0,80}?)(?=(?:\s*(?:,|;|\)|\]|\.$|$))|\s+\b(?:for|aspect|ratio|size|resolution|format|voice|duration|negative|quality|seed|bpm|variations?|versions?|options?)\b)
L00000700	```
L00000701	(?i)(?<!\w)@(?P<model2>[a-z0-9][a-z0-9._/\-]{1,64})(?!\w)
L00000702	```
L00000703	
L00000704	**Normalize model key:** lowercase; collapse spaces, underscores, and hyphens.
L00000705	
L00000706	**Resolution order:** alias → exact model id → exact displayName → else `MODEL_UNAVAILABLE`.
L00000707	
L00000708	**Canonical media model aliases** (e.g., "Nano Banana", "Nano Banana Pro", "Veo fast", "TTS flash", "TTS pro") are defined in `Plans/Models_System.md` [§6.8](Plans/Models_System.md#MEDIA-ALIASES) (SSOT). Do not restate the alias table here.
L00000709	
L00000710	ContractRef: ToolID:media.generate, ContractName:Plans/Models_System.md#MODEL-ID, ContractName:Plans/Models_System.md#MEDIA-ALIASES
L00000711	
L00000712	### 3.5 `count` extraction
L00000713	
L00000714	Digits form:
L00000715	```
L00000716	(?i)\b(?:(?:make|generate|create|give me|output|render)\s+)?(?P<count>\d{1,2})\s*(?:x\s*)?(?:variations?|versions?|options?|images?|pics?|pictures?|clips?|frames?)\b
L00000717	```
L00000718	
L00000719	Optional word forms (one through ten) follow the same pattern. Clamp to safe max (default 8). Last match wins.
L00000720	
L00000721	### 3.6 `aspect_ratio` extraction
L00000722	
L00000723	Numeric:
L00000724	```
L00000725	(?i)\b(?P<ar_w>\d{1,2})\s*:\s*(?P<ar_h>\d{1,2})\b
L00000726	```
L00000727	
L00000728	Named:
L00000729	```
L00000730	(?i)\b(?P<ar_named>square|portrait|landscape|vertical|horizontal|widescreen)\b
L00000731	```
L00000732	
L00000733	Mapping: `square` = `1:1`; `portrait` / `vertical` = `9:16`; `landscape` / `horizontal` / `widescreen` = `16:9`.
L00000734	
L00000735	### 3.7 `size` / `resolution` extraction
L00000736	
L00000737	Image keyworded:
L00000738	```
L00000739	(?i)\b(?:size|resolution|res)\s*[:=]?\s*(?P<size_px>512|768|1024|1152|1280|1536|2048|3072|4096)\s*(?:px|pixels)?\b
L00000740	```
L00000741	
L00000742	Image keyworded (k-form):
L00000743	```
L00000744	(?i)\b(?:size|resolution|res)\s*[:=]?\s*(?P<size_k>2k|4k|8k)\b
L00000745	```
L00000746	
L00000747	Video resolution:
L00000748	```
L00000749	(?i)\b(?P<vres>720p|1080p|1440p|2160p|4k)\b
L00000750	```
L00000751	
L00000752	Bare numbers are **not** treated as size unless they appear in a controls block or trailing comma controls.
L00000753	
L00000754	Deterministic assignment to envelope fields:
L00000755	- `size_px` populates `size`.
L00000756	- `size_k` populates `size` using `2k -> 2048`, `4k -> 4096`, `8k -> 8192`, and also populates `resolution` with the symbolic token.
L00000757	- `vres` populates `resolution` for `kind=video`; for `kind=image`, bare `vres` matches in creative prose are ignored unless provided in a keyed controls context.
L00000758	- If both `size_k` and `vres` are present in an image request, `size_k` is authoritative and `resolution` remains the symbolic `size_k` token.
L00000759	
L00000760	ContractRef: ToolID:media.generate, PolicyRule:Decision_Policy.md§2
L00000761	
L00000762	### 3.8 `duration` extraction (video/music only)
L00000763	
L00000764	Keyworded:
L00000765	```
L00000766	(?i)\b(?:for|duration|length)\s*(?P<secs>\d{1,3}(?:\.\d+)?)\s*(?:s|sec|secs|second|seconds)\b
L00000767	```
L00000768	
L00000769	Bare (only in controls block or trailing controls):
L00000770	```
L00000771	(?i)\b(?P<secs2>\d{1,3}(?:\.\d+)?)\s*(?:s|sec|secs)\b
L00000772	```
L00000773	
L00000774	### 3.9 `format` extraction
L00000775	
L00000776	```
L00000777	(?i)\b(?:format|output|export|as)\s*[:=]?\s*(?P<fmt>png|jpg|jpeg|webp|gif|mp4|mov|wav|mp3|flac|pcm16)\b
L00000778	```
L00000779	
L00000780	### 3.10 `voice` extraction (TTS)
L00000781	
L00000782	Voice ID:
L00000783	```
L00000784	(?i)\bvoice\s*[:=]\s*(?P<voice>[a-z0-9][a-z0-9 _\-]{0,32})\b
L00000785	```
L00000786	
L00000787	Voice style:
L00000788	```
L00000789	(?i)\bin\s+a[n]?\s+(?P<voice_style>[^,.;]{1,40})\s+voice\b
L00000790	```
L00000791	
L00000792	### 3.11 `quality` extraction
L00000793	
L00000794	```
L00000795	(?i)\b(?P<qual>draft|standard|high)\b
L00000796	```
L00000797	
L00000798	Optional phrase mapping (e.g., "quick draft" → `draft`, "high quality" → `high`).
L00000799	
L00000800	Deterministic guard: bare lexical matches from the regex above are candidate tokens only. `quality` MUST be set only when the match is in a controls block or a quality-keyword phrase (`quality: high`, `quality=standard`, `high quality`, `draft quality`); plain descriptive adjectives in the creative prompt MUST NOT set `quality`.
L00000801	
L00000802	ContractRef: ToolID:media.generate, PolicyRule:Decision_Policy.md§2
L00000803	
L00000804	### 3.12 `seed` extraction
L00000805	
L00000806	```
L00000807	(?i)\bseed\s*[:=]?\s*(?P<seed>\d{1,10})\b
L00000808	```
L00000809	
L00000810	### 3.13 `bpm` extraction
L00000811	
L00000812	```
L00000813	(?i)\b(?P<bpm>\d{2,3})\s*bpm\b|\bbpm\s*[:=]\s*(?P<bpm2>\d{2,3})\b
L00000814	```
L00000815	
L00000816	### 3.14 `negative_prompt` extraction
L00000817	
L00000818	Explicit:
L00000819	```
L00000820	(?is)\bnegative\s+prompt\s*[:=]\s*(?P<neg>"[^"]{1,200}"|'[^']{1,200}'|[^,;\n]{1,200})
L00000821	```
L00000822	
L00000823	Avoid-clauses (collect all):
L00000824	```
L00000825	(?is)\b(?:without|no|avoid)\s+(?P<avoid>[^,.;\n]{1,80})
L00000826	```
L00000827	
L00000828	Combine explicit + avoid list (dedupe, preserve order).
L00000829	
L00000830	### 3.15 Prompt cleaning
L00000831	
L00000832	- If a controls block is present: remove it from the creative prompt.
L00000833	- Remove only matched spans introduced by control keywords (`using`, `model`, `size`, `aspect`, `ratio`, `resolution`, `format`, `voice`, `duration`, `negative`, `quality`, `seed`, `bpm`).
L00000834	- Preserve remaining text as the creative prompt.
L00000835

L00001059	## Appendix A. Slot extraction rules (regex-ish, deterministic)
L00001060	
L00001061	1) Pre-processing:
L00001062	- Keep raw (original) and s_lower (normalized lowercased).
L00001063	- If trailing controls block exists (ends with (...) or [...] and contains control tokens), split body + controls and parse controls first; remove block from prompt.
L00001064	Controls-block regex: (?is)^(?P<body>.*?)(?:\s*(?P<bracket>\(|\[)\s*(?P<controls>[^)\]]{1,400})\s*(?:\)|\])\s*)$
L00001065	Control token gate: \b(model|aspect|ratio|size|resolution|duration|voice|format|bpm|seed|negative|quality)\b
L00001066	2) kind detection:
L00001067	- Prefix form: (?is)^\s*(?P<prefix>image|video|tts|music)\s*:\s*
L00001068	- Else keyword-based:
L00001069	image: \b(image|picture|photo|logo|poster|thumbnail|cover)\b
L00001070	video: \b(video|clip|animation|broll|b-roll)\b
L00001071	tts: \b(tts|text to speech|read aloud|say this|voiceover|voice-over)\b
L00001072	music: \b(music|song|beat|instrumental|soundtrack)\b
L00001073	- Else verb fallback only if unambiguous.
L00001074	3) Precedence: controls block key/values override everything then: model_override, count, aspect_ratio, size/resolution, duration, format, voice/style, quality, seed, bpm, negative_prompt
L00001075	4) model_override:
L00001076	Keyword form: (?is)\b(?:using|with|via|use|model)\s*(?:[:=]\s*)?(?P<model>@?[a-z0-9][a-z0-9._/\-\s]{0,80}?)(?=(?:\s*(?:,|;|\)|\]|\.$|$))|\s+\b(?:for|aspect|ratio|size|resolution|format|voice|duration|negative|quality|seed|bpm|variations?|versions?|options?)\b)
L00001077	@ shorthand: (?i)(?<!\w)@(?P<model2>[a-z0-9][a-z0-9._/\-]{1,64})(?!\w)
L00001078	Normalize model key: lowercase; collapse spaces/underscores/hyphens.
L00001079	Resolve: alias -> exact model id -> exact displayName -> else MODEL_UNAVAILABLE.
L00001080	5) count:
L00001081	digits: (?i)\b(?:(?:make|generate|create|give me|output|render)\s+)?(?P<count>\d{1,2})\s*(?:x\s*)?(?:variations?|versions?|options?|images?|pics?|pictures?|clips?|frames?)\b
L00001082	optional words one-ten similar.
L00001083	Clamp to safe max (default 8). Last match wins.
L00001084	6) aspect_ratio:
L00001085	numeric: (?i)\b(?P<ar_w>\d{1,2})\s*:\s*(?P<ar_h>\d{1,2})\b
L00001086	named: (?i)\b(?P<ar_named>square|portrait|landscape|vertical|horizontal|widescreen)\b
L00001087	Mapping: square=1:1; portrait/vertical=9:16; landscape/horizontal/widescreen=16:9.
L00001088	7) size/resolution:
L00001089	Image keyworded: (?i)\b(?:size|resolution|res)\s*[:=]?\s*(?P<size_px>512|768|1024|1152|1280|1536|2048|3072|4096)\s*(?:px|pixels)?\b
L00001090	Image keyworded k: (?i)\b(?:size|resolution|res)\s*[:=]?\s*(?P<size_k>2k|4k|8k)\b
L00001091	Video: (?i)\b(?P<vres>720p|1080p|1440p|2160p|4k)\b
L00001092	Do not treat bare numbers as size unless they are in controls block or trailing comma controls.
L00001093	Envelope mapping: size_px -> size; size_k -> size (2k=2048,4k=4096,8k=8192) plus resolution token; vres -> resolution for video and MUST NOT override size_k-derived resolution for image prompts.
L00001094	ContractRef: ToolID:media.generate, PolicyRule:Decision_Policy.md§2
L00001095	8) duration (video/music only):
L00001096	keyworded: (?i)\b(?:for|duration|length)\s*(?P<secs>\d{1,3}(?:\.\d+)?)\s*(?:s|sec|secs|second|seconds)\b
L00001097	bare (only in controls block or trailing controls): (?i)\b(?P<secs2>\d{1,3}(?:\.\d+)?)\s*(?:s|sec|secs)\b
L00001098	9) format: (?i)\b(?:format|output|export|as)\s*[:=]?\s*(?P<fmt>png|jpg|jpeg|webp|gif|mp4|mov|wav|mp3|flac|pcm16)\b
L00001099	10) voice (tts):
L00001100	voice id: (?i)\bvoice\s*[:=]\s*(?P<voice>[a-z0-9][a-z0-9 _\-]{0,32})\b
L00001101	voice style: (?i)\bin\s+a[n]?\s+(?P<voice_style>[^,.;]{1,40})\s+voice\b
L00001102	11) quality: (?i)\b(?P<qual>draft|standard|high)\b optional phrase mapping. Guard: set only when in controls block or quality-keyword phrase; bare descriptive adjectives in creative prompt MUST NOT set quality.
L00001103	ContractRef: ToolID:media.generate, PolicyRule:Decision_Policy.md§2
L00001104	12) seed: (?i)\bseed\s*[:=]?\s*(?P<seed>\d{1,10})\b
L00001105	13) bpm: (?i)\b(?P<bpm>\d{2,3})\s*bpm\b|\bbpm\s*[:=]\s*(?P<bpm2>\d{2,3})\b
L00001106	14) negative_prompt:
L00001107	explicit: (?is)\bnegative\s+prompt\s*[:=]\s*(?P<neg>"[^"]{1,200}"|'[^']{1,200}'|[^,;\n]{1,200})
L00001108	avoid-clauses (collect all): (?is)\b(?:without|no|avoid)\s+(?P<avoid>[^,.;\n]{1,80})
L00001109	Combine explicit + avoid list (dedupe preserve order).
L00001110	15) prompt cleaning:
L00001111	- If controls block present: remove it.
L00001112	- Remove only matched spans introduced by control keywords (using/model/size/aspect/etc).
L00001113	- Preserve remaining text as the creative prompt.
