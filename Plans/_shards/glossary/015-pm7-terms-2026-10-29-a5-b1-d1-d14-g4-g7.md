## PM7 terms (2026-10-29; A5, B1, D1–D14, G4/G7)

| Term | Meaning and owner |
|---|---|
| Pip | Puppet Master’s mascot/brand and the single agent puppet primitive; one drawing kit, optional chat/onboarding extras only. F3-660/F3-594/SSYS-056. Not the unrelated tour word pip-done. |
| Project box | The title bar’s option A Tab secondary switch menu; Projects view stays primary. F3-661; B1–B6. |
| Processes | Thread Activity domain and platform status item/tab for owner-started processes, scripts, watchers, servers, browser sessions and scheduled work. ACD-505/F3-664. Not To-Dos. |
| Question | Agent needs-you item counted once in Agents and its source group. F3-664. |
| Needs input | A process’s detected current prompt, separate from an agent question but part of the same attention projection. SIR-054. |
| Completion delivery | Per-work agent/user/quiet routing on completion, independent of holds_reply. D9/SIR-054. |
| Lost (work) | Process vanished after owner reconciliation; warning, never an invented clean exit. D8/SIR-054. |
| ObservableWork | The shared owner record for live/queued/finished work and lineage; ProcessFacts is subordinate via subject_refs. SIR-054. |
| Operational Awareness | Owner-derived cross-surface projection of work, agents, processes, ports and freshness, not a view-private runtime. SIR-054. |
| Backgrounded | ObservableWork runtime state. Task means a To-Do item, not a synonym for process or background work. |
| Resources | Third platform work-panel tab: CPU/memory/ports for explicit servers/environments, sampled only while open; no CPU/RAM status-bar item. G4/G8. |
