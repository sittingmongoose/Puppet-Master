## 5.6 Pro Chat Round Controls That Are Not Commands (2026-10-09)

The 5.6 Pro chat round (DL-140 to DL-151) adds no command identity (UI_Command_Catalog UCC-188). This unit records, for this owner, which of its controls are not commands, and the one reuse that replaces a would-be alias, so that no port mints a command for them.

### CS-093 - 5.6 Pro Chat Round Non-Command Controls And The Subagent Open Reuse

**View state (`LOCAL_PRESENTATION`): no command, no event, no catalog row.**
- In Goal Activity Detail: Edit objective, which only swaps in the objective editor, Cancel edit, and the Objective history disclosure. The Goal preview's Edit objective is `cmd.chat.goal.open_editor`.
- A To-Do row's selection and expansion, and Close details.
- Activity Detail's domain tabs, including their icon-only fit (FinalGUISpec F3-616).
- In a subagent's read-only live transcript: a stretch row's toggle, Expand or Collapse, and More details. Its Copy is `cmd.chat.copy_message`.
- Message More and its panel, and a setup sheet's dropdown trigger pressed again.
- Technical details on a setup sheet's Advanced page, the only place it remains (FinalGUISpec F3-617), and Show raw data on a record.
- Hover tags, their press-to-close, and the activity preview dwell are presentation, not actions (UIW-013).

**Draft state.** The Schedule Message send-time track writes the sheet's Date and Time fields; it dispatches nothing of its own.

**Reuse instead of an alias.** Opening a subagent's live transcript is `cmd.agents.open_thread` (UCC-129) with the child run's thread ref, from every opener assistant-chat-design ACD-485 names. There is no chat-local subagent open command or alias. A Subagents preview row routes into Activity Detail as every preview row does.

**Concept demos (`CONCEPT_DEMO_ONLY`, CS-079).** The concept's Demo Studio NieR controls (Plug-in Chips, presets, the background picker and Play reboot moment) and the concept's `nier-*`, `feed-stretch` and `goal-*` action names. NieR Mode itself is a Settings write that the Settings owner owns.
