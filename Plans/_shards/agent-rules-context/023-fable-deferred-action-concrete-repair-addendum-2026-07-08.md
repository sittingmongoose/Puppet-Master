It never panics and never returns a bare string; every outcome is a result. Each `warnings[]` and `errors[]` entry is `{code, source_path?, detail}` where `code` is closed. Warning codes: `project_rules_missing` (a project is set and `.puppet-master/project-rules.md` does not exist; Project rules are omitted), `scoped_agents_skipped` (a scoped `AGENTS.md` was outside the cone or disabled by `scoped_agents_enabled`), `budget_threshold_exceeded` (assembled bytes exceed `request.warn_threshold_bytes` while `<= request.max_bytes`, OR after ARC-029 deterministic truncation the block still exceeds `request.warn_threshold_bytes` while `<= request.max_bytes`, OR after truncation it still exceeds `request.max_bytes` with `request.strict_mode == false`), `truncated` (deterministic truncation per ARC-029 removed illustrative/example sections because raw assembled bytes exceeded `request.max_bytes`; ARC-030 records it). Error codes: `invalid_request` (a typed-request rule below is broken: for example missing/empty `request_id`, `computer_id` or `application_rules_ref`, invalid `caller`, neither `thread_id` nor `run_id`, `project_id` and `project_rules_ref` not present together, missing required `source_revisions[]` entry for `app.agent_rules.application_markdown`, the work Computer's application context, or `.puppet-master/project-rules.md` when a Project is bound, `max_bytes` not an integer `>= 1`, `warn_threshold_bytes` not an integer in `1..=max_bytes`, `strict_mode` not a boolean, or invalid `created_at_utc`), `source_revision_stale` (any source's current revision or presence/absence differs from the entry pinned in `source_revisions[]`; the caller re-resolves the revisions and starts again), `application_rules_unreadable` (the redb settings store or `app.agent_rules.application_markdown` record cannot be opened, read, or decoded as valid UTF-8—including malformed or wrong-type settings payloads or an unreadable/non-UTF-8 pinned bootstrap `AGENTS.md` source—OR the work Computer's applicable application context for `request.computer_id` cannot be resolved, read, or decoded as valid UTF-8), `project_rules_unreadable` (`.puppet-master/project-rules.md`, or an in-cone scoped `AGENTS.md` when `scoped_agents_enabled` is `true`, exists—or its existence cannot be determined because of a filesystem/permission I/O error—and cannot be read or is not valid UTF-8), `budget_exceeded_strict` (`request.strict_mode` is `true` and after ARC-029 deterministic truncation the block is still over `request.max_bytes`). Budget decision from request inputs (`max_bytes`, `warn_threshold_bytes`, `strict_mode`): raw bytes `<= warn_threshold_bytes` yield no budget warning or error; `warn_threshold_bytes < raw_bytes <= max_bytes` emits `budget_threshold_exceeded` (usable); `raw_bytes > max_bytes` runs ARC-029 deterministic truncation (emitting `truncated` when content is removed), after which post-truncation bytes `<= warn_threshold_bytes` are usable with `truncated`, `warn_threshold_bytes < final_bytes <= max_bytes` are usable with `truncated` and `budget_threshold_exceeded`, `final_bytes > max_bytes` with `strict_mode == false` are usable with `budget_threshold_exceeded` (plus `truncated` if trimmed), and `final_bytes > max_bytes` with `strict_mode == true` emit `budget_exceeded_strict` and refuse dispatch. Partial-output decision: the result is usable if and only if `errors[]` is empty. With warnings only, `formatted_block_ref` names the assembled block and the caller prepends it (ARC-010). With any error, `formatted_block_ref` is null, `byte_count` is 0, and the caller must not start the agent run: Orchestrator, Interview and Assistant refuse that dispatch with the first error code as the reason. No caller may fall back to a partial block, for example Everywhere application rules alone when the work Computer's application context is unreadable, or application rules alone when project rules exist but are unreadable. The pipeline does not retry. A read error is evaluated again only when the caller starts again or the user retries; `invalid_request` and `budget_exceeded_strict` stay failed until their input changes.
