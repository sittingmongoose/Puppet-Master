## Numeric policy and proof limits

The accepted typed domain is the existing canonical MessagePack integer range [-2^63, 2^64−1]. Floats, including mathematical integers accepted by stock JSON Schema, refuse through the mandatory DS15 asserted `ds15IntegerDomain` profile. Every family explicitly adopts that profile. It is a custom schema assertion; stock JSON Schema alone does not distinguish numeric lexemes. Shared schemas and codecs stay unchanged. Invalid identity/commitment calls return null; predicates return false; event operations return REFUSE with zero effects before a codec can throw.

Raw JSON ingress rejects `-0` before parsing erases its sign, decimal/exponent forms, nonfinite forms and malformed leading zeros. Programmatic integer zero remains valid and byte-identical; no duplicate digest or invented collision is claimed. Identity, full-value commitment and producer-semantic digest preimages are unchanged. Caller copies of Storage metadata remain outside semantic retry comparison after their representation is validated.
