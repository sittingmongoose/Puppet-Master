# D-M03-A final — `Path.rglob('*.csv')` traversal and error behavior (CPython 3.12.3)

## Recommendation

`Path.rglob('*.csv')` is a sound inventory primitive for ordinary files and dotfiles at every visited depth, but its completeness promise holds only under four governing conditions: (1) CSVs beneath symlinked directories are **absent** (`**` recursion never follows directory symlinks); (2) one unreadable subdirectory **silently removes** its whole subtree while an unreadable root **raises**; (3) case matching follows the platform unless `case_sensitive=` pins it; (4) a broken link named `*.csv` is yielded as a name match, never descended. Do not promise completeness without stating these conditions. Read-only source inspection only; no code executed.

## Material findings (7)

1. **rglob entry → selector chain.** `Path.rglob` (pathcode 1097–1110) prepends `"**"` to pattern parts and yields `selector.select_from(self)`; for `rglob('*.csv')` parts are `("**","*.csv")`. `_make_selector` (82–103): leading `**` with no further `**` → `_RecursiveWildcardSelector`; plain component → `_WildcardSelector`. `_Selector.select_from` (164–171) gates on `parent_path.is_dir()` — a non-dir root yields nothing. `_RecursiveWildcardSelector._iterate_directories` (223–238) yields the root then every directory from `parent_path.walk()` called with defaults, running the `*.csv` successor at each. `_DoubleRecursiveWildcardSelector` (245–257) only dedupes multiple non-adjacent `**`; not reached here.
2. **Directory scanning path.** `_WildcardSelector._select_from` (200–220): `with scandir(parent_path)` snapshot to list (`except OSError: pass`, 206–207); per entry, `dironly` filter via `entry.is_dir()` with no argument (211–215, `except OSError: continue`); name match via `_compile_pattern` = `re.compile(fnmatch.translate(pat), flags).match` (107–109). `Path._scandir` → `os.scandir(self)` (1059–1063). fd discipline witnessed by `test_glob_many_open_files` (pathscan 1950–1965).
3. **Recursive `**` never descends symlinked dirs; explicit `*` dironly positions follow them.** `Path.walk` defaults `follow_symlinks=False` (1112) and classifies with `entry.is_dir(follow_symlinks=False)` (1140): symlink-to-dir lands in `filenames`, never descended; docs confirm (pathdoc 1103–1125). Since `_iterate_directories` calls `walk()` with defaults, `**` recursion never enters symlinked directories. The distinct explicit path calls `entry.is_dir()` with DirEntry defaults (211–215), confirmed from carried osdoc bytes as `follow_symlinks=True` ("a symbolic link pointing to a directory", osdoc 2819–2823). Test evidence: `rglob('*/fileB')` matches through `dirB/linkD`, `linkB`, `dirA/linkC` (pathscan 1900–1905); `rglob('*/')` lists those links as dir matches (1909–1916). **Inventory condition:** CSVs under symlinked dirs are absent from `rglob('*.csv')` but reachable via explicit-component patterns such as `glob('*/x.csv')`.
4. **Dotfiles match.** No dotfile exclusion exists in `_WildcardSelector` (191–220). Carried fnmatch-3.12.3 bytes show `*` compiling to `.*` / atomic `(?>.*?fixed)` groups with no leading-dot rule (lines 74–184). Therefore `rglob('*.csv')` matches `.hidden.csv` at every visited depth, root included. No dotfile-specific glob test exists in the corpus; conclusion rests on compiler bytes, not test witness.
5. **Broken links match by name, are never descended, excluded from dironly positions.** `Path.is_dir` (870–876) returns False only on `_IGNORED_ERRNOS = (ENOENT, ENOTDIR, EBADF, ELOOP)` (line 48) plus ignored winerrors; other OSErrors raise. Docs: False for broken symlink, permission errors propagate (pathdoc 955–961). `rglob('*')` yields `brokenLink`, `brokenLinkLoop`, `linkA` without descending (pathscan 1932–1948). `test_glob_permissions` (1981–1997, 50 dangling + 50 valid links): `*`→100, `*/`→50, `*/fileC`→50. A broken link named `b.csv` is yielded as a match, never descended; carried osdoc bytes confirm `DirEntry.is_dir` catches FileNotFoundError (osdoc ~2840), so dangling entries read False in dironly filters.
6. **Platform and case conditions.** Default `case_sensitive=None` resolves per flavour via the `_is_case_sensitive` normcase probe (58–59, 195–198); `glob`/`rglob` `case_sensitive` keyword added in 3.12 (1081–1097). Docs: typically case-sensitive on POSIX, case-insensitive on Windows, overridable (pathdoc 930–933, 1347–1350). Test: `test_glob_case_sensitive` (pathscan 1876–1887). **Inventory condition:** whether `Z.CSV` is returned for `*.csv` differs by platform unless `case_sensitive=` pins it.
7. **Access errors: unreadable root raises, unreadable subdirectories silently skipped.** Suppression points: selector scandir (206–207), dironly `is_dir` (214–215), walk scandir → `on_error` or continue (1128–1133; `on_error` is None in the rglob path), walk `is_dir` OSError → treated as file (1141–1143). Propagation: top-level `is_dir` gate (169; 870–876; pathdoc 926–928). EACCES/EPERM are not in `_IGNORED_ERRNOS`, so a permission failure on the root propagates while the same failure on a subdirectory suppresses that subtree and its CSVs without raising. **Inventory condition:** completeness is exact only if every reachable subdirectory is listable; one `chmod 0` subdir silently removes its CSVs.

Accepted (re-verified this stage in corpus bytes): selector chain, walk-default no-descend, broken-link match/descend split, case/platform rule, root-raises vs subdir-skipped error rule. ## Proposed discriminating checks (proposed only — none executed)

1. `.hidden.csv` at root and depth 2 → expect both yielded. 2. Symlinked dir containing `x.csv` → expect absent from `rglob('*.csv')`, present via `glob('*/x.csv')`. 3. Broken symlink `b.csv` → expect yielded as match, not descended. 4. `chmod 0` subdir with `y.csv` → expect silently absent, no raise; `chmod 0` root → expect raise. 5. `Z.CSV` on POSIX vs Windows semantics and `case_sensitive=True/False` overrides.
