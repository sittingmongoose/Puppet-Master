## Material findings (7)

1. rglob entry → selector chain (obligation 1). `Path.rglob` (pathcode 1097–1110) prepends `"**"` to pattern parts and yields `selector.select_from(self)`. For `rglob('*.csv')` parts are `("**","*.csv")`. `_make_selector` (82–103): leading `**` with no further `**` → `_RecursiveWildcardSelector`; plain component → `_WildcardSelector`. `_Selector.select_from` (164–171) gates on `parent_path.is_dir()`; a non-dir root yields nothing. `_RecursiveWildcardSelector._iterate_directories` (223–238) yields `parent_path` then every directory from `parent_path.walk()` called with defaults, running the `*.csv` successor at each. `_DoubleRecursiveWildcardSelector` (245–257) only dedupes multiple non-adjacent `**`; not reached here.

2. Directory scanning path (obligation 1). `_WildcardSelector._select_from` (200–220): `with scandir(parent_path)` snapshot to list (fd discipline; `test_glob_many_open_files`, pathscan 1950–1965), `except OSError: pass` (206–207); per entry, `dironly` filter via `entry.is_dir()` with no argument (211–215, `except OSError: continue`), name match via `_compile_pattern` = `re.compile(fnmatch.translate(pat), flags).match` (107–109). `Path._scandir` → `os.scandir(self)` (1059–1063). Conditions: `case_sensitive=None` resolves per flavour via `_is_case_sensitive` normcase probe (58–59, 195–198).

3. Recursive `**` never descends symlinked dirs; explicit `*` dironly positions follow them (obligations 2–3). `Path.walk` defaults `follow_symlinks=False` (1112) and classifies with `entry.is_dir(follow_symlinks=False)` (1140): symlink-to-dir lands in `filenames`, is never descended; docs confirm (pathdoc 1103–1125). Since `_iterate_directories` calls `walk()` with defaults and `on_error=None`, `**` recursion in `rglob('*.csv')` never enters symlinked directories. The distinct explicit path calls `entry.is_dir()` with DirEntry defaults (211–215), now confirmed from primary osdoc bytes: `is_dir(*, follow_symlinks=True)` returns True for "a symbolic link pointing to a directory" (osdoc 2819–2823). In-corpus test evidence matches: `rglob('*/fileB')` matches through `dirB/linkD`, `linkB`, `dirA/linkC` (pathscan 1900–1905); `rglob('*/')` lists those links as dir matches (1909–1916). Inventory condition: CSVs under symlinked dirs are absent from `rglob('*.csv')` but reachable via explicit-component patterns such as `glob('*/x.csv')`.

4. Broken links match by name, are never descended, and are excluded from dironly positions (obligation 3). `Path.is_dir` (870–876) returns False only on `_IGNORED_ERRNOS = (ENOENT, ENOTDIR, EBADF, ELOOP)` (line 48) plus ignored winerrors; other OSErrors raise. Docs: False for broken symlink, permission errors propagate (pathdoc 955–961). In glob: `rglob('*')` yields `brokenLink`, `brokenLinkLoop`, `linkA` without descending (pathscan 1932–1948). `test_glob_permissions` (1981–1997, 50 dangling + 50 valid links): `*`→100, `*/`→50, `*/fileC`→50. Governing dependency confirmed in osdoc bytes: `DirEntry.is_dir` "can raise OSError, such as PermissionError, but FileNotFoundError is caught and not raised" (osdoc ~2840), so a dangling entry reads False in dironly filters. A broken link named `b.csv` is yielded as a match, never descended.

5. Dotfiles match (obligation 2; resolves focused_read unresolved item). No dotfile exclusion exists in `_WildcardSelector` (191–220). `fnmatch.translate` bytes show `*` compiles to `.*` (trailing STAR) or atomic `(?>.*?fixed)` groups with `re.escape` literals and no leading-dot rule (fnmatch-3.12.3.py lines 74–184). Therefore `rglob('*.csv')` matches `.hidden.csv` at every visited depth, root included. No dotfile-specific glob test was found in the corpus; the conclusion rests on inspected compiler bytes, not on test witness.

6. Platform and case conditions (obligation 4). Default `None` → `_is_case_sensitive` platform rule; `glob`/`rglob` `case_sensitive` keyword added in 3.12 (pathcode 1081–1097). Docs: typically case-sensitive on POSIX, case-insensitive on Windows, overridable (pathdoc 930–933, 1334–1359). Test: `test_glob_case_sensitive` (pathscan 1876–1887). Inventory condition: whether `Z.CSV` is returned for `*.csv` differs by platform unless `case_sensitive=` pins it. `rglob` doc states no error semantics of its own; error behavior below is code-inferred from the shared glob/walk machinery.

7. Access errors: unreadable root raises, unreadable subdirectories are silently skipped (obligation 5). Suppression points: selector scandir (206–207), dironly `is_dir` (214–215), walk scandir → `on_error` or continue (1128–1133; `on_error` is None in the rglob call path), walk `is_dir` OSError → treated as file (1141–1143). Propagation: top-level `is_dir` gate (169; 870–876; pathdoc 926–928). Since EACCES/EPERM are not in `_IGNORED_ERRNOS`, a permission failure on the root propagates while the same failure on a subdirectory suppresses that subtree and its CSVs without raising. Inventory condition: completeness is exact only if every reachable subdirectory is listable; one `chmod 0` subdir silently removes its CSVs.
