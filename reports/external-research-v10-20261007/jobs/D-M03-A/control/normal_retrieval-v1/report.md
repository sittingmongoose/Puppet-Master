## Material findings (static, source-linked)

1. Traversal chain (accepted). `rglob(pattern)` prepends one `**` segment and builds `_RecursiveWildcardSelector` via `_make_selector` (single `**`; multiple non-adjacent `**` gives `_DoubleRecursiveWildcardSelector` with dedup). Recursion enumerates directories through `parent_path.walk()` with defaults (`follow_symlinks=False`, `on_error=None`), then applies a leaf `_WildcardSelector('*.csv', dironly=False)` per directory; each scan uses `Path._scandir` → `os.scandir`, entries buffered via `list()` inside the context manager. Top-level `select_from` gates on `parent.is_dir()`; nested scans handle their own `OSError`. (pathcode L1097-1110, L82-105, L223-238, L200-220, L164-171, L1059-1063.)
2. Dotfiles match; symlink recursion does not (accepted, distinct mechanisms). The leaf selector matches `entry.name` against `fnmatch.translate('*.csv')` with no dot-exclusion, so `.hidden.csv` matches wherever its containing real directory is visited. Recursive `**` never descends into symlinked directories because the driving `walk()` runs with `follow_symlinks=False` (dir-symlinks land in `filenames`). Explicit intermediate segments DO follow them: intermediate `_WildcardSelector(dironly=True)` filters with `entry.is_dir()` (default `follow_symlinks=True`). Test contrast is exact: bare `rglob("fileB")` → only `dirB/fileB`, while `rglob("*/fileB")` → also `linkB/fileB`, `dirB/linkD/fileB`, `dirA/linkC/fileB`. (pathcode L191-220, L107-110, L1112-1155; pathscan `test_rglob_common`, `test_walk_symlink_location`.)
3. Broken leaf yielded; broken intermediate skipped (accepted). Leaf matching is name-only with no stat gate, so a broken symlink named `x.csv` is yielded; corpus tests yield `brokenLink`, `brokenLinkLoop` from `rglob('*')` and a 600-char-target `bad_link` from `glob('**/*')`. As an intermediate, a broken link fails `entry.is_dir()` (returns `False`, or raises `OSError` → `continue`) and is never descended into. (pathcode L200-220; pathscan `test_rglob_symlink_loop`, `test_glob_long_symlink`.)
4. Followed directory links, bounded (accepted). An explicit-segment symlink-to-directory IS traversed (`test_glob_permissions`: 100 links → `glob("*/")` yields exactly the 50 pointing at `dirC`; `*/fileC` 50). But `**` recursion is immune to symlink loops precisely because it never follows them (`test_rglob_symlink_loop` terminates with links yielded as names only). No `recurse_symlinks` parameter exists on `glob`/`rglob` at 3.12.3 (signatures take only `case_sensitive`); the only follow-switch in this chain is `walk(follow_symlinks=…)`, which rglob does not set. (pathcode L1081-1110, L1140-1148; pathdoc L1104-1125.)
5. Platform / case conditions (accepted). `case_sensitive=None` resolves per call through `_is_case_sensitive(flavour)` = `flavour.normcase('Aa')=='Aa'`: case-sensitive on POSIX, insensitive on Windows; explicit `True`/`False` overrides. So `*.csv` misses `X.CSV` on POSIX by default, matches on Windows; pin the flag for a portable inventory. `is_dir`/`exists` follow symlinks by default and return `False` (not raise) only for ignored errnos `(ENOENT, ENOTDIR, EBADF, ELOOP)` + documented winerrors; permission errors propagate from those predicates. (pathcode L58-60, L193-198, L852-884, L40-56; pathdoc L930-933, L955-970, L1347-1350.)
6. Access errors silently truncate the inventory (accepted; completeness impact). Nested `_WildcardSelector._select_from` catches `OSError` from `scandir(parent)` with bare `pass` — an unreadable subdirectory contributes zero entries and zero signal. The driving `walk()` likewise `continue`s on `scandir` `OSError` when `on_error is None`, which is how rglob calls it. Entry-level `is_dir()` `OSError` → treated as not-a-directory, skipped. Only the top-level `is_dir()` gate propagates non-ignored `OSError` (doc: glob "propagates" top-level, "suppresses" subsequent). Net: root-unreadable raises; any nested-unreadable silently drops that subtree. rglob exposes no error channel, so callers cannot distinguish "empty" from "skipped". (pathcode L200-207, L210-215, L1128-1133, L1140-1143; pathdoc L926-928, L1098-1102.)
7. Inventory completeness conditions (accepted). `rglob('*.csv')` is complete only if: every needed directory is a real (non-symlinked) descendant readable at scan time; needed names match case rules in force; and results are post-filtered, because leaf hits include broken symlinks, directories named `*.csv`, and symlinks-to-files — `is_file()`/`lstat()` filtering is the caller's job. Symlinked-dir subtrees and unreadable-dir subtrees are missing with no warning. (Follows from 1–6.)

Rejected: "rglob follows symlinked directories recursively" (false at 3.12.3 for `**`); "unreadable subdirectories raise" (false except the top-level gate); "dotfiles are excluded" (no such filter in the selector). Unresolved: exact `fnmatch` leading-dot edge cases beyond `translate('*.csv')` reading (no dotfile test in corpus); Windows junction traversal (documented predicate only, no traversal test in corpus).

T2 symlink recursion: real `d/x.csv` + `link→d`; bare `rglob('x.csv')` expected `[d/x.csv]` only, while `rglob('*/x.csv')` expected to add `link/x.csv` (discriminates `**`-via-walk vs explicit-segment following). T3 broken link: `b.csv→nonexistent` + `d.csv→real-dir`; `rglob('*.csv')` expected to yield `b.csv` as a leaf; `rglob('b.csv/*.csv')` expected empty (leaf-yield vs intermediate-skip). T5 case: `X.CSV` on POSIX; default expected miss, `case_sensitive=False` expected hit (platform-rule witness). T6 loop: `l→.` self-loop; `rglob('*')` expected to terminate with `l` yielded once as a name (loop-immunity witness). Cleanup: restore permissions before removal.
