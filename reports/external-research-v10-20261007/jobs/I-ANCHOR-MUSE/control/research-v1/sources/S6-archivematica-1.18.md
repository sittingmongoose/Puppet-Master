Bounded excerpts:

- Versioning: "Archivematica 1.18.0 is our latest release"; docs list 1.18.0 stable-current, 1.17.1 stable-previous, older legacy; Storage Service 0.24.0 stable-current.
- "Archivematica is a free and open-source digital preservation system that is designed to maintain standards-based, long-term access to collections of digital objects. Archivematica is packaged with the web-based content management system AtoM for access to your digital objects." (Precedent: preservation store and access system are SEPARATE components — cf. brief's public-vs-internal split.)
- "Open source OAIS": "process digital objects from ingest to archival storage and access in compliance with the Open Archival Information System (OAIS) functional model and other digital preservation standards"; code AGPL-3.0, docs CC-BY-SA-4.0.
- Audience fit: "give archivists and librarians with limited technical and financial capacity the tools, methodology, and confidence to begin preserving digital information today" — matches the community archive's affordable/volunteer constraint.
- Method: "thorough OAIS use case and process analysis to synthesize the specific, concrete steps ... from Ingest to Access"; "expanded beyond OAIS to address analysis and arrangement of transferred digital objects into SIPs and allow for archival appraisal at multiple decision points"; steps not automatable "are incorporated and documented into a manual procedure" — system = "technology, people and procedures, not just a set of software tools."
- Docs structure (1.18 root): Getting started (overview: intro/dashboard/technical-architecture/microservices/external-tools/system-requirements; quick-start; troubleshooting incl. error handling/reporting/FAQ), User manual, Administrator manual — i.e. transfer/ingest, archival storage, and access are distinct documented stages, unlike the frozen plan's single tree + copy.
