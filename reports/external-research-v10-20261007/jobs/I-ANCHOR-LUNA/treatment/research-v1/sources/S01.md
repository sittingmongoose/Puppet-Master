## Bounded excerpt

> SQLite supports multiple simultaneous read transactions ... but only one simultaneous write transaction.

## Research use

A local app can atomically commit an inspection change, outbox row, and pull cursor; a single-writer client must handle SQLITE_BUSY.

## Limits

Docs do not establish the app’s power-loss behavior, encryption, OS filesystem durability, or a particular SQLite library version.
