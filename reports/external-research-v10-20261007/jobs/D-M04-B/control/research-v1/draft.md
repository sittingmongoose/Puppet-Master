# D-M04-B bounded research draft

## Recommendation (six obligations)

1. **Land-cover labels — conditional default.** Use Resampling.nearest when each output pixel should inherit one source pixel’s class. It does not invent intermediate class codes, though it can miss a minority class while downsampling. Do not use bilinear, cubic, or average on class IDs: their arithmetic has no label meaning. Rasterio says grid changes require recalculation, there is no universally correct method, and nearest is its default [rasterresample, lines 53–68; rasterio, lines 438–485].

2. **Elevation — choose for the quantity represented.** For a smooth, point-sampled elevation field, bilinear is a conservative starting choice; cubic is another documented continuous-data choice only if edge behavior and output range are checked. If each output cell is intended to represent the mean elevation over its footprint, prefer Resampling.average, subject to a defined nodata coverage threshold. The docs identify bilinear/cubic for continuous data and average for retaining selected numerical properties, but do not prescribe which matches this tile’s sampling semantics [rasterresample, lines 56–68].

3. **Validity is per band and separate from values.** Keep each band’s GDAL-style mask (0 invalid, nonzero—typically 255—valid) distinct; NumPy masked-array masks have the inverse sense [rastermask, lines 4–15, 46–70, 188–216]. For nearest land cover, output validity should follow the selected source pixel. For any footprint aggregation, define whether valid support requires all contributors, any contributor, or a named valid-area fraction; do not silently treat partial coverage as fully valid. Avoid using dataset_mask() as a substitute for two independent masks: its documented nodata fallback ORs band masks, and an existing .msk/alpha/internal mask takes precedence [rastermask, lines 219–236]. Rasterio’s write_mask() applies one mask to all dataset bands, so separate per-band validity may require separate outputs or a format/workflow that preserves it [rastermask, lines 94–124].

4. **Do not assume masked reads exclude invalid contributors from interpolation.** In Rasterio 1.3.10, read(masked=True) first calls _read for values with the chosen resampler, then reads masks with that same resampler and converts the mask result to Boolean [rasterio, lines 631–676; mask I/O at 221–288]. This establishes output-mask construction, not whether GDAL omitted invalid source values inside each interpolation kernel. Set a support/nodata policy explicitly and test a conspicuous invalid sentinel adjacent to valid values; if it bleeds into bilinear/average results, use a nodata-aware warp/weighted procedure or exclude that target under the chosen support threshold. The exact driver/GDAL path remains unproven here.

5. **Bind the transform to the final array shape.** When preserving the same extent without reprojection, compute the output transform from the actual output width and height: Rasterio’s example composes the source transform with scale factors source.width / output.width and source.height / output.height [rasterresample, lines 34–48]. Keep the origin/footprint fixed and scale both pixel basis vectors; the north-up y pixel size remains negative. GDAL defines the affine transform’s origin, pixel width/height, and rotation terms explicitly [geotransform, lines 9–32]. If the read is windowed, base the transform on that window before scaling. Check corner-coordinate equivalence, not just pixel-size metadata.

6. **Limits, alternative, and optional improvement.** These sources do not establish this tile’s class legend, whether elevation values are points or cell means, dimensions/transform/CRS, mask provenance, nodata collision, driver, or runtime GDAL behavior. Inspect those per band before final selection. If land-cover downsampling must represent the dominant area class, a useful alternative is mode/majority aggregation with an explicit tie/coverage rule; verify that the pinned Rasterio/GDAL read path supports it (the docs defer the method inventory to the Resampling class [rasterresample, lines 59–60]). Optional improvement: store validity explicitly rather than reserving a potentially valid code such as zero as nodata; Rasterio documents 8-bit collisions and that a .msk mask can override nodata metadata [rastermask, lines 85–92, 111–124]. Because write_mask() is dataset-wide, preserve differing per-band masks deliberately.

## Proposed discriminating fixtures (not run)

- A tiny categorical raster with labels {0, 1, 2}, a class boundary, and independent valid masks; downsample by nearest and assert every valid output is an input label and its mask follows the selected source pixel. Add a majority/mode case only if pinned-runtime support is confirmed; assert tie behavior and whether a small class survives.
- A continuous ramp/plane plus a very large nodata sentinel, a valid zero, a partial-validity footprint, and an all-invalid footprint. Compare bilinear (point-sample intent) and average (area-mean intent); assert the selected valid-support threshold and that invalid sentinels do not influence accepted outputs.
- Include odd source dimensions and a non-square downsample ratio. Assert actual output shape, preserved outer-corner coordinates/footprint, scaled pixel vectors, and negative north-up y resolution. These tests discriminate method/mask semantics and grid alignment; they are proposals, not results.
