# D-M04-B control critic

## Dispositions

1. **Accepted — categorical label preservation.** Nearest is a conditional default when the target pixel should inherit one source label. It cannot create an arithmetic intermediate label, but downsampling can omit a small class. The draft correctly warns against bilinear, cubic, and average on class codes. A mode/majority alternative is appropriate only for an area-dominance objective and with pinned-runtime support and tie rules verified.
2. **Amended — continuous method is semantics-dependent.** Retain bilinear for smooth point-sampled elevation and cubic only if edge/range behavior is acceptable; retain average only when the output represents a footprint mean. Documentation says there is no universally correct method and calls bilinear/cubic better suited to continuous data, but does not establish this tile’s measurement meaning or an average/nodata policy (rasterresample 1.3.10, lines 56–68).
3. **Amended — mask handling must be explicit.** The draft correctly distinguishes GDAL valid masks (zero invalid, nonzero valid) from NumPy masked-array polarity, notes dataset_mask() can OR per-band masks on its nodata fallback, and notes write_mask() is dataset-wide (rastermask, lines 7–15, 94–124, 219–236). Add that Rasterio 1.3.10 read(masked=True) reads values first, then reads masks with the same resampling and converts the mask result to Boolean (rasterio _io.pyx, lines 631–673). This does not implement a stated all/any/coverage-fraction policy. Read/aggregate validity separately where that policy matters; do not infer support from the Boolean result.
4. **Unresolved — selected runtime nodata behavior.** The code path shows GDALRasterIOEx for values and separate mask reads, but does not prove whether the selected GDAL/driver/kernel excludes nodata or external invalid-mask samples during interpolation. Keep the sentinel/partial-coverage fixture; report no runtime result and do not claim invalid values either do or do not bleed (rasterio _io.pyx, lines 101–115, 631–662).
5. **Accepted — bind grid to actual output shape.** Scale the source or window transform by source-width/output-width and source-height/output-height only when preserving that extent without reprojection; bind metadata to the returned array’s actual dimensions. Check all outer corners/bounds and both pixel basis vectors, including negative north-up y size (rasterresample, lines 34–48; geotransform 3.9.0, lines 13–32).
6. **Accepted — tile-specific uncertainty and optional improvement.** The sources do not establish this tile’s class legend, elevation point-vs-area semantics, CRS/transform, mask provenance, nodata collisions, driver or runtime GDAL behavior. Retain explicit masks as an optional improvement where a sentinel such as zero may also be valid; preserve differing band masks deliberately. Retain proposed discriminating fixtures. Nothing proposed was executed.

No material draft claim is rejected. The main correction is to avoid treating a resampled Boolean mask as an explicit coverage rule. The corrected final below preserves the draft’s supported content and makes this limit actionable.
