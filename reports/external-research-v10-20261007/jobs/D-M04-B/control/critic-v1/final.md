# D-M04-B bounded recommendation

Use a separate, conditional policy for each band. First inspect the tile’s per-band mask and metadata, class legend, elevation measurement meaning, source and target grid, nodata values, driver, and runtime GDAL version. The pinned documentation does not establish these tile-specific facts.

1. **Categorical land cover.** Use nearest when each output pixel should inherit the label of one selected source pixel. It preserves existing class codes, though downsampling may miss a small class. Do not apply bilinear, cubic, or average arithmetic to class IDs. If the intended output is the dominant class by area, consider mode/majority instead only after confirming support in the pinned Rasterio/GDAL path and specifying tie, edge, and valid-coverage rules. Rasterio says no method is universally correct and points to its Resampling enum for the available methods [rasterresample, 1.3.10, lines 56–68].

2. **Continuous elevation.** For a smooth, point-sampled field, bilinear is a reasonable starting choice; use cubic only if edge behavior and output range are acceptable. If each target cell is meant to summarize elevation over its footprint, consider average, with an explicit rule for how much valid source support is required. These are conditional recommendations: the docs do not say whether this tile contains point samples or cell means, nor do they settle its nodata behavior [rasterresample, lines 56–68].

3. **Validity and nodata.** Keep a validity mask per band where bands have different valid regions. Rasterio’s GDAL-style masks use zero for invalid and nonzero (typically 255) for valid; a NumPy masked-array mask has the inverse polarity [rastermask, lines 7–15, 188–216]. Avoid substituting dataset_mask() for independent band masks: when it falls back to nodata metadata it ORs band masks, while an existing .msk, alpha, or internal mask takes precedence. write_mask() applies to all dataset bands, so use separate outputs or a format/workflow that preserves differing masks [rastermask, lines 94–124, 219–236].

   Define output validity separately from value interpolation: for nearest categorical selection, validity may follow the selected source pixel; for aggregation, specify all-valid, any-valid, or a named minimum valid-area fraction. In Rasterio 1.3.10, read(masked=True) reads resampled values and then reads masks with the same resampling before converting them to Boolean [rasterio _io.pyx, lines 631–673]. That Boolean result is not a documented coverage threshold. Do not assume it implements the policy above. The implementation passes value reads through GDALRasterIOEx, but these sources do not establish whether this tile’s driver/kernel excludes invalid contributors. Verify with a sentinel and partial-coverage fixture; if invalid values affect accepted results, use a nodata-aware warp or an explicitly weighted/filtered procedure.

4. **Output grid.** When changing only resolution while retaining the same extent and CRS, compute transform scale factors from source dimensions divided by the actual output width and height; for a window, start with that window’s transform. Bind the written array’s exact shape, transform, and resolution together. If extent or CRS changes, define the target grid explicitly instead of applying scale-only logic. Check all outer-corner coordinates and both pixel basis vectors; GDAL defines the affine origin, resolution, rotation, and north-up negative y pixel size [rasterresample, lines 34–48; geotransform, GDAL 3.9.0, lines 13–32].

**Limits and checks.** The sources do not prove this tile’s class legend, elevation semantics, dimensions, transform/CRS, mask provenance, nodata collisions, driver behavior, or runtime results. A zero value may be valid even when nodata metadata also treats zero as missing; an explicit mask can avoid that collision, but per-band preservation must be deliberate [rastermask, lines 85–92, 111–124].

Proposed fixtures, not executed: (a) a small categorical raster with labels {0,1,2}, a class boundary, independent band masks, nearest selection, and a majority case with tie/coverage assertions; verify valid outputs remain input labels and record whether a minority class disappears; (b) a continuous plane plus a conspicuous invalid sentinel, valid zero, partial-valid and all-invalid footprints; compare bilinear for point intent with average for area-mean intent and assert the chosen support rule and sentinel exclusion; (c) odd dimensions and unequal x/y downsampling, plus a windowed case; assert array shape, preserved bounds, scaled transform vectors, and negative north-up y resolution.

**Optional improvement retained:** prefer explicit validity masks over a potentially colliding 8-bit nodata code when the selected format supports the needed per-band validity model.
