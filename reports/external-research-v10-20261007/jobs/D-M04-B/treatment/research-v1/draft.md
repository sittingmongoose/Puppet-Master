# D-M04-B treatment research draft

## Bounded recommendation

1. **Categorical land-cover band: use nearest-neighbor by default.** It samples an existing class label instead of averaging class codes into values that may name no class. This is conditional on the stored band actually being categorical codes and on the target grid using a compatible class-label interpretation. Rasterio documents nearest as the default and warns that it may not suit continuous data; it does not prescribe a categorical policy. [S1: lines 56–68; S3: lines 438–485] A useful alternative to evaluate is modal resampling only when the output cell is meant to represent its dominant class area; it needs a declared tie rule and confirmation of the selected API’s support. Do not treat class-code averages as class proportions.

2. **Continuous elevation: choose the statistic that matches the measurement.** For a downsampled cell intended to represent mean elevation over its footprint, test average resampling. For a smooth, point-sampled surface where an interpolated value at the output location is wanted, bilinear is a reasonable default; Rasterio explicitly names bilinear and cubic as better suited to continuous data and average when a numerical property should be retained. [S1: lines 56–68] Prefer bilinear over cubic unless tests show cubic’s smoothing/overshoot behavior is acceptable. The sources do not say whether this tile stores point samples, cell means, or another elevation convention.

3. **Make validity a separate, explicit part of the contract.** Preserve per-band validity masks. Rasterio’s GDAL-style masks use zero for invalid and nonzero (typically 255) for valid; masked-array masks have the inverse sense. A .msk, internal mask, alpha, or nodata metadata can determine validity, and the mask documentation warns that valid low values can collide with a declared nodata value in 8-bit data. [S2: lines 4–15, 46–70, 85–92, 219–250; S3: lines 631–673, 1935–1944] Do not infer invalidity from a sample value alone without checking the tile’s flags and mask source.

4. **Do not assume masked reads make interpolation validity-aware.** Rasterio’s selected-release code reads/resamples band values, then separately reads masks using the same resampling setting and converts the result to a boolean mask. [S3: lines 631–673, 836–860, 910–982] That documents the API path, but does not establish that invalid source neighbors are excluded from value interpolation or define a desired partial-coverage rule. For categorical output, require the nearest source sample and its validity to agree. For elevation, resample valid contributors only, and mark output valid only when a declared valid-coverage threshold is met; never let a nodata sentinel participate as an elevation. Test this path because the docs do not guarantee its exact edge behavior.

5. **Bind output dimensions to the georeferencing.** For a same-extent, same-CRS full-raster resize, set output shape and scale the source transform by source_width/output_width and source_height/output_height, as in Rasterio’s example. [S1: lines 34–48] GDAL’s geotransform maps pixel/line corner coordinates (0,0) through (width,height); the top-left pixel center is (0.5,0.5). [S4: lines 9–32] Keep the upper-left origin and any rotation terms consistent with the scaled grid. If cropping or changing CRS, define the target extent/grid separately rather than applying the full-raster formula blindly. Check bounds and pixel-center coordinates to catch half-cell shifts.

6. **Tile-specific uncertainty and proposed fixtures.** The frozen documents cannot establish this tile’s class codebook, elevation sampling meaning, CRS/target grid, per-band mask flags, nodata collision, alpha or sidecar-mask precedence, or whether its stored mask is trustworthy. Inspect those properties before finalizing thresholds. Proposed checks (not run): (a) categorical checkerboard, isolated rare classes, and invalid edges; assert nearest outputs contain only source labels and invalid sources remain invalid; compare modal output only under an explicit dominant-area interpretation and tie rule; (b) elevation constant and planar-ramp fixtures, plus a nodata stripe containing an extreme sentinel; verify constant/ramp behavior and that changing invalid sentinel values cannot affect valid outputs; (c) distinct masks for the two bands, a valid zero-valued cell, and a sidecar/internal-mask case; assert validity follows the selected mask source; (d) odd source/output dimensions and a rotated transform; assert intended bounds, resolution, and pixel-center alignment. An optional improvement is to store output valid-coverage fraction alongside each band and set an explicit threshold, so partially supported elevation cells are visible to downstream users.

## Evidence boundary

This is a source-linked draft from the four frozen Rasterio 1.3.10 / GDAL 3.9.0 captures. The recommendations are conditional; no tile was inspected and none of the proposed checks were executed.
