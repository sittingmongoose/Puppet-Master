# D-M04-B: bounded resampling and mask recommendation

**Scope.** Conditional recommendation from the listed Rasterio 1.3.10 and GDAL 3.9.0 frozen sources. The documentation and wrapper code do not reveal this tile's data semantics or establish its actual edge behavior. No tile was inspected; proposed checks below were not run.

## Contract

1. **Categorical land cover — nearest by default.** If stored values are class codes, nearest samples a source label without creating interpolated code values. Preserve the codebook and choose an output dtype that represents it. Consider modal resampling only if the pinned runtime supports it, the target cell should represent its dominant class, and tie behavior is explicitly defined and checked; the mapped sources do not establish those details. [S1, 56–68; S3, 438–485]

2. **Continuous elevation — choose by measurement meaning.** Use average when a target cell is intended to summarize elevation over its footprint. Use bilinear for a smoothly varying, point-sampled surface when an interpolated location value is intended. Consider cubic only after checking overshoot and edge behavior. Rasterio describes bilinear/cubic as better suited to continuous data and average as useful for retaining a numerical property; it cannot tell whether this band stores point samples, cell means, or another quantity. [S1, 56–68]

3. **Validity and nodata — specify independently of value interpolation.** Inspect each band's mask flags and actual mask source. GDAL-style masks use zero for invalid and nonzero for valid; NumPy masked-array masks invert that sense. Nodata, alpha, internal masks, and sidecar `.msk` masks can differ in precedence; a `.msk` can override nodata metadata, and an 8-bit valid zero can collide with a nodata value. Do not infer validity from sample values alone. [S2, 4–15, 85–92, 111–124, 247–250]

   In this Rasterio wrapper, `read(masked=True)` reads/resamples band values, then separately reads/resamples masks with the same resampling choice. This documents the API path, not whether GDAL excludes invalid contributors from value interpolation or what partial coverage means. For elevation, explicitly exclude invalid contributors, define normalization and a valid-coverage threshold, and prevent nodata sentinels from influencing values. For categorical data, require the chosen source label and its validity to agree. Test these rules on the selected stack. Critically, `write_mask` creates a per-dataset mask; it does not establish preservation of distinct per-band masks. If masks differ, choose and verify an output format/representation that preserves them, or explicitly define a combination policy. Do not silently replace independent masks with `dataset_mask()`. [S3, 631–673, 836–861, 910–982, 984–1076, 1716–1725, 1935–1978]

4. **Bind dimensions to the output grid.** For a same-extent, same-CRS resize of the full raster, set output dimensions and use `T_out = T_src * Affine.scale(W_src/W_out, H_src/H_out)`; this scales pixel size and any rotation terms. Store that transform with the output. For a crop, derive from the source window before scaling; for a CRS or extent change, define the target grid and reproject to it instead. Check bounds and pixel centers: GDAL's transform maps pixel/line corners, with the first center at (0.5, 0.5). [S1, 34–48; S4, 9–32]

5. **Tile uncertainty and proposed checks.** The sources do not prove the class codebook, elevation sampling convention, CRS/target grid, per-band mask flags or trustworthiness, nodata collisions, or sidecar/internal-mask state for this tile. Inspect these before fixing thresholds. Proposed, unrun fixtures: (a) categorical checkerboard, rare labels, invalid edge, and modal ties; assert outputs remain valid source labels and obey validity; (b) elevation constant and planar ramp plus a nodata stripe with varied extreme sentinel; assert expected interpolation and sentinel independence; include partly valid neighborhoods to exercise the threshold; (c) different masks per band, a valid zero, and sidecar/internal-mask precedence; round-trip distinct output masks; (d) odd dimensions, a crop, and rotated affine; assert bounds, resolution, and pixel-center alignment. Optional improvement: store per-band valid-contributor fraction with an explicit threshold so partial elevation support is visible. This fraction is an application-computed diagnostic, not a feature established by these sources.

## Dispositions

Accepted: conditional nearest/continuous choices, transform scaling for the stated grid case, uncertainty and fixtures. Amended: modal alternative, validity-aware resampling, and output mask preservation. Rejected: any implicit guarantee that masked reads exclude invalid contributors or that one `write_mask` preserves distinct band masks. Unresolved: tile properties, runtime mode support/ties, and the desired measurement/coverage semantics.
