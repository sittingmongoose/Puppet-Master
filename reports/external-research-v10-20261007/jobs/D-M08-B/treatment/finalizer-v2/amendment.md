# D-M08-B v2 amendment records

Disposition of each numbered common critique finding, applied to the preliminary draft. The critique is input, not authority; dispositions below retain only claims supported by the pinned primary corpus and identify policy choices separately.

1. **Class labels and resampling — AMEND.** Keep nearest neighbor as a conservative *candidate policy* when the requirement is to select a source class. The pinned guide documents that resizing changes grid and values and that no method is universally correct; it does not prove nearest's categorical behavior or describe majority. Keep the limitation that nearest does not satisfy area-majority or class-coverage requirements. Any such requirement needs a specified aggregation, tie, and invalid-contributor rule. Proposed validation must confirm that output values belong to permitted IDs and obey that rule. [rasterresample]
2. **Class IDs, nodata, and precedence — ACCEPT core; AMEND scope.** Determine validity from per-band metadata/masks and inspect alpha/internal/external masks; never infer invalidity from a numeric class alone. Preserve the valid-value/nodata collision warning. Add that `write_mask()` documents one mask applying across all bands, and a `.msk` sidecar can override nodata interpretation; choose a representation compatible with per-band validity and delivery packaging, then reopen the delivered artifact. `dataset_mask()` precedence includes `.msk`/dataset alpha/internal mask, then RGBA shadow-nodata band 4, then OR of band masks for nodata, else all-valid. [rastermask]
3. **Output validity — ACCEPT as explicit policy; UNRESOLVED as implementation behavior.** For a source-selection policy, propose target-valid iff the selected source cell is valid. For aggregation, specify partial-neighborhood eligibility and exclusion of invalid contributors. Bind whether the product validity is per-band or dataset-wide and explicitly write/verify the output mask. The pinned docs do not establish propagation for every `out_shape`/method/format path; do not claim the policy is already implemented. Require a small-grid write/reopen check for the selected Rasterio 1.3.10 path and actual output format. [rastermask; rasterresample]
4. **Transform/resolution — ACCEPT with target-grid condition.** On a pure resize over the same footprint, use `new_transform = src.transform * src.transform.scale(src.width / out_width, src.height / out_height)`. If bounds or grid differ, derive the affine from that target instead. Check dimensions, pixel basis/resolution, and mapped outer corners. [rasterresample; geotransform]
5. **Continuous-band lead — ACCEPT.** Keep bilinear/cubic as possible choices for genuinely continuous data and average where its numerical properties fit the quantity; state per-band policy and do not apply it to class labels by default. No one method is universal. [rasterresample]
6. **Checks/uncertainty — ACCEPT as proposed, not performed; AMEND coverage.** Preserve the hand-computable class/nodata-collision/external-mask scenario, output mask/metadata reopen checks, transform corner assertions, and separate continuous check. Add partially invalid neighborhoods if offering aggregation, test the actual sidecar/internal-mask packaging and per-band-vs-dataset validity choice, and check allowed class IDs. None of these checks has been executed. Report outcomes only after running them. [rastermask; rasterresample; geotransform]
