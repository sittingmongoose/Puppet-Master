# Categorical raster downsampling: bounded recommendation

Treat each categorical band as class labels. For a requirement that selects a source class, nearest neighbor is a conservative candidate policy because it selects a sampled value rather than interpolating a new class ID. It does not compute area majority or class coverage, and the pinned Rasterio guide does not specify nearest’s categorical behavior or document a majority method. If the requirement is dominant area, define the aggregation method, tie-break, and invalid-contributor rule first; validate that method and assert outputs belong to the permitted class set. **Critique finding 1 — AMEND** the rationale to a policy to validate, not source-proven method behavior. [rasterresample]

Determine validity from the input’s validity metadata and masks, not from the class number alone. Inspect per-band nodata values and masks, dataset-wide alpha/internal masks, and external `.msk` files. GDAL-style valid-data masks use nonzero for valid; NumPy masked-array masks use `True` for invalid. Rasterio’s `dataset_mask()` precedence is: `.msk`, dataset-wide alpha, or internal mask; then band 4 for RGBA with shadow nodata; then the OR of band masks when nodata exists; otherwise all-valid. The 8-bit example shows that nodata metadata can hide legitimate zero-valued cells. A colliding class value therefore needs an explicit validity representation rather than nodata alone. **Critique finding 2 — ACCEPT core; AMEND scope:** `write_mask()` writes one mask for all dataset bands, and the default sidecar can override nodata metadata. Choose a representation compatible with per-band validity and delivery packaging; ensure sidecars are included or use a supported internal representation, then verify on reopen. [rastermask]

Define output validity separately from class selection. For nearest, a defensible proposed policy is valid exactly when the selected source cell is valid. For aggregation, specify whether partially valid neighborhoods qualify and how invalid contributors are excluded. Decide whether validity is per-band or dataset-wide and encode the output mask accordingly; do not assume a data resampling call produces the intended mask. The pinned sources do not establish mask propagation for every `out_shape`, resampling, and output-format path. **Critique finding 3 — ACCEPT as a policy; UNRESOLVED pending the selected path:** settle the implementation behavior with a read/write/reopen check for the chosen Rasterio 1.3.10 path, output format, and packaging. [rastermask; rasterresample]

For a pure resize that keeps the source footprint, scale the source affine transform by the old-to-new width and height ratios, for example `new_transform = src.transform * src.transform.scale(src.width / out_width, src.height / out_height)`. This follows Rasterio’s documented `out_shape` example; the GDAL tutorial explains the affine mapping and that the outer image coordinates run from `(0, 0)` to `(width, height)`. If requested bounds or grid differ from a pure resize, derive the transform from that target instead. Check output dimensions, pixel basis/resolution, and transformed outer corners. **Critique finding 4 — ACCEPT**, retaining that target-grid condition. [rasterresample; geotransform]

Keep continuous bands on a distinct, explicit per-band policy. For genuinely continuous quantities, bilinear or cubic may be better suited than nearest; average may help retain particular numerical properties when those properties match the objective. No method is right for every quantity. Do not apply these suggestions to class IDs by default. **Critique finding 5 — ACCEPT.** [rasterresample]

**Proposed checks (not performed):** use a small hand-computable grid with several class IDs, a legitimate class equal to a misleading nodata value, and a distinct external mask. Assert the chosen categorical rule and permitted output classes; verify output validity, nodata/mask metadata, and reopen behavior. Include partially invalid neighborhoods if aggregation is offered. Exercise the actual per-band or dataset-wide validity choice and sidecar/internal-mask packaging, including whether delivery preserves required sidecars. Check dimensions, pixel basis/resolution, and outer-corner coordinates for both same-footprint resize and any changed target grid. Test any continuous-band method separately. No check has been run, so no result is claimed. **Critique finding 6 — ACCEPT as proposed, AMEND coverage** to include partial neighborhoods and the chosen validity representation and packaging. [rastermask; rasterresample; geotransform]
