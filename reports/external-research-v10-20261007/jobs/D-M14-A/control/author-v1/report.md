# D-M14-A — bounded decision proposal

## Decision and evidence

**F1 — Choose by the meaning of the coarse cell.** For a categorical class raster whose product needs one representative label per target cell, use **Alternative A: nearest source class plus independent validity accounting**. Sample the class band with nearest so each emitted ID is an input ID, and sample the selected validity mask at the same source location so an invalid selected pixel does not become a valid class. Keep total valid-area accounting on the source validity mask; do not estimate area by counting non-nodata class IDs. This is the bounded default for label-preserving display or lookup. For summaries that must describe composition within each coarse cell, choose **Alternative B: overlap aggregation**: accumulate valid source-cell area by class and total valid area within each target cell; return per-class coverage, or emit a dominant class only under an explicit winner, tie, and mixed-cell rule. It is exact by counts for aligned nested equal-area grids; otherwise compute footprint overlaps/area weights. B answers a different product question and costs more work. Rasterio says changing grid changes values and there is no universally correct resampling method [S2, “Up and downsampling”; “Resampling Methods”]. The choice is conditional on what a coarse label means, not on a library default.

**F2 — Define validity independently of the pixel value.** A GDAL/Rasterio valid-data mask uses nonzero (commonly 255) for valid; a NumPy masked-array mask uses True for invalid. read_masks(band) is per-band; read(band, masked=True).mask is its inverse. An external .msk, dataset-wide alpha, or internal mask takes precedence in dataset_mask(); otherwise the documented dataset-mask fallback uses RGBA alpha, then the binary **OR** of nodata-derived band masks, or all-valid when no nodata is declared [S1, “Reading dataset masks”; “NumPy masked arrays”; “Dataset masks”]. For a selected class band, default to that band's mask. For a multi-band product, explicitly select selected-band, all-bands-valid (AND), any-band-valid (OR), or dataset-wide semantics; do not silently treat dataset_mask() as an all-bands rule. If an external mask says a value equal to declared nodata is valid, preserve that mask decision: the docs say a .msk causes Rasterio to ignore nodata metadata for returned masks, without changing data values or nodata metadata [S1, “Writing masks”; “Nodata representations in raster files”]. Therefore class ID 0 is valid when its chosen mask says valid; nodata equality alone is not a safe validity test.

**F3 — Apply the alternatives to the same declared inputs.** Both paths require a declared target grid (shape, transform, CRS) and a validity policy from F2. In A, nearest preserves sampled labels but can omit rare classes; it does not mean “dominant class.” Summarize source-valid area separately, or expose a separate target-cell coverage result if requested. In B, class fractions expose mixtures; a single winner discards that information and needs an explicit tie/threshold rule. Do not bilinearly or cubically interpolate class IDs. The supplied resampling guidance only says nearest may be unsuitable for continuous data and identifies bilinear/cubic and sometimes average for continuous values; it does not name a categorical majority rule [S2, “Resampling Methods”]. Do not generalize the mask tutorial’s empirically selected sieve size as a repair policy [S1, “Writing masks”].

**F4 — State what “area” means.** Always report valid-pixel count and the chosen validity policy. If physical area is required, use the affine cell footprint: for coefficients in the GDAL geotransform, the planar cell area is **abs(GT(1)*GT(5) - GT(2)*GT(4))** in squared coordinate units; this follows from the documented affine basis vectors [S4, “Transformation from image coordinate space to georeferenced coordinate space”]. Multiplying count by this constant is appropriate only when the source grid and area model make that constant meaningful. Geographic-coordinate degrees are not an area unit; choose a geodesic or suitable projected-area method and state it. The supplied tutorial defines affine mapping and pixel-corner/center convention but does not prescribe CRS area calculations, reprojection, or overlap weighting [S4]. Do not call a pixel count “area” without this choice.

**F5 — Preserve grid geometry and bounded processing.** Reading to a different out_shape is resampling; update the output transform to match the new shape [S2, “Up and downsampling”]. Pixel/line coordinates describe pixel corners from (0,0) to (width,height), with the first center at (0.5,0.5) [S4, “Transformation…”]. For large inputs, process windows/blocks and carry the matching window transform; Rasterio notes window reads may fetch whole underlying blocks and bands can have different block shapes, so check that assumption before sharing windows [S3, “Window transforms”; “Blocks”]. These are implementation safeguards, not executed checks.

**F6 — Retain one optional continuous-band extension.** The same module may offer an opt-in continuous-band path: bilinear/cubic when interpolation is intended, or average when retaining numerical properties is desired [S2, “Resampling Methods”]. Keep it separate from categorical classes and validity summaries. The supplied docs do not define the desired nodata kernel behavior or guarantee conservation, so this remains an opportunity requiring its own product semantics and validation, not part of the default decision.

**F7 — Proposed validation and open choices.** Proposed, **not executed**, checks: (1) fixture with declared nodata 0 but an external .msk marking a zero-valued class valid; assert values remain unchanged and reported validity follows the selected mask; (2) disagreeing band masks, comparing selected-band, AND, OR, and dataset_mask() behavior; check NumPy-mask inversion; (3) nearest output contains only valid input class IDs, while an aggregation fixture verifies class-area totals, invalid-area exclusion, ties, no-valid cells, and the chosen mixed-cell rule; (4) aligned nested-grid valid counts/areas against hand-computed totals, plus a rotated affine and partial edge/window case to check transforms and area method; (5) a continuous-band fixture demonstrating the chosen resampling and nodata policy. Product decisions still open: all/any/selected-band validity; whether an external mask is authoritative for this product; target grid; source-total versus per-target-cell summaries; nearest versus class fractions/dominant class, ties and mixed-cell thresholds; area unit/CRS method; and class/nodata collisions. The sources establish mask/resampling mechanics but cannot answer these choices.
