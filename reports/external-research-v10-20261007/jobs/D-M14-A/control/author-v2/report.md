# D-M14-A / control / author-v2 — decision proposal

**Scope:** one Rasterio 1.3.10 module for class-ID downsampling and valid-area summaries, conditional on an aligned source grid.

## Decision view with evidence

### 1. Establish validity from the intended mask, not from a second nodata comparison

Use the class band's GDAL-style validity mask (read_masks(class_band); nonzero means valid); NumPy masked-array True means invalid. Do not also discard every value equal to the nodata metadata value: Rasterio documents that a .msk sidecar can override nodata metadata, so a value equal to the sentinel can still be valid under the active mask. Use dataset_mask() only when its dataset-footprint semantics are intended. In 1.3.10 it prefers a per-dataset mask, then a fourth alpha band in the stated case, otherwise ORs band masks when nodata exists, and returns all-valid if no nodata is declared; that OR can differ from the class band's own validity in a multiband product. [R1, “Reading dataset masks,” “Dataset masks,” “Numpy masked arrays,” “Nodata representations”; R5, lines 742–770 and 984–1077.]

### 2. For a footprint summary, prefer an explicit windowed vote over valid class IDs

When the output cell represents an aligned, same-CRS, integer-factor footprint and the product wants one summary label, tally only source class IDs whose selected class-band mask is valid. Emit the most frequent label and a separate valid-coverage fraction; mark a cell invalid when it has no valid contributors. This preserves IDs and makes the mask rule explicit. A vote suppresses minority labels, so use a per-class composition/count summary instead if their presence must remain visible. Define a tie rule (for example, configured priority or a schema-approved mixed/ambiguous class) and any minimum-coverage threshold as product choices; do not infer semantics from numeric ID order. Rasterio supports Resampling.mode, defined as selecting the most frequent sampled value, but the cited enum does not specify tie handling or whether invalid contributors are excluded under the chosen mask. Treat built-in mode as an optimization only after item 6 pins mask and tie behavior for the deployed format/runtime. [R2, “Resampling Methods”; R3, “Windows,” “Reading,” “Blocks”; R5, lines 742–770; R6, lines 44–108.]

### 3. Keep nearest-neighbor as the bounded alternative for representative-sample semantics

If each coarse cell is meant to report the class at one representative source location (rather than aggregate its footprint), nearest-neighbor downsampling is the simpler alternative. Read the class and its mask at the same target grid/sampling locations; it returns an existing label, but can omit minority classes lying between sampled locations. It is suitable only when that sample meaning is accepted; it is not a footprint composition or area estimate. Do not use interpolating methods such as bilinear/cubic for IDs. Rasterio describes nearest as the default and cautions that grid changes have no universally correct method. [R2, “Up and downsampling,” “Resampling Methods”; R5, lines 742–770.]

### 4. Compute valid area independently from the coarse class label

Build summaries from the full-resolution validity mask and declared AOI, not coarse labels. On an equal-area projected grid with identical affine cell footprints, sum valid source-cell areas (converting CRS units as needed). For geographic or otherwise nonuniform ground areas, use an explicit ground-area method, such as geodesic cell areas or an appropriate equal-area grid, and define how partial AOI-edge cells count. Keep valid-pixel count/coverage distinct from physical area. GDAL's transform tutorial maps pixel/line coordinates to georeferenced coordinates (including rotation); it does not define a ground-area calculation, CRS choice, or AOI-edge convention. [R1, “Dataset masks”; R4, “Geotransform Tutorial.”]

### 5. Retain one separate continuous-band lead

For a continuous band, evaluate bilinear/cubic interpolation or average when its numerical meaning is appropriate; keep that branch separate from class IDs. Rasterio notes nearest may not suit continuous data and says average can help retain certain numerical properties, but does not choose the scientific meaning, mask policy, or area model for this pipeline. [R2, “Resampling Methods”; R6, lines 44–108.]

### 6. Proposed validation and unresolved product choices

**Proposed, not executed:** create tiny fixtures for nodata-only validity, an external .msk that marks a nodata-valued pixel valid and a non-sentinel invalid, and distinct per-band masks. Assert mask polarity, .msk precedence, and no accidental band-mask OR. On a known pattern with a rare class, tie, all-invalid footprint, and partial edge window, compare explicit counts/coverage with hand results and mode/nearest outputs under Rasterio 1.3.10 plus deployed GDAL/driver. Compare window/block processing with an in-memory reference and target transform; check area against constant-area and independent nonuniform-area references. No code or fixture was run.

**Decisions still needed:** footprint vote versus representative sample; tie policy; minimum valid coverage; whether minority classes require per-class counts; class-band versus dataset-footprint mask for multiband inputs; CRS/physical-area method and AOI-edge convention; and the continuous-band method. The sources establish API and coordinate/mask distinctions but do not choose these product semantics. [R1–R6.]
