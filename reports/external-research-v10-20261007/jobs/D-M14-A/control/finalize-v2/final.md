# D-M14-A / control / finalize-v2 — decision view

**Decision.** For an aligned, same-CRS, integer-factor footprint summary, prefer an explicit valid-only class tally with a separately reported valid-coverage fraction, subject to the product choices below. Use nearest-neighbor only when the intended meaning is a representative sampled location. Neither is a universal class rule. Compute physical valid area independently from the coarse class label.

## Findings and evidence

### 1. Define validity from the selected mask

For a class band, use its GDAL-style per-band validity mask (`read_masks(class_band)`): nonzero is valid. A NumPy masked-array mask has the inverse polarity (`True` is invalid). Do not additionally reject every raw value equal to `nodata`: Rasterio documents that an external `.msk` mask takes precedence over nodata metadata, so the active mask can mark a sentinel-valued pixel valid; conversely, a non-sentinel value can be invalid. Its 8-bit example also shows that valid values rounded to zero can be confused with declared nodata. `dataset_mask()` expresses a dataset footprint, not necessarily the selected class band: documented precedence is a `.msk`, dataset-wide alpha or internal mask; then the fourth band in the stated RGBA/shadow-nodata case; then the OR of band masks if nodata exists; otherwise all-valid. That OR can differ from a class band’s mask. Choose it only when those dataset semantics are intended. [S1: “Reading dataset masks,” “Numpy masked arrays,” “Dataset masks”; S5: `read_masks` and `dataset_mask` implementation locators.]

### 2. Alternative A — footprint vote (recommended conditionally)

When each output cell summarizes an aligned source footprint, tally only class IDs whose selected class-band mask is valid. Emit the most frequent ID, valid-contributor fraction, and invalid status when there are no valid contributors. A vote hides minority classes; if their presence matters, report per-class counts/composition instead. Set tie behavior (for example, schema-approved priority or mixed/ambiguous class) and any minimum-coverage threshold explicitly; numeric ID order has no inferred meaning. Rasterio names `Resampling.mode` as selecting the most frequent sampled value, but the cited docs and enum do not settle tie handling or exclusion of invalid contributors for this input/driver. Treat built-in mode as an optimization only after tests pin those behaviors for the deployed format/runtime. Windowed/block processing can bound working arrays and support large inputs, but small windows may still read whole storage blocks (or an unchunked dataset); verify band block-shape assumptions and benchmark the actual driver. [S2: “Resampling Methods”; S3: “Windows,” “Reading,” “Blocks”; S5: mask locators; S6: enum definitions.]

### 3. Alternative B — nearest representative sample

If a coarse cell is meant to report the class at one representative source location, nearest-neighbor on the target grid is the simpler bounded alternative. Read/sample the class and its validity mask at the same locations. It returns an existing label but can miss minority classes between samples; it is neither footprint composition nor an area estimate. Do not interpolate class IDs with bilinear/cubic methods. Rasterio explains that changing grid size resamples values and that there is no universally correct method; its example rescales the affine transform with output shape. [S2: “Up and downsampling,” “Resampling Methods”; S5: `read_masks`; S6: enum definitions.]

### 4. Keep valid-area summaries independent

Build validity summaries from the full-resolution chosen mask intersected with the declared AOI, not from downsampled labels. For uniform footprints on a suitable equal-area projected grid, sum valid cell areas and convert squared CRS units as needed; retain valid-pixel count/coverage separately from physical area. For geographic or otherwise nonuniform ground areas, use an explicit ground-area method (such as geodesic cell areas or an appropriate equal-area grid). Define treatment of partial AOI-edge cells. GDAL’s affine transform maps pixel/line coordinates to georeferenced coordinates and includes rotation terms; it does not select a CRS, area method, or AOI-edge convention. [S1: “Dataset masks”; S4: “Geotransform Tutorial.”]

### 5. Optional continuous-band lead

Keep continuous data on a separate branch: consider bilinear/cubic interpolation or average when its numerical meaning fits. Rasterio cautions nearest may not suit continuous data and notes average can preserve certain numerical properties; these sources do not decide the scientific meaning, validity policy, or area model for this pipeline. [S2: “Resampling Methods”; S6: enum definitions.]

### 6. Proposed checks and open choices

**Proposed, not executed:** use small fixtures for nodata-only validity, an external `.msk` marking a nodata-valued pixel valid and a non-sentinel invalid, and distinct per-band masks; assert mask polarity, `.msk` precedence, and no accidental band-mask OR. For a known pattern containing a rare class, tie, all-invalid footprint, and partial edge window, compare explicit counts/coverage with hand results and mode/nearest on Rasterio 1.3.10 plus the deployed GDAL/driver. Compare window/block output with an in-memory reference and verify target transform. Check area against constant-area and independent nonuniform-area references. No code, fixtures, or runtime comparison was executed for this delivery.

**Product choices still open:** footprint vote or representative sample; tie policy; minimum valid coverage; whether to expose per-class counts; class-band or dataset-footprint mask for multiband inputs; CRS/physical-area method and AOI-edge convention; continuous-band method. The references document APIs, masks, resampling tradeoffs, storage windows, and affine coordinates; they do not choose these product semantics.
