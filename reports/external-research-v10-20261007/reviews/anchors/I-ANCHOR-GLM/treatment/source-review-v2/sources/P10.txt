393: Success Criterion 1.3.4 Orientation
394: Understanding Orientation |
395: How to Meet Orientation
396: (Level AA)
397: Content does not restrict its view and operation to a single display orientation, such as portrait or landscape, unless a specific display orientation is essential.
398: Note
399: Examples where a particular display orientation may be essential are a bank check, a piano application, slides for a projector or television, or virtual reality content where content is not necessarily restricted to landscape or portrait display orientation.

860: Success Criterion 2.5.5 Target Size (Enhanced)
861: Understanding Target Size (Enhanced) |
862: How to Meet Target Size (Enhanced)
863: (Level AAA)
864: The size of the target for pointer inputs is at least 44 by 44 CSS pixels except when:
865: Equivalent
866: The target is available through an equivalent link or control on the same page that is at least 44 by 44 CSS pixels;
867: Inline
868: The target is in a sentence or block of text;
869: User Agent Control
870: The size of the target is determined by the user agent and is not modified by the author;
871: Essential
872: A particular presentation of the target is essential to the information being conveyed.
883: All functionality that uses a dragging movement for operation can be achieved by a single pointer without dragging, unless dragging is essential or the functionality is determined by the user agent and not modified by the author.
884: Note
885: This requirement applies to web content that interprets pointer actions (i.e., this does not apply to actions that are required to operate the user agent or assistive technology).
886: Success Criterion 2.5.8 Target Size (Minimum)
887: Understanding Target Size (Minimum) |
888: How to Meet Target Size (Minimum)
889: (Level AA)
890: New
891: The size of the target for pointer inputs is at least 24 by 24 CSS pixels, except when:
892: Spacing
893: Undersized targets (those less than 24 by 24 CSS pixels) are positioned so that if a 24 CSS pixel diameter circle is centered on the bounding box of each, the circles do not intersect another target or the circle for another undersized target;
894: Equivalent
895: The function can be achieved through a different control on the same page that meets this criterion;
896: Inline
897: The target is in a sentence or its size is otherwise constrained by the line-height of non-target text;
898: User Agent Control
899: The size of the target is determined by the user agent and is not modified by the author;

1115: One of the following levels of conformance is met in full.
1116: For Level A conformance (the minimum level of conformance), the web page
1117: satisfies all the Level A success criteria, or a conforming alternate version is provided.
1118: For Level AA conformance, the web page satisfies all the Level A and Level AA success criteria, or a Level AA conforming alternate version is provided.
1119: For Level AAA conformance, the web page satisfies all the Level A, Level AA and Level AAA success criteria, or a Level AAA conforming alternate version is provided.
1120: Note 1
1121: Although conformance can only be achieved at the stated levels, authors are encouraged to report (in their claim) any progress toward meeting success criteria from all levels beyond the achieved level of conformance.
1122: Note 2
1123: It is not recommended that Level AAA conformance be required as a general policy for entire sites because it is not possible to satisfy all Level AAA success criteria for some content.
1124: 5.2.2 Full pages
1125: Conformance (and conformance level) is for full web page(s) only, and cannot be achieved if part of a web page is excluded.
1126: Note 1
1127: For the purpose of determining conformance, alternatives to part of a page's content are considered part of the page when the alternatives can be obtained directly from the page, e.g., a long description or an alternative presentation of a video.
1128: Note 2
1129: Authors of web pages that cannot conform due to content outside of the author's control may consider a Statement of Partial Conformance.
1130: Note 3
1131: A full page includes each variation of the page that is automatically presented by the page for various screen sizes (e.g. variations in a responsive web page). Each of these variations needs to conform (or needs to have a conforming alternate version) in order for the entire page to conform.
1132: 5.2.3 Complete processes
1133: When a web page is one of a series of web pages presenting a process (i.e., a sequence of steps that need to be completed in order to accomplish an activity), all web pages in the process conform at the specified level or better. (Conformance is not possible at a particular level if any page in the process does not conform at that level or better.)
1134: Example
1135: An online store has a series of pages that are used to select and purchase products. All pages in the series from start to finish (checkout) conform in order for any page that is part of the process to conform.
1136: 5.2.4 Only Accessibility-Supported Ways of Using Technologies
1137: Only accessibility-supported ways of using technologies are relied upon to satisfy the success criteria. Any information or functionality that is provided in a way that is not accessibility supported is also available in a way that is accessibility supported. (See Understanding accessibility support.)
