1114: Note: Virtual A/B updates have
1115: replaced Legacy A/B system updates in Android 10.
1116: Legacy A/B system updates, also known as seamless updates , ensure a workable booting system
1117: remains on the disk during an
1118: over-the-air (OTA) update. This approach reduces the
1119: likelihood of an inactive device after an update, which means fewer device replacements and
1120: device reflashes at repair and warranty centers. Other commercial-grade operating systems such
1121: as ChromeOS also use A/B updates
1190: A/B system updates use two sets of partitions referred to as
1191: slots (normally slot A and slot B). The system runs from the current slot
1192: while the partitions in the unused slot are not accessed by the running system during
1193: normal operation. This approach makes updates fault resistant by keeping the unused slot as a
1194: fallback: If an error occurs during or immediately after an update, the system can rollback to
1195: the old slot and continue to have a working system. To achieve this goal, no partition used by
1196: the current slot should be updated as part of the OTA update (including partitions
1197: for which there is only one copy).
1198: Each slot has a bootable attribute that states whether the slot contains a correct

1393: After rebooting, update_verifier triggers the integrity check using dm-verity.
1394: This check starts before zygote to avoid Java services making any irreversible changes that
1395: would prevent a safe rollback. During this process, bootloader and kernel may also trigger a
1396: reboot if verified boot or dm-verity detect any corruption. After the check completes,

1398: marks the boot successful.
