2146: 6.1.11. script-src-elem
2147: The syntax for the directive’s name and value is described by the following ABNF:
2148: directive-name = "script-src-elem"
2149: directive-value = serialized-source-list
2150: The script-src-elem directive applies to all script requests and
2151: script blocks. Attributes that execute script (inline event handlers) are
2152: controlled via script-src-attr.
2153: As such, the following differences exist when comparing to script-src:
2154: script-src-elem applies to inline checks whose |type| is "script" and
2155: "navigation" (and is ignored for inline checks whose |type| is "script attribute").
2156: script-src-elem’s value is not used for JavaScript
2157: execution sink checks that are gated on the "unsafe-eval" check.
2158: script-src-elem is not used as a fallback for the worker-src directive.
2159: The worker-src checks still fall back on the script-src directive.
