57: Changes in this specific patch release, version 3.46.1 (2024-08-13):
58: Improved robustness while parsing the tokenize= arguments in FTS5.
59: Forum post 171bcc2bcd.
60: Enhancements to covering index prediction in the query planner.
61: Add early detection of over-prediction of covering indexes so that
62: sqlite3_prepare() will return an error rather than just generate bad bytecode.
63: Forum post e60e4c295d22f8ce.
64: Do not let the number of terms on a VALUES clause be limited by
67: double-quoted string literals.
68: Fix the window function version of group_concat() so that it returns
69: an empty string if it has one or more empty string inputs.
70: In FTS5 secure-delete mode, fix false-positive
71: integrity-check reports about corrupt indexes.
72: Syntax errors in ALTER TABLE should always return SQLITE_ERROR. In
73: some cases, they were formerly returning SQLITE_INTERNAL.
