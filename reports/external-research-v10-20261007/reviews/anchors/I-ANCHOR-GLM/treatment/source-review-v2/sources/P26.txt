642: Decompression pitfalls¶
643: The extraction in zipfile module might fail due to some pitfalls listed below.
644: From file itself¶
645: Decompression may fail due to incorrect password / CRC checksum / ZIP format or
646: unsupported compression method / decryption.
647: File system limitations¶
648: Exceeding limitations on different file systems can cause decompression failed.
649: Such as allowable characters in the directory entries, length of the file name,
650: length of the pathname, size of a single file, and number of files, etc.
651: Resources limitations¶
652: The lack of memory or disk volume would lead to decompression
653: failed. For example, decompression bombs (aka ZIP bomb)
654: apply to zipfile library that can cause disk volume exhaustion.
655: Interruption¶
656: Interruption during the decompression, such as pressing control-C or killing the
657: decompression process may result in incomplete decompression of the archive.
658: Default behaviors of extraction¶
659: Not knowing the default extraction behaviors
660: can cause unexpected decompression results.
