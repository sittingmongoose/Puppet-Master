# Independent source evidence

S01–S21 are independent primary checks, not copies of the candidate source notes. Each records an exact URL, version or rolling identity, assessed range/section, retrieval timestamps, raw response SHA-256 and bounded excerpt or locator. Their local hashes are in primary_sources_checked.json. Additional immutable code/API identities and small witnesses establish PouchDB fix/release inclusion and the adapter package version.

retrievals.json preserves each public request, including two failed assumed tag source paths and corrected gzip normalization for ODK. The 9.0.0 tag is a built distribution; release code was read at the full commit SHA from lib/index.js. P06/P07 404s are retrieval-path failures, not component failures. Only corrected ODK text informed the assessment.

Raw-response hashes identify fetched bytes (including compression where applicable); evidence-note hashes identify local note bytes. Parsed line numbers refer to the stated independent normalization; code numbers refer to raw repository files. Section names and immutable URLs are the portable locators. No complete downloaded source body, installer, executable, cloned repository or scratch cache is retained.

Authorized input identities and frozen-note hash checks are separate from scientific correctness. All 22 predecessor note hashes matched their manifest, but no passing grade was inferred from those matches.
