2419: .. function:: mkdir(path, mode=0o777, *, dir_fd=None)
2420: 
2421:    Create a directory named *path* with numeric mode *mode*.
2422: 
2423:    If the directory already exists, :exc:`FileExistsError` is raised. If a parent
2424:    directory in the path does not exist, :exc:`FileNotFoundError` is raised.
2425: 
2426:    .. _mkdir_modebits:
2427: 
2428:    On some systems, *mode* is ignored.  Where it is used, the current umask
2429:    value is first masked out.  If bits other than the last 9 (i.e. the last 3
2430:    digits of the octal representation of the *mode*) are set, their meaning is
2431:    platform-dependent.  On some platforms, they are ignored and you should call
2432:    :func:`chmod` explicitly to set them.
2433: 
2434:    On Windows, a *mode* of ``0o700`` is specifically handled to apply access
2435:    control to the new directory such that only the current user and
2436:    administrators have access. Other values of *mode* are ignored.
2437: 
2438:    This function can also support :ref:`paths relative to directory descriptors
2439:    <dir_fd>`.
2440: 
2441:    It is also possible to create temporary directories; see the
2442:    :mod:`tempfile` module's :func:`tempfile.mkdtemp` function.

2456: .. function:: makedirs(name, mode=0o777, exist_ok=False)
2457: 
2458:    .. index::
2459:       single: directory; creating
2460:       single: UNC paths; and os.makedirs()
2461: 
2462:    Recursive directory creation function.  Like :func:`mkdir`, but makes all
2463:    intermediate-level directories needed to contain the leaf directory.
2464: 
2465:    The *mode* parameter is passed to :func:`mkdir` for creating the leaf
2466:    directory; see :ref:`the mkdir() description <mkdir_modebits>` for how it
2467:    is interpreted.  To set the file permission bits of any newly created parent
2468:    directories you can set the umask before invoking :func:`makedirs`.  The
2469:    file permission bits of existing parent directories are not changed.
2470: 
2471:    If *exist_ok* is ``False`` (the default), a :exc:`FileExistsError` is
2472:    raised if the target directory already exists.
2473: 
2474:    .. note::
2475: 
2476:       :func:`makedirs` will become confused if the path elements to create
2477:       include :data:`pardir` (eg. ".." on UNIX systems).
2478:

2676: .. function:: rename(src, dst, *, src_dir_fd=None, dst_dir_fd=None)
2677: 
2678:    Rename the file or directory *src* to *dst*. If *dst* exists, the operation
2679:    will fail with an :exc:`OSError` subclass in a number of cases:
2680: 
2681:    On Windows, if *dst* exists a :exc:`FileExistsError` is always raised.
2682:    The operation may fail if *src* and *dst* are on different filesystems. Use
2683:    :func:`shutil.move` to support moves to a different filesystem.
2684: 
2685:    On Unix, if *src* is a file and *dst* is a directory or vice-versa, an
2686:    :exc:`IsADirectoryError` or a :exc:`NotADirectoryError` will be raised
2687:    respectively.  If both are directories and *dst* is empty, *dst* will be
2688:    silently replaced.  If *dst* is a non-empty directory, an :exc:`OSError`
2689:    is raised. If both are files, *dst* will be replaced silently if the user
2690:    has permission.  The operation may fail on some Unix flavors if *src* and
2691:    *dst* are on different filesystems.  If successful, the renaming will be an
2692:    atomic operation (this is a POSIX requirement).
2693: 
2694:    This function can support specifying *src_dir_fd* and/or *dst_dir_fd* to
2695:    supply :ref:`paths relative to directory descriptors <dir_fd>`.
2696: 
2697:    If you want cross-platform overwriting of the destination, use :func:`replace`.
2698:
