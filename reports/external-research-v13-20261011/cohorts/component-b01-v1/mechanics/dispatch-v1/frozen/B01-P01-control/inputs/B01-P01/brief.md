Design the backup/export component of a single-user desktop notebook using CPython 3.13.9 and SQLite on local disks. Editing must continue during a manual backup. The database contains notes, tags and attachment references; attachment files live outside SQLite. The user expects a restorable bundle, progress, cancellation, no silently overwritten prior backup, and a clear explanation when a backup fails. Remote synchronization and a server database are outside scope. Backups can be several GiB; memory must not scale with the whole database. Explain consistency across database and attachments, restore checks, security/privacy, competing mechanisms and their operational costs. Deliver a research-backed implementation proposal, not a built application. Preserve useful investigation history and distinguish actual evidence inspection from proposed tests.
