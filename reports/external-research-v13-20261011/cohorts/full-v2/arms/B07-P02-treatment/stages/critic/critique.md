# Independent critic review: accessible recording review annotations

**Run/stage:** B07-P02-treatment / critic  
**Decision status:** review of the investigator proposal against the exact revealed plan and assigned brief. This is not an endorsed final or implementation instruction.  
**Inputs read:** the assigned brief; the complete investigator discovery, draft, source map and source index; the revealed plan and its reveal record.  
**Review method:** coverage-first audit, followed by independent checks of governing standards, pinned library source/docs/tests, official manuals, releases and issue history. Source IDs are preserved in this stage’s source map.  
**Execution status:** the native Goal activation binding check passed before case/source reading. No product code, downloaded code, build, app, audio fixture, browser, screen reader, or external test suite was run here. Proposed tests remain proposals.

## Review summary

The proposal covers every material obligation in the brief and gives a faithful, clause-by-clause disposition of the released plan. Its strongest correction is to reject restoration based on filename and duration. Its second essential correction is to treat milliseconds as a chosen storage/display resolution, not a cross-player guarantee of where playback will land. It also makes time origin explicit, keeps overlaps as separate comments, and preserves a keyboard-only, transcript-free route.

I found no material scope omission that warrants reducing or redirecting the proposal. The major requirements, alternative families, and useful opportunities are all present. The unresolved player, media, accessibility-platform, storage, and source-equivalence choices are honestly identified as owner inputs. One carried ELAN boundary-manual URL appears malformed or unavailable; the matching official guidance is available at a different URL. This is a locator issue, not a rejection of the ELAN comparison.

No consequential factual claim in the reviewed draft needs to be rejected on the evidence checked. The W3C, WHATWG, APG, library, Audacity, and ELAN claims are appropriately bounded. The issue reports are treated as reports, not as general defects or proof that the proposed design has passed validation.

## Source and issue-history assessment

The evidence is appropriately qualified. WaveSurfer 8.0.2 source shows drag and resize defaults and pointer event wiring. Its cited Cypress file covers region creation/removal, pointer-style interactions and stereo/marker cases; the draft only claims that this file does not establish keyboard/screen-reader behavior. The README’s large-file/VBR cautions are framed as risks to measure.

Peaks 3.4.2 API documents optional precomputed local waveform data, custom player integration, multichannel configuration and keyboard controls defaulting off. GitHub lists v3.4.2 as latest stable and v4.0.0-beta.2 as a prerelease; the repository notes ongoing development moved to Codeberg. Issue #573 is still open in the inspected repository view and reports a custom seek/playhead mismatch without establishing the reporter’s library version or a general defect. The draft does not overstate it.

The WaveSurfer 6.6.1 discussion is closed unanswered. The owner suspected a width calculation issue and the reporter said a then-current alpha appeared to resolve it, but no validated 8.0.2 fix was established in that discussion. The draft treats it as a historical long-file alignment test prompt, not an 8.0.2 defect.

Audacity’s current manual supports the tab-separated start/end/text precedent and notes the multi-track export behavior. Its keyboard support page documents keyboard table editing and boundary/mark commands. Issue #5690 remains open in the inspected view, describes versions 3.4.x/3.5 alpha, and shows no linked branch or pull request there. It is correctly used as a reason to test exports, not as evidence that the proposal has a matching bug.

ELAN’s official manual search result and recovered page support typed time entry and annotation navigation. The official EAF 3.0 PDF search extract supports the stated same-tier top-level non-overlap constraint and richer tier constraints. Direct access to the originally supplied boundary URL and PDF failed in this pass; those access limits are recorded in this review source map. The ELAN citation locator should be repaired, but this does not change the comparative conclusion.
