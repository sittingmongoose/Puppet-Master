Design a CPython 3.13.9 CSV import component for a desktop inventory editor. Users receive large CSVs from different vendors. Preview a bounded sample, let users confirm encoding, delimiter, quoting and header mapping, preserve SKU leading zeros and exact text, distinguish empty strings from missing/null values according to an explicit user-selected policy, and import only after validation. Support quoted embedded newlines, ragged rows, useful row diagnostics, cancellation and bounded resource use. Existing inventory must not be partially mutated on failure. Compare inference with explicit configuration, streaming with whole-file loading, and null-preserving alternatives. This is a research proposal, not a live spreadsheet or production import.
