400: Dialects support the following attributes:
401: 
402: 
403: .. attribute:: Dialect.delimiter
404: 
405:    A one-character string used to separate fields.  It defaults to ``','``.
406: 
407: 
408: .. attribute:: Dialect.doublequote
409: 
410:    Controls how instances of *quotechar* appearing inside a field should
411:    themselves be quoted.  When :const:`True`, the character is doubled. When
412:    :const:`False`, the *escapechar* is used as a prefix to the *quotechar*.  It
413:    defaults to :const:`True`.
414: 
415:    On output, if *doublequote* is :const:`False` and no *escapechar* is set,
416:    :exc:`Error` is raised if a *quotechar* is found in a field.
417: 
418: 
419: .. attribute:: Dialect.escapechar
420: 
421:    A one-character string used by the writer to escape characters that
422:    require escaping:
423: 
424:       * the *delimiter*, the *quotechar*, ``'\r'``, ``'\n'`` and any of the
425:         characters in *lineterminator* are escaped if *quoting* is set to
426:         :const:`QUOTE_NONE`;
427:       * the *quotechar* is escaped if *doublequote* is :const:`False`;
428:       * the *escapechar* itself.
429: 
430:    On reading, the *escapechar* removes any special meaning from
431:    the following character. It defaults to :const:`None`, which disables escaping.
432: 
433:    .. versionchanged:: 3.11
434:       An empty *escapechar* is not allowed.
435: 
436: .. attribute:: Dialect.lineterminator
437: 
438:    The string used to terminate lines produced by the :class:`writer`. It defaults
439:    to ``'\r\n'``.
440: 
441:    .. note::
442: 
443:       The :class:`reader` is hard-coded to recognise either ``'\r'`` or ``'\n'`` as
444:       end-of-line, and ignores *lineterminator*. This behavior may change in the
445:       future.
446: 
447: 
448: .. attribute:: Dialect.quotechar
449: 
450:    A one-character string used to quote fields containing special characters,
451:    such as the *delimiter* or the *quotechar*, or which contain new-line
452:    characters (``'\r'``, ``'\n'`` or any of the characters in *lineterminator*).
453:    It defaults to ``'"'``.
454:    Can be set to ``None`` to prevent escaping ``'"'`` if *quoting* is set
455:    to :const:`QUOTE_NONE`.
456: 
457:    .. versionchanged:: 3.11
458:       An empty *quotechar* is not allowed.
459: 
460: .. attribute:: Dialect.quoting
461: 
462:    Controls when quotes should be generated by the writer and recognised by the
463:    reader.  It can take on any of the :ref:`QUOTE_\* constants <csv-constants>`
464:    and defaults to :const:`QUOTE_MINIMAL` if *quotechar* is not ``None``,
465:    and :const:`QUOTE_NONE` otherwise.
466: 
467: 
468: .. attribute:: Dialect.skipinitialspace
469: 
470:    When :const:`True`, spaces immediately following the *delimiter* are ignored.
471:    The default is :const:`False`.  When combining ``delimiter=' '`` with
472:    ``skipinitialspace=True``, unquoted empty fields are not allowed.
473: 
474: 
475: .. attribute:: Dialect.strict
476: 
477:    When ``True``, raise exception :exc:`Error` on bad CSV input.
478:    The default is ``False``.

482: Reader Objects
483: --------------
484: 
485: Reader objects (:class:`DictReader` instances and objects returned by the
486: :func:`reader` function) have the following public methods:
487: 
488: .. method:: csvreader.__next__()
489: 
490:    Return the next row of the reader's iterable object as a list (if the object
491:    was returned from :func:`reader`) or a dict (if it is a :class:`DictReader`
492:    instance), parsed according to the current :class:`Dialect`.  Usually you
493:    should call this as ``next(reader)``.
494: 
495: 
496: Reader objects have the following public attributes:
497: 
498: .. attribute:: csvreader.dialect
499: 
500:    A read-only description of the dialect in use by the parser.
501: 
502: 
503: .. attribute:: csvreader.line_num
504: 
505:    The number of lines read from the source iterator. This is not the same as the
506:    number of records returned, as records can span multiple lines.
507: 
508: 
509: DictReader objects have the following public attribute:
510: 
511: .. attribute:: DictReader.fieldnames
512: 
513:    If not passed as a parameter when creating the object, this attribute is
514:    initialized upon first access or when the first record is read from the
515:    file.
