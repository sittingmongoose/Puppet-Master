571: Examples
572: --------
573: 
574: The simplest example of reading a CSV file::
575: 
576:    import csv
577:    with open('some.csv', newline='') as f:
578:        reader = csv.reader(f)
579:        for row in reader:
580:            print(row)
581: 
582: Reading a file with an alternate format::
583: 
584:    import csv
585:    with open('passwd', newline='') as f:
586:        reader = csv.reader(f, delimiter=':', quoting=csv.QUOTE_NONE)
587:        for row in reader:
588:            print(row)
589: 
590: The corresponding simplest possible writing example is::
591: 
592:    import csv
593:    with open('some.csv', 'w', newline='') as f:
594:        writer = csv.writer(f)
595:        writer.writerows(someiterable)
596: 
597: Since :func:`open` is used to open a CSV file for reading, the file
598: will by default be decoded into unicode using the system default
599: encoding (see :func:`locale.getencoding`).  To decode a file
600: using a different encoding, use the ``encoding`` argument of open::
601: 
602:    import csv
603:    with open('some.csv', newline='', encoding='utf-8') as f:
604:        reader = csv.reader(f)
605:        for row in reader:
606:            print(row)
607: 
608: The same applies to writing in something other than the system default
609: encoding: specify the encoding argument when opening the output file.
610: 
611: Registering a new dialect::
612: 
613:    import csv
614:    csv.register_dialect('unixpwd', delimiter=':', quoting=csv.QUOTE_NONE)
615:    with open('passwd', newline='') as f:
616:        reader = csv.reader(f, 'unixpwd')
617:
