Design a CPython 3.13.9 export component for a desktop media organizer on Linux and Windows. Export a user-selected immutable media file to a chosen directory, optionally replacing an existing file only after explicit confirmation. Source data must remain intact. Files may be several GiB, destinations may be on another volume, and users need progress, cancel and truthful success/failure. Preserve bytes and useful timestamps; disclose unsupported metadata rather than claiming archival fidelity. Explain publication atomicity, crash-durability limits, cleanup, destination races and viable performance alternatives. The deliverable is an implementation proposal with evidence and test plans, not a deployed exporter.
