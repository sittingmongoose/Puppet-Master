# C-P02 — Provisional design for review

The draft keeps originals in a content-addressed media store and records each interview as a collection of tracks. Imported metadata would establish one project timeline; timestamps would initially be converted to milliseconds for display and stored excerpt boundaries. The investigator should examine whether this representation retains sufficient information for the requested inputs, and whether embedded timestamps deserve the authority the draft gives them.

A lightweight inspection component would inventory streams before creating a low-resolution preview. Alignment would be a per-track offset plus an optional drift adjustment. Excerpts, transcript anchors, and comments would refer to project timeline positions rather than container offsets. Updating alignment would automatically recalculate their source positions, while transcript corrections would preserve anchor identifiers. This could make revision convenient, but the semantics of an already approved excerpt need an explicit decision.

For portability, the draft exports a manifest, previews, transcript changes, and named excerpts. Originals would remain external when the receiver already has them, matched by digest and a user-selected search location. The draft currently treats matching digests as enough to resolve all references; investigate metadata, stream identity, unavailable files, and storage trade-offs before accepting that claim.

Compare offset-only and richer alignment models, and compare preview-centered review with source-based playback. Recommend how unsupported streams, changed transcripts, and ambiguous timing should be represented. Give explicit dispositions for the provisional design, supported by primary context and useful public history. Include proposed tests for drift, variable frame rate, relinking, excerpt revision, and interrupted preview generation; label any actually executed fixture checks and their limits.
