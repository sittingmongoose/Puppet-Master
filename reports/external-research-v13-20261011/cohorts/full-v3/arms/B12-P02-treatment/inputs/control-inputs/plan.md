# Tentative exact plan: Cancelable local document-preview jobs

The first design uses a FIFO queue with two worker slots. A new request for a document cancels any older request for that document by setting a shared flag. A worker checks the flag between pages; a child format handler is asked to exit, and shutdown waits until both slots finish. Visible-item requests are inserted at the front, while import jobs are appended. Failed jobs may retry twice.

A cache key is the document path and modification time. Any successful worker writes the preview to that cache entry, then the UI reads it if the document is selected. Progress is the number of pages completed divided by the page count when known; unknown-size jobs show activity. Queue entries are saved after each request, and startup resumes entries not marked complete. Temporary output is renamed into the cache on success.
