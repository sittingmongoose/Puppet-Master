# Independent critique — D-R1-P04-treatment

**Stage:** critic / same-context finalizer  
**Frozen scope:** brief D-P04 and the released revealed plan identified in input-map.json.  
**Review method:** read the complete brief, discovery, draft, source map, exact revealed plan, plan-release record, and carried source index; then reopened governing primary documentation and selected upstream issue/PR pages. No other candidate or campaign material was read.

## Assessment

The investigator package covers the brief and gives an explicit disposition for every released-plan clause. I found no materially wrong source claim in the consequential defaults, deletion semantics, relative-position limits, or cited regression history after checking the governing pages. The central split between layout merge and comment-intent resolution is sound. Its proposals for stable identity, deletion history, unresolved threads, region and connector anchors, privacy, exports, alternatives, and synthetic checks are all within scope.

Two material incompletions affect the product contract: the identity/incarnation terms leave restoration ambiguous, and the stale-replica path needs to preserve and surface old edits rather than make rejection look like the only outcome. Three smaller wording issues concern Automerge conflict visibility, the strength of the Loro prototype ranking, and privacy erasure versus context retention. The final below makes these corrections while retaining all covered goals and leaving product policy open where evidence cannot decide it.

## Adversarial checks: negative, default, limit, and capability claims

| Loro deletion may mean child targets are gone | The Rust 1.16.2 API distinguishes a deleted node from its children: descendants beneath a deleted parent disappear in visible state but are not actually deleted; deleted nodes are enumerable and contains includes them [CRITIC-LORO-RUST-TREE-1.16.2]. | The draft is right not to equate layout visibility with comment existence. Final requires a thread index independent of visible tree traversal and tests a child move concurrent with ancestor deletion. The API is not an audit log or product restore policy. |
| Loro fractional sibling order might be unsuitable | Maintainer analysis describes same-index peer tie-breaking, optional jitter, index resets, interleaving, and says relative ordering can be acceptable where strict sequential semantics are unnecessary [CRITIC-LORO-MOVABLE-TREE-ARTICLE-2024]. | Keep as conditional, not categorical. Product must decide whether layer order is only relative or must preserve stricter intent; test concurrent inserts/moves at the chosen pin. |
| A JavaScript snapshot fix might imply a Rust 1.16.2 defect | The 1.16.4 changelog is for the loro-crdt JavaScript package and describes a JS tree snapshot decoder correction. Preserve/show alternatives before resolution; raw historical retention has separate privacy and storage costs. |
| Yrs GC/defaults or StickyIndex might be unconditional loss/stability | Yrs 0.28.0 defaults to byte offsets and skip_gc=false, whose documented meaning is that commits should try GC. ## Capability-removal and architectural-choice audit

- Rejecting nearest-coordinate reattachment does not require removing suggestions: a UI may show ranked candidates, but selection must remain visible and deliberate. Final preserves that capability.
- Rejecting silent resurrection does not forbid restoration: an authorized person can issue an explicit restore/recreate event with provenance and a new incarnation key. Final preserves it.
- Treating screenshots as insufficient does not remove screenshots: final keeps them as optional previews alongside a semantic manifest and unresolved-target explanations.
- Distinguishing sequence anchors from object anchors does not remove text comments or Yjs/Yrs interoperability. It keeps those mechanisms in their proper subcomponent.
- No source or experiment justifies committing to Loro, Automerge, Yrs, a hosted service, or a server sequencer now. Final retains all as alternatives and makes the initial Loro investigation conditional.
