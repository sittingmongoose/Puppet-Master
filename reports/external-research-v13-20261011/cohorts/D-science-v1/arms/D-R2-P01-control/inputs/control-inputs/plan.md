# D-P05 — Provisional design for review

The draft indexes text chunks identified by document ID, edition number, and ordinal position. Results would show the document title, heading path, and a short highlighted snippet. A citation would store those fields plus the live document URL. The draft assumes the edition field and chunk position let an opener reconstruct what the user saw; inspect revision retention, chunk-boundary changes, and reference alternatives before accepting that assumption.

A permission filter would run before results are displayed. The index would carry team labels, refreshed when a document is reindexed. Cached snippets would remain until the next refresh. Research whether this order and invalidation boundary protect the requested visibility behavior, including stale caches, ranking signals, and edition-specific access.

The initial ranking combines exact terms with semantic similarity. A newer edition would replace its predecessor in ordinary results, while citations could request the older edition from an archive. Removed passages would open the latest related heading and show a warning. Compare this redirect with alternatives that preserve original context or explicitly stop rather than implying the same policy meaning.

Return dispositions for chunk identity, citations, permission handling, edition replacement, and missing-passage behavior, with consequential source evidence. Include an indexing-state model and explain when freshness or visibility is uncertain. Propose tests for heading moves, permission withdrawal, archived editions, conflicting rankings, and removed passages. Distinguish executed toy-corpus checks from proposed production relevance and authorization validation.
