575:     /// Commit the cumulative auto commit transaction.
576:     ///
577:     /// There is a transaction behind every operation.
578:     /// The events will be emitted after a transaction is committed. A transaction is committed when:
579:     ///
580:     /// - `doc.commit()` is called.
581:     /// - `doc.export(mode)` is called.
582:     /// - `doc.import(data)` is called.
583:     /// - `doc.checkout(version)` is called.
584:     ///
585:     /// Note: Loro transactions are not ACID database transactions. There is no rollback or
586:     /// isolation; they are a grouping mechanism for events/history. For interactive undo/redo,
587:     /// use [`UndoManager`].
588:     ///
589:     /// Empty-commit behavior: this method is an explicit commit. If the pending
590:     /// transaction is empty, any previously set next-commit options (message/timestamp/origin)
591:     /// are swallowed and will not carry over.
