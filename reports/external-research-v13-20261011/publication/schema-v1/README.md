# ER13 publication/record contract v1

Prepared mechanics, not executed science. Root alone dispatches, maintains state, commits and pushes. Target public package: `reports/external-research-v13-20261011/` on root's distinct ER13 research branch. This directory contains schemas/docs, not invented native receipts.

Use one primary flat record per each of the 80 queue arm IDs; all repeat/retry/interrupted/support attempts are additional rows with unique IDs. Primary IDs may equal arm IDs. Extras explicitly record `charged_extra`, observed `extra_start_count`, parent attempt and cost category. A reserve start is an actual candidate stage start, not a row, admission or helper invocation. Unknown reserve counts stay null. Never reset T0 across retries. Full/component scopes and original/new judgments remain separate. Unexecuted queue placeholders express allocation only.

`attempt.schema.json` describes the flat arithmetic input. Unknown numeric metrics use JSON null; CSV UNKNOWN is distinct from numeric 0. Provider input includes its cached subset; output includes reasoning subset only where that provider defines it so. `counter_basis` identifies the actual provider/cumulative/export semantics. Goal counters, subscription consumption and billing are parallel observations, never summed with token totals. Currency and subscription unit are mandatory when corresponding values are known. Record independent denominators; do not convert failed or missing finals to a delivery time. PASS means independent complete assigned-scope assessment, including a complete component output when scope is COMPONENT; component PASS does not qualify a complete pipeline.

`dispatch-terminal.schema.json` describes separately saved observation records. Save actual returned native envelopes privately without reconstruction; point to their approved retained hash/body. Public records contain bounded safe IDs, selected observations and evidence pointers. Native provider/account IDs needing privacy normalization use stable public aliases with an explicit private mapping. Do not represent aliases as directly invocable account routes. Public configuration uses documented caller-supplied `AUTHORIZED_PROVIDER_INSTANCE`; preserve actual route judgment separately with safe alias/version. The public runner must accept an actual authorized route at invocation.

Every timestamp is an actually observed timezone-aware UTC timestamp, or null. T0 is the arm's pre-materialization admission boundary, not accepted/start. Nullable `admitted_utc`, `queued_utc`, `setup_start_utc`, `setup_end_utc`, `finish_utc`, `last_artifact_utc` and `quiet_utc` retain other observed boundaries without conflation. `accepted_utc` means actual tool/server acceptance, `start_utc` actual provider start, `terminal_utc` native terminal observation. Capture time is separate from the event's own observed time. Delivery uses the last complete scientific artifact timestamp when genuinely observable, otherwise the specifically named request-to-quiet proxy. Neither root terminal nor a fast FAIL creates successful delivery. Open context lifetime (created to close), provider stage duration (start to terminal), and active provider intervals are distinct.

Flat context records used by `lifetimes.py` have `attempt_id`, unique `context_id`, `stage`, optional `predecessor_context_id`, and nullable `created_utc`, `start_utc`, `terminal_utc`, `closed_utc`, `active_start_utc`, `active_end_utc`. Use actual topology. Negative predecessor-end-to-start is disclosed overlap, not negative waiting. A missing bound makes all-context aggregate unknown, while known intervals remain labeled partial. For multiple active intervals, supply an activity-only row with a unique ID; its unknown residency must not be folded into a complete residency aggregate. Prefer separate invocations for context residence and provider activity.

Freeze full authored investigation, complete criticisms/finals, source bodies/locators, witnesses and failure outputs before independent evaluation; preserve byte hashes and freeze timestamp. Root verifies the evaluator's dispatch is after the freeze. Read-only files plus create-exclusive manifests enforce accidental-overwrite protection, not a claim of tamper-proof storage. Evaluate frozen originals, not privacy-normalized variants. Keep both original and normalized hashes in publication lineage. A path-only/hash-only source pointer is insufficient semantic evidence; publication requires bodies or pinned public references with disclosed access limits.

The public handoff is a separate reviewed redacted edition; its private original remains untouched. Explicit selective-copy manifests must include all necessary science/criticism/evaluation/source evidence, configs, task prompts, executable witnesses, failures and limitations. Filename rules cannot prove semantic coverage or detect every transcript disguise: root reviews the explicit manifest and scans all selected final bytes. Do not copy raw native transcripts, account routing, credentials or machine state. Schema/scan success is not publication approval, scientific validation, native lifecycle proof or affordability evidence.
