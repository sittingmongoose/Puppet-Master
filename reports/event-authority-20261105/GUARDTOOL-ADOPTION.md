# Shared check-11 guard isolation: adoption contract

`scripts/pm_guard_isolation.py` replaces lane-specific inventory, schema/code mutation, duplicate discovery, flip/stay matrix and restoration machinery. It does not replace product validators, source constructors, history recipes or lane fixtures. ATS-003 owns oracle selection; ATS-004 owns truthful automated evidence and gaps. No new ATS unit, family admission or product binding is needed for this repository tool.

## Five-part interface

1. **Schemas:** `SchemaCatalog({absolute_resource_uri: document}, roots=(complete_entry_uri, ...), format_checker=lane_checker)`. Declare every consumed root and its complete document closure, including dormant definitions. Use stable logical URIs, independent of machine/worktree paths. References resolve eagerly with no network retrieval or flattening.
2. **Code:** `AstGuards(name, source_text, original_module.__dict__)`; enumerate `candidates()`, register each atomic rejection with `register(candidate, normalized_code, Invariant(input_field, predicate))`. Supply an evidenced disposition for every other candidate. `require` predicates are recognized by default; `call_predicates={"_guard": 1}` declares another acceptance-predicate argument. Direct raises/returns, individual Boolean clauses, boolean-return predicates, asserts and refusal appends are supported. Source hashes, function, statement, column and predicate fingerprints bind the exact site.
3. **Cases:** `Control(id, complete_value, boundary)` and `Negative(id, complete_value, target_id, expected_code, control_id, source_defect)`. Boundary is `append`, `retry` or `retained_history`. `synthetic` is reserved for the tool's examples/traps. Repeated authored instances need unique IDs, even when their display names repeat.
4. **Runner:** `runner(value, state) -> Outcome.accept() | Outcome.refuse(code)`. Execute the complete boundary, using `state.modules[name]` and `state.schema.validator(entry)` at every enforcement site. Configure schema factories on the cloned module, whose functions share its live namespace. Translate only actual product refusals. Unexpected exceptions remain checker errors. Instantiate fresh per-case model/storage state; do not repair inputs after validation begins.
5. **Proof:** `run(Suite(...), memory=MemoryGate(...))` returns JSON; `markdown(report)` renders the table. CLI: `python3 scripts/pm_guard_isolation.py --adapter path/to/adapter.py:factory --json result.json --markdown result.md --max-rss 1536 --pause-when-low 6 --resume-at 7`. The factory returns a `Suite`. `--self-test` executes the committed trap corpus.

The runnable wiring example is `--adapter scripts/pm_guard_isolation_traps.py:example_suite`. It validates a synthetic complete schema and grants no product or append-path coverage.

Private schema-resource URIs exist only in the proof registry. They are never product identities, EventRecord metadata, registry/admission rows or newly authored event bindings. Source schemas and $ref siblings are not flattened or rewritten on disk.

Case data must be reifiable fixtures: JSON values plus explicitly typed byte strings, tuples or sets where needed by wrong-type/physical cases. Diagnostic hashes preserve types and physical float bits, including signed zero. These hashes never serialize producer payloads, compute product identities or select a history recipe. Arbitrary live objects/callables belong in the adapter, not the case value. Each declared schema root must actually be consumed by the baseline callback.

## Required adapter work

**Construct before execution.** Start with a genuinely accepting complete-path control. Change one owner-defined source invariant, then derive all legitimate observational copies, digests, keys and post-state from that source. Freeze this result before calling the checker. The report exports type-sensitive changed paths and input hashes; several synchronized JSON changes can represent one source defect. A missing-copy negative is not repaired by disabling the copy guard.

**Register predicates, not codes.** Two different fields may have the same refusal code. A compound schema keyword, a shared helper or a structured-value comparison can enforce several predicates. Split those predicates and keep their peers. Generic AST discovery cannot infer the fields hidden inside an opaque helper or a dynamic structured comparison: the lane must expose those atomic sites in its adapter, include the helper's source in the inventory, and retain its complete caller. Parent delegation/composition can be classified as a selector only with evidence naming its separately inventoried child guards. It is not another duplicate enforcement site.

**Resolve every schema.** Inventory is independent of negative execution. It includes scalar bounds, lengths, membership, patterns, formats, each required/dependent member, closure and array assertions, branches, references and boolean schemas. Applicator containers are explicit routing rows; their children carry rejecting assertions. `if`/`contains` matching clauses are selector rows, including referenced selectors; contains counts have separate minimum/maximum guards. `oneOf` exclusivity has its own `oneOf:maxMatches` predicate. Ordinary reference occurrences receive separate field/root/reference-trail identities and private in-memory resources, including mixed logical polarities. Their assertions and reference boundaries are preserved; sibling fields never share a cut. Recursive and dynamic contexts are explicitly unclassified until an adapter supplies a sound occurrence boundary. Do not relabel them proved.

**Classify with evidence.** Unconsumed definitions are reported with the complete declared-root reachability evidence. True/no-op boolean assertions are classified by logical polarity. Any further selector, unreachable or redundant claim must cite the actual source/logic; it appears in JSON for review. A manually waived redundant guard yields PARTIAL, not PASS. Unknown schema vocabulary is unclassified until its semantics and assertion inventory are supplied. Missing format-checker capability is reported as a format-sweep item and validation fails closed. Supply the lane's actual enforced format grammar; the tool creates no new product date/time policy.

**Keep type membership.** Cutting `type` permits a wrong-type witness while preserving same-node const/enum membership on correctly typed inputs. A well-typed foreign enum value must remain rejected. A required cut removes one member; a dependency cut removes one trigger/member pair. A negated assertion is cut at the selected atom with the opposite polarity. Whole compound keywords are not bypasses. The `oneOf` exclusivity cut retains all alternatives and their nonzero-match requirement.

**Prove duplicates explicitly.** Declare `Duplicate(id, sites, invariant, evidence)`. All sites must name the same input field and predicate. Schema occurrence identities include the consumed root, input field and reference trail; use `SchemaCatalog.bind(site_id, invariant, evidence)` only after proving the mapping from that occurrence to the same input field. The tool never unions groups by overlap. Every individual site cut must retain the same defect code, and the combined cut must accept. All unrelated negatives are rerun and keep their exact original refusal. Sharing a code, keyword, helper or enclosing expression proves nothing by itself.

**Read the whole result.** A control refusal, accepted/wrong-code negative, checker error, masked target, changed unrelated refusal, unproved guard or failed restoration fails the proof. Each matrix row executes every negative; `stays` identifies its exact complement in the stable negative universe. There is no instance-result cache or inferred complement. Validator construction alone is cached within an immutable mutation state. The JSON includes duplicate per-site outcomes, classifications, source hashes and complete/partial row markers. Review the declared input-field bindings as well as the behavioral table.

**Preserve history.** Select the retained original's authenticated at-write recipe before validating it. Current-writer rules must not reach retained compatibility/replay-only history. Shared number-domain and format work remains in its sweep; do not introduce a local serializer, number cap or new history edition here.

## Resource and proof limits

One lane/family process at a time. Use `--pause-when-low 6 --resume-at 7 --pause-poll 120 --low-timeout 2700` on Nas1. Sampling pauses below 6 GiB, waits for 7 GiB, and stops only after continuously staying below 6 GiB for 45 minutes. `--max-rss` checks peak process RSS before and after every callback; it is not an allocation sandbox and cannot interrupt a single oversized allocation. Bound large constructors/callbacks by family. Native subprocess memory, external stores and imported mutable services remain the adapter's resource responsibility.

No lane is categorically excluded by the surveyed Python/JSON Schema architecture. **No complete lane adoption or family grade is certified here.** Adapters must expose dynamic/opaque field predicates, include external module guard sources, supply real format checkers and preserve complete paths. Native/compiled guards, closures or class-method internals need explicit adapter seams; the top-level Python AST backend does not pretend to discover them. Recursive/dynamic schema contexts and unknown validation extensions fail closed until given a sound per-occurrence representation. Selector/redundancy declarations and cross-copy input bindings remain reviewable evidence, not an automatic semantic proof.
