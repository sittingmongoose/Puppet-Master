# Shared check-11 guard isolation: adoption contract

`scripts/pm_guard_isolation.py` replaces lane-specific inventory, schema/code mutation, duplicate discovery, flip/stay matrix and restoration machinery. It does not replace product validators, source constructors, history recipes or lane fixtures. ATS-003 owns oracle selection; ATS-004 owns truthful automated evidence and gaps. No new ATS unit, family admission or product binding is needed for this repository tool.

## Five-part interface

1. **Schemas:** `SchemaCatalog({absolute_resource_uri: document}, roots=(complete_entry_uri, ...), format_checker=lane_checker)`. Declare every consumed root and its complete document closure, including dormant definitions. Use stable logical URIs, independent of machine/worktree paths. References resolve eagerly with no network retrieval or flattening.
2. **Code:** `AstGuards(name, source_text, original_module.__dict__)`; enumerate `candidates()`, register each atomic rejection with `register(candidate, normalized_code, Invariant(input_field, predicate))`. Supply an evidenced disposition for every other candidate. `require` predicates are recognized by default; `call_predicates={"_guard": 1}` declares another acceptance-predicate argument. The explicit allow-list below controls automatic cuts. Direct raises/fixed refusal returns, individual Boolean leaves (including nested `not` polarity), transparent Boolean-return predicates, asserts and standalone single-error appends can be cut. Chained comparisons, conditional-expression returns, returned local names, general mutations and opaque calls remain unclassified; registration is refused. Class, nested-function and module-level declared predicate calls and refusal constructions remain explicit unsupported candidates with their enclosing identity and reason. Refusal calls are discovered independently of how their result is used: assigned, annotated or nested refusal calls require an atomic adapter seam and remain unproved unless dispositioned with evidence. Standalone expressions have one candidate. Source hashes, function, statement, column and predicate fingerprints bind the exact site.
3. **Cases:** `Control(id, complete_value, boundary)` and `Negative(id, complete_value, target_id, expected_code, control_id, source_defect)`. Boundary is `append`, `retry` or `retained_history`. `synthetic` is reserved for the tool's examples/traps. Repeated authored instances need unique IDs, even when their display names repeat.
4. **Runner:** `runner(value, state) -> Outcome.accept() | Outcome.refuse(code)`. Execute the complete boundary, using `state.modules[name]` and `state.schema.validator(entry)` at every enforcement site. Configure schema factories on the cloned module, whose functions share its live namespace. Translate only actual product refusals. Unexpected exceptions remain checker errors. Instantiate fresh per-case model/storage state; do not repair inputs after validation begins.
5. **Proof:** `run(Suite(...), memory=MemoryGate(...))` returns JSON; `markdown(report)` renders the table. CLI: `python3 scripts/pm_guard_isolation.py --adapter path/to/adapter.py:factory --json result.json --markdown result.md --max-rss 1536 --pause-when-low 6 --resume-at 7`. The factory returns a `Suite`. `--self-test` executes the committed trap corpus.

The runnable wiring example is `--adapter scripts/pm_guard_isolation_traps.py:example_suite`. It validates a synthetic complete schema and grants no product or append-path coverage.

Private schema-resource URIs exist only in the proof registry. They are never product identities, EventRecord metadata, registry/admission rows or newly authored event bindings. Source schemas and $ref siblings are not flattened or rewritten on disk.

Case data must be reifiable fixtures: JSON values plus explicitly typed byte strings, tuples or sets where needed by wrong-type/physical cases. Diagnostic hashes preserve types and physical float bits, including signed zero. These hashes never serialize producer payloads, compute product identities or select a history recipe. Arbitrary live objects/callables belong in the adapter, not the case value. Each declared schema root must actually be consumed by the baseline callback. Conversely, every requested validator entry must resolve to a declared root occurrence, including requests reached only under a cut. Pointer, anchor and resource aliases are canonicalized by their resolved schema location. An undeclared entry fails the callback and its consumed assertions appear as unproved; add that entry to `roots` and supply its witnesses before rerunning.

## Rule and explicit cut allow-list (round 3)

**Only constructs with an implemented single-predicate cut earn proof credit.** Each automatic guard carries `predicate_count=1` and a named `cut`. Routing/no-op rows carry zero predicates; unknown or unsupported obligations carry an unknown count and no cut. Anything outside the allow-list fails closed as unclassified. A physical AST site or schema keyword is never proof that there is only one predicate. `SCHEMA_CUTS`, `python_atom_reason`, and the committed executable audits define the bounded grammar.

| Construct | Predicates / cut | Scope |
|---|---|---|
| `type` | 1; remove type, keep same-node const/enum for correctly typed inputs | Supported positive context |
| `const`, `enum` | 1 membership/equality predicate each; remove only that assertion | No splitting of enum values into separate rules |
| `minimum`, `maximum`, `exclusiveMinimum`, `exclusiveMaximum`, `multipleOf` | 1 per keyword; remove only that bound/divisibility assertion | Four supported dialects |
| `minLength`, `maxLength`, `minItems`, `maxItems`, `minProperties`, `maxProperties`, `uniqueItems=true` | 1 per keyword; remove only that assertion | Zero lower bounds / uniqueness=false have explicit no-op evidence |
| `required` | 1 per listed member; remove only that member | Peers remain |
| `dependentRequired` / list `dependencies` | 1 per trigger/member pair; remove only that pair | Dialect-correct activation |
| Boolean false | 1; replace only that Boolean schema | Boolean true is a no-op in positive context |
| `contains` counts | 1 per effective lower/upper count; lower cut preserves upper and matcher, upper cut preserves lower and matcher | Draft-06/07 implicit >=1 cuts `contains` itself; ignored min/maxContains spellings do not erase that obligation |
| `oneOf` upper match count | 1 exclusivity predicate; keep alternatives and >=1 match via anyOf | Branch-assertion cuts remain unclassified |
| Same-input `not` over type/const/enum/Boolean | 1; polarity-correct cut of that sole total type/const/enum/Boolean predicate | No applicability, branching, nested not, or multiple child assertions |
| Python one scalar comparison, Boolean input leaf | 1 per leaf; replace only that leaf, respecting and/or/not and short-circuit order | Direct refusal, Boolean return, assert or declared acceptance-predicate helper; structured operands have no automatic cut |
| Python fixed refusal statement / single-error append | 1 per controlling Boolean leaf; skip only that refusal or replace only its leaf | Plain top-level function and at most one direct if-body; loops, else/nested paths and other unsupported ancestors fail closed before registration; append requires one scalar literal error |
| Read-only Python views | 0 new predicates; preserve scalar literals, bound names/attributes/subscripts, len/type, literal-key get, literal-argument encode | Reviewer checks scalar subject binding, standard semantics and absence of overloaded side effects; tuple/list/set/dict displays, starred values, comprehensions and other non-scalar expressions refuse |
| Positive routing / declarations / annotations | 0 at the container; inventory active child predicates | properties, items/tuple items/prefixItems/additionalItems, propertyNames, schema dependencies, allOf/anyOf, if/then/else, ordinary refs; only supported dialect/reachability cases |
| Everything else | Unknown; **no automatic cut; FAIL/unproved** | Patterns (even a simple-looking regex), format grammars, patternProperties, unevaluated coverage, oneOf branches, negative applicability, mixed/dynamic/recursive contexts, unknown vocabulary; Python chains, ternaries, dataflow/returned locals, extend/+=/slice/insert/item writes, unknown calls and unsupported contexts |

The trap corpus executes both audits. Tables describe the bounded cut contract, not a completeness theorem about arbitrary validators. Unsupported original grammar stays unproved; an adapter author must expose separately inspectable atomic seams before requesting broader capability.

The round-4 Python construct census is generated from the running interpreter's concrete `ast.stmt`, `ast.expr`, `ast.boolop`, `ast.cmpop`, `ast.unaryop`, `ast.excepthandler` and `ast.pattern` classes. Every class has a classification in controlling-context, condition, comparison-operand, refusal-value and accumulator-write positions. `--self-test` fails before running traps if a live class or position is unclassified, or the policy names a nonexistent class. `AstGuards` construction also refuses such a census. ## Shared refusal composition (round 5)

`AstGuards._compose_refusal` supplies the predicate set for every raise, refusal return, assertion, accumulator write, refusal helper and predicate helper. The rejection formula contains every enclosing controlling test with its branch polarity, plus failure of the refusal's own acceptance test. Inventory exports this full `composition` and each exact `cut_target`. Cloning applies those targets through one transformer; it never chooses a different test based on the refusal kind.

A literal refusal under a controller contributes no input atom. For example, `if x_bad or y_bad: assert False` has separate x/y obligations and cuts; replacing `False` cannot earn credit. The same rule applies to `assert 0`, fixed return values, raises, appends and helpers. Every component must be supported before any part of that site's composition can register. Structured comparisons, else paths, two-deep nesting, a body shared by multiple statements, or a nonconstant own test combined with a controller require an explicit atomic seam. They remain unclassified before registration. This deliberately conservative scope does not claim general Boolean-formula normalization.

The self-test generates **630 cells**: six census refusal kinds represented by 15 source forms × 14 branch contexts × three two-field controlling forms (`or`, negated `and`, tuple inequality). Contexts include each branch side and every body/else combination nested two deep, with the compound at the outer test, inner test, or both. Every baseline accepts its control and rejects both isolated defects. All **48 credited cuts** in **24 cells** accept exactly their own defect, retain the held-out peer, and pass flip/peer/restoration proofs. The other **606 cells** remain explicitly unclassified and cannot register a cut.

The refusal-kind registry is part of the generated census. A preflight gate compares it and every supported refusal statement/call position and controlling-context class with the executable fixture coverage. New supported kinds or contexts without fixtures fail self-test before the corpus runs. The generated regression also checks every cut directly, even when another obligation already makes the overall suite FAIL; an unrelated FAIL cannot hide an aggregate cut. The four exact C5-B1 source traps separately retain single-negative/held-out-peer and truthful aggregate attempts plus independent narrow sources.

## Reviewer trust decisions on every adoption

`trust_decisions` is present even on PASS reports. Review every listed decision:

- **Complete callback and invocation:** execute the actual append/retry/reader boundary. Merely constructing `state.schema.validator` satisfies only request accounting; it cannot establish that validation ran. A callback must not manufacture outcomes from `state.cuts`.
- **Consumer/input occurrences:** bind distinct schema uses to distinct inputs. Reusing one declared root for envelope and payload makes a cut affect both. Digest equality is not an occurrence binding.
- **Code sources and dynamic subjects:** include helper/module closure, preserve cloned execution, and bind each dynamic subject/input occurrence. Loop contexts now refuse automatic registration; an adapter must expose their predicates separately. Review scalar subject bindings and standard semantics of read-only views. Structured comparisons remain unclassified until component-preserving cuts are available.
- **Refusal translation:** translate actual product refusals only. Catching an AssertionError or internal RuntimeError and translating it hides its origin from the engine. Uncaught exceptions correctly fail.
- **Aliases and duplicates:** review every SchemaCatalog.bind and each same-field/same-predicate declaration. The DC broad/narrow enums remain different predicates. Per-site refusals for one specimen cannot prove that a declared alias is true.
- **Dispositions and contexts:** verify every selector, unreachable, redundant, helper-composition and unsupported-seam declaration against source and the complete boundary. The report lists manual schema/code dispositions, source hashes, predicate bindings, dynamic contexts and duplicate evidence.

## Required adapter work

**Construct before execution.** Start with a genuinely accepting complete-path control. Change one owner-defined source invariant, then derive all legitimate observational copies, digests, keys and post-state from that source. Freeze this result before calling the checker. The report exports type-sensitive changed paths and input hashes; several synchronized JSON changes can represent one source defect. A missing-copy negative is not repaired by disabling the copy guard.

**Register predicates, not codes.** Two different fields may have the same refusal code. A compound schema keyword, a shared helper or a structured-value comparison can enforce several predicates. Split those predicates and keep their peers. Generic AST discovery cannot infer the fields hidden inside an opaque helper or a dynamic structured comparison: the lane must expose those atomic sites in its adapter, include the helper's source in the inventory, and retain its complete caller. Parent delegation/composition can be classified as a selector only with evidence naming its separately inventoried child guards. It is not another duplicate enforcement site.

**Resolve every schema.** Inventory is independent of negative execution. It includes scalar bounds, lengths, membership, patterns, formats, each required/dependent member, closure and array assertions, branches, references and boolean schemas. Supported positive applicator containers have explicit routing rows; their children carry rejecting assertions. This is conditional on the allow-list: oneOf child cuts, unevaluated coverage, patterns, formats, patternProperties, and negative routing are unclassified. Known inapplicable standard keywords have explicit dialect/reachability evidence; unknown vocabulary always needs an adapter. `if`/`contains` matching clauses are selector rows, including referenced selectors; contains counts have separate minimum/maximum guards. `oneOf` exclusivity has its own `oneOf:maxMatches` predicate. Ordinary reference occurrences receive separate field/root/reference-trail identities and private in-memory resources, including logical polarity and activation context. Conditional antecedents, schema-dependency triggers and contains matchers are part of the default predicate identity; same-field count assertions with different matchers cannot become automatic duplicates. Their assertions and reference boundaries are preserved; sibling fields never share a cut. Recursive, dynamic and mixed-dialect contexts are explicitly unclassified until a sound atomic occurrence representation exists. A Classification label alone cannot waive an unclassified schema obligation; its declaration is recorded while the obligation stays unproved. Do not relabel them proved.

**Classify with evidence.** Unconsumed definitions are reported with the complete declared-root reachability evidence. Schema rows retain their resource dialect. In homogeneous evaluation paths, Draft-07 and earlier `$ref` siblings that the validator ignores carry that evidence and have no witness obligation. Mixed-dialect paths require a context-bound adapter: jsonschema can select keywords using the caller's dialect while dispatching the target's handlers. The tool preserves the original graph, inventories all potentially evaluated branches, and marks their assertions unclassified/unproved, including siblings and children a resource-only filter would omit. No mixed-dialect cut or proof clearance is granted. Dynamic targets and their conservative candidate closure are inventoried as context-bound unclassified occurrences, never unreachable merely because dynamic traversal needs an adapter. True/no-op boolean assertions are classified by logical polarity. Any further selector, unreachable or redundant claim must cite the actual source/logic; it appears in JSON for review. A manually waived redundant guard yields PARTIAL, not PASS. Unknown schema vocabulary is unclassified until its semantics and assertion inventory are supplied. Format assertions remain unclassified even when a checker exists; deleting an arbitrary format grammar has no automatic per-clause proof. Missing format-checker capability also makes validation fail closed. Supply the lane's actual enforced format grammar; the tool creates no new product date/time policy.

**Keep type membership.** Cutting `type` permits a wrong-type witness while preserving same-node const/enum membership on correctly typed inputs. A well-typed foreign enum value must remain rejected. A required cut removes one member; a dependency cut removes one trigger/member pair. A same-input negation of one total type/const/enum/Boolean predicate is cut with the opposite polarity. Negated numeric, length, collection, requiredness and dependency assertions also impose their applicability domain and remain unclassified. Negated properties/applicability, conditional routing, nested not and compound negative schema contexts, including `not` over a multi-keyword conjunction or `allOf`, are unsupported and remain unproved before mutation: replacing one child with false would disable the whole conjunction. Supply a sound context-bound atomic adapter seam for those contexts. Whole compound keywords are not bypasses. The `oneOf` exclusivity cut retains all alternatives and their nonzero-match requirement.

**Prove duplicates explicitly.** Declare `Duplicate(id, sites, invariant, evidence)`. All sites must name the same input field and predicate. Schema occurrence identities include the consumed root, input field and reference trail; use `SchemaCatalog.bind(site_id, invariant, evidence)` only after proving the mapping from that occurrence to the same input field. The tool never unions groups by overlap. Every individual site cut must retain the same defect code, and the combined cut must accept. All unrelated negatives are rerun and keep their exact original refusal. Sharing a code, keyword, helper or enclosing expression proves nothing by itself.

**Read the whole result.** A control refusal, accepted/wrong-code negative, checker error, masked target, changed unrelated refusal, unproved guard or failed restoration fails the proof. Each matrix row executes every negative; `stays` identifies its exact complement in the stable negative universe. There is no instance-result cache or inferred complement. Validator construction alone is cached within an immutable mutation state. The JSON includes duplicate per-site outcomes, classifications, source hashes and complete/partial row markers. Review the declared input-field bindings as well as the behavioral table.

**Preserve history.** Select the retained original's authenticated at-write recipe before validating it. Current-writer rules must not reach retained compatibility/replay-only history. Shared number-domain and format work remains in its sweep; do not introduce a local serializer, number cap or new history edition here.

## Resource and proof limits

One lane/family process at a time. Public MemoryGate thresholds must be finite int/float values; NaN and infinities are rejected for every threshold. Use `--pause-when-low 6 --resume-at 7 --pause-poll 120 --low-timeout 2700` on Nas1. Every configured callback-boundary check takes a fresh available-memory sample (there is no one-second throttle). Sampling pauses below 6 GiB, waits for 7 GiB, and stops only after continuously staying below 6 GiB for 45 minutes. `--max-rss` checks peak process RSS before and after every callback, after each pause sample, and before resuming; it is not an allocation sandbox and cannot interrupt a single oversized allocation. Bound large constructors/callbacks by family. Native subprocess memory, external stores and imported mutable services remain the adapter's resource responsibility.

The tool currently cannot grant complete automatic isolation credit to lanes whose active validators contain unsupported grammar. In particular, adoption alone does not close DM C8C-B1: a multi-clause regex stays unproved. No automatic regex or arbitrary format grammar clause splitter is provided. **No complete lane adoption or family grade is certified here.** Adapters must expose dynamic/opaque field predicates, include external module guard sources, supply real format checkers and preserve complete paths. Native/compiled guards, closures or class-method internals need explicit adapter seams; the top-level Python AST backend does not pretend to discover them. Recursive/dynamic schema contexts and unknown validation extensions fail closed until given a sound per-occurrence representation. Selector/redundancy declarations and cross-copy input bindings remain reviewable evidence, not an automatic semantic proof.
