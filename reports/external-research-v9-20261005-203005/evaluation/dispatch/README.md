# Frozen final packet mechanics

`build_blind_packet.py` is run by root/ops after both designated pipeline finals have immutable `er9.stage-output-freeze.v1` receipts and terminal native quiescence. The evaluator does not receive the coordinator binding or private alias sidecar. Receipt presence alone does not designate a research/critic artifact as a final.

The coordinator starts from `I01_TASK_BINDING.json`, fills exactly two `final_freezes` pins and `candidate_outputs_frozen_utc`, and runs the builder with a new anonymous packet directory and a coordinator-owned private sidecar outside that directory. The builder randomly assigns A/B, verifies freeze/task/artifact hashes, copies only `final/{proposal.md,sources.json,witnesses.json,leads.json}` and explicitly selected frozen evidence, and writes `dispatch.json`. It does not open ongoing outputs or provide expected truths. No native receipt, family/cost field, arm map or research/critique stage is placed in Phase 1.

Output bytes remain exact. File locations are anonymous, but prose/catalog content may reveal incidental hints. The evaluator discloses those hints. Additional witness code/input/results or source captures can be copied from the immutable receipt's positive artifact inventory at a neutral request; never substitute mutable candidate workspace files or inject semantic fixes.

External same-arm operation receipts/source captures can be separately frozen by ops. Each `final_freezes` row can include an `evidence_freeze` path/SHA-256 pin to a JSON manifest using `er9.blind-evidence-freeze.v1`, `candidate_output_freeze_sha256` bound to this exact final freeze, and a positive `files` list. Each file has anonymous `relative_path`, actual `path`, `sha256`, and `evidence_kind`: `public_source_capture`, `candidate_execution_receipt`, `candidate_code`, `candidate_input`, `candidate_stdout`, `candidate_stderr` or `candidate_exit`. Optional `original_sha256` and `redaction_policy` disclose mechanical provider/arm/economic-field removal; retain code, request/input, expected-value basis if authored, output, error, exit and component/pin identities exactly. Do not sanitize away relevant failure or execution facts. The builder verifies/copies those bytes under the alias's `evidence/` path; original paths stay in the coordinator sidecar. A catalog declaration without supporting actual execution evidence never proves execution.

The supported designated final stage labels are `final`, `revision`, `final_author` and prospectively added `final_resolution`. There is no research/critic-stage admission.

Ops final-ready outbox is `ops/dispatcher/evaluation_notifications.jsonl`. Consume `FROZEN_OUTPUT_READY_FOR_EVALUATION` events with the pinned freeze path/hash and `pipeline_final` designation; creation of an event is not an assessment. An incomplete/missing final keeps its operational status and cannot become a scored completed artifact by packet construction.

I01 reservation: `ER9-EVAL-I01-001`, one xhigh independent pair evaluator. Prospective hard evaluation bound is 1800 seconds across full pair coverage, with a 1200-second decisive-screen target. Both arms receive the same five predeclared important checks. A screen FAIL retains the explicit unassessed remainder; no whole-case PASS from partial coverage. Stage history/economics are released only after the blind judgment snapshot is saved.
