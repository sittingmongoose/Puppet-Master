# Authentic seed manifest interface

`bind_seeded.py` accepts schema `er9.authentic-candidate-seed.v1` with these fields:

- `origin_freezes`: objects with actual output-freeze `path`, `sha256`, observed `actual_family` (Luna/GLM/Muse), `actual_model` and `actual_effort`. Each freeze must show operational completion and a genuine native Goal start. Candidate roles must exactly match that freeze's artifact inventory and hashes. Native/runtime acceptance remains grounded in the owner receipts; metadata is not private comprehension evidence.
- `candidate_files`: named `proposal`, `critique`, `revision`, `enrichment`, `dependencies`, `source_catalog`, `witness_catalog`, `lead_inventory` objects with `path`, `sha256`, and `origin_job_id`. Supply only roles genuinely produced; a needed missing role blocks that task. Do not supply expected answers or an evaluator findings role.
- `public_source_files`: full governing public source context objects with `kind: PUBLIC_PRIMARY_CAPTURE`, exact admitted `public_captures` path/hash, `url`, `version_or_commit`, useful `locator`, honest `capture_limitations`, and `capture_receipt: {path,sha256}`. The receipt binds `body_sha256` (or `sha256`) and actual URL. If a native source-capture format needs normalization, do it mechanically from its original pinned receipt, retain that original reference, and invent no source interpretation.
- `cold_cost_references`: nonempty actual originating accounting/receipt references. Charge each actual native start once in campaign totals; report cold seed, warm marginal and full workflow costs distinctly. Reuse refers to the existing charged origin rather than inventing zero cold cost or adding the same start twice.
- `fixture_admission_receipt`: a host-only pin to a compact independent suitability receipt. It has `status: SUITABLE_FROZEN_INPUT`, appropriate `pair_ids` (comparison or original source-slot IDs), and `input_content_digest`. Compute the digest with `bind_seeded.content_digest(seed)`, which hashes the candidate-file/public-source/origin records and excludes the admission/cost fields, avoiding a circular digest. Source truth labels/counterexamples remain in separate evaluator-only evidence. Suitability is not the scored output's quality verdict.

Bind only the current stage's exact prerequisite receipts with `--predecessor-map`. A parallel peer, sibling arm or incomplete/changed predecessor is rejected. The source-first phase receives only neutral question/brief plus raw governing public sources and mechanical URL/version locators; all candidate proposal/catalog/dependency prose is withheld. The next phase requires its immutable prior record before release.

CLI: `python3 -B dev/diagnostic-runner/bind_seeded.py --lab LAB --plan PLAN --plan-sha256 SHA --seed-manifest SEED --seed-sha256 SHA --arm ARM --stage STAGE --destination NEW_DEST [--predecessor-map MAP]`. It prepares a single-stage registration request for sole ops and never launches. Existing attempts, pair closures and registration receipts are not overwritten.
