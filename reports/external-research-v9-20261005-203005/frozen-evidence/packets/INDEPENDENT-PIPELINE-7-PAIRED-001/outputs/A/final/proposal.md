# Biomedical image review workspace: current proposal

Purpose: local desktop research review and annotation for six researchers, not diagnosis. Build a thin app around napari 0.9.0 Shapes/Labels and multidimensional navigation; own project identity, provenance, calibration, undo/redo, persistence and export in the app. Candidate pins: napari 0.9.0, tifffile v2026.9.20 for narrow TIFF/OME-TIFF reading, Zarr-Python 3.4.0 for chunked derived masks/cache, SQLite local metadata, OME-NGFF 0.4 interchange with explicit Zarr format 2. These are candidates, not integrated proof. Use public viewer APIs.

Independent precedents: napari supplies viewer/layers, not project persistence; tifffile offers TIFF strip/tile/page/IFD/SubIFD/series/pyramid access, not lazy end-to-end proof; OME-NGFF/Zarr supply axes, coordinate and chunk mechanisms, not full project semantics. Sources complement one another [S1-S4]. NGFF 0.4 permits two or three spatial axes and optional T and C, including TCYX/TCZYX, and defines scale then translation but not arbitrary affine [S1]. Zarr 3.4 defaults new arrays to format 3; explicit `zarr_format=2` is required for NGFF 0.4 [S2-S3]. Versioned evidence URLs: https://zarr.readthedocs.io/en/v3.4.0/user-guide/arrays/ and https://zarr.readthedocs.io/en/v3.4.0/user-guide/v3_migration/. None proves application performance.

V1 support choice: one user-selected series from single-file TIFF/BigTIFF or OME-TIFF; 2D/3D space; optional independent T/C; integer/float; known or explicitly unknown calibration. Never silently select first series. Normalize named axes but preserve raw order and reversible mapping. Qualify every layout/codec on lab instrument fixtures; actual instruments and calibration conventions remain critical unknowns. Unsupported: ambiguous RGB/sample axes, custom/unknown axes, malformed/contradictory metadata, untested codecs/layouts, multi-file/vendor formats. Show needs_mapping/unsupported and reason. Ask explicit correction, keep raw metadata and append before/after/reason/actor/time. Failed import remains staged; it never modifies original or replaces saved project/annotations. No universal compatibility claim.

Data contract: versioned project/image IDs; reader/version; selected series; source axes/order/shape/dtype; raw metadata; normalized mapping; geometry revision. Identify single files by streaming SHA-256 plus size; multi-file data by canonical sorted manifest of relative names/sizes/hashes. Paths/times are hints. Full 3 GB hash uses bounded RAM but reads all bytes; show progress/cancel and keep identity provisional until complete. Detect instability and block use until stable reference or managed copy. Hash means byte identity only. Offer external reference or portable copy, disclose costs, keep relative path and absolute hint. Relink by full hash plus metadata; mismatch requires explicit new identity and preserves old annotations/history detached, never filename-only retargeting.

Product coordinate convention: named axis type/order/unit; spatial zero-based continuous pixel-center indices. This convention needs tests. Persist full-precision `world=A·index+t`, named spatial order, origin, orientation/handedness, units, provenance and geometry revision. Time spacing/origin/unit only when known; irregular time uses per-frame map or is unsupported; channels categorical. Unknown calibration displays index only. UI reports index and physical coords when available. NGFF example `[2,3,4]*[2,.5,.25]+[100,10,20]=[104,11.5,21]`; reverse differs (W1 arithmetic check). Keep arbitrary affine in project; export physical coordinates only when representable, else index+transform sidecar or refuse misleading physical overlay [S1].

Annotations: UUID, source byte identity, geometry revision, point/polygon/mask, coordinate frame, scope plane/volume/acquisition, explicit T/C index/range/all/not-applicable selectors, never inferred from view, plus author/time/style/labels/history. Plane includes non-displayed coordinate. Mask also stores hash, axes/order/shape, voxel-to-image mapping, source identity/revision, scope/selectors, label IDs/names and provenance; matching dimensions alone is insufficient. Reusable versioned styles; undo/redo command journal, mask chunk deltas. Window/level/LUT/gamma/channel/time/slice/zoom/visibility is separate display state and never alters original samples. Original/derived layers visibly differ. Geometric transform/resample creates a separate asset with hashes, output-to-input map, axes/dtype/calibration, interpolation/bounds/parameters/software/time. Annotations remain original-frame unless an explicit mapped copy is recorded.

Workflow: create; import/inspect; correct ambiguity or retain unsupported; navigate channels/T/Z and adjust display; annotate; undo/redo; save/close/reopen elsewhere; identity-based relocation; export table/overlay/small derived crop; verify changed and unchanged data. Store metadata/commands in local single-writer SQLite rollback journal. SQLite atomicity depends on OS/filesystem/hardware and does not cover external assets [S13]. Write assets to unique partials, flush/hash/validate, publish generation, success marker last; retain previous good generation. Restart reconciles manifests and quarantines partials; DB integrity check and closed backup/checkpoint. Never live DB on shared storage. WAL if ever used only locally: WAL can contain committed persistent state; SHM is shared-memory index; WAL unsupported on network filesystem [S14]. Never copy a live main DB alone/delete sidecars. Close/snapshot/verify, copy unique bundle, verify again; test actual share semantics.

Export UTF-8 CSV plus versioned JSON sidecar: schema/app, hashes, axes/order, transform/revision, coordinate convention/units, annotation IDs/types/scope/T/C, styles/labels and explicit unknowns. CSV is lossy. Validate overlays/NGFF labels independently [S1]. Small derived output has own hash, bounds, map/calibration/interpolation. Report preserved/transformed/omitted data; do not claim vendor metadata/history unless verified. Fail/cancel leaves last-good state and recoverable partial.

Proposed, unverified 8-core/16GB target: request only visible regions/planes; 256-512 MiB cache, 1-2 workers, no full-array display read; TIFF codec/strip may decode larger blocks. Hash is full I/O but not second full RAM copy. Progress and cancellation between supported units. Keyboard-operable navigation/annotations/styles/undo/redo/dialogs; legible errors, calibration and focus; state not color-only.

Proposed UNEXECUTED checks: (1) lab fixture matrix for TCYX/TCZYX, axes, dtype, series, calibration, codecs and safe unsupported failure; (2) unequal dimensions, axis permutations, origin/anisotropy, T/C, unknown calibration, annotation scopes/masks through reopen/export and independent NGFF v2 reader; (3) 3 GB tiled/stripped test on named hardware measuring p95 navigation, RSS, bytes/decode, cache, hash progress, cancellation/recovery. Starting targets p95 plane <=500ms post-decode, display RSS delta <=1GiB, cancel <=1s between decode units; goals only; (4) run upstream and app slice regression; (5) fault-inject DB/assets/manifest/copy, test real shares/OSs, recovery/relink; (6) independent export inspection, loss report, hashes and source immutability; (7) keyboard-only workflow/focus/readability. Critical gates: real instrument/calibration corpus, codec performance, pinned package integration, pixel-center/mask raster semantics, share durability. If a gate fails, retain source, explain failure, defer format or add specifically qualified reader.
