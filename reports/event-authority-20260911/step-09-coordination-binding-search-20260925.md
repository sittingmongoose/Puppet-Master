# Coordination families: per-family binding search, 2026-09-25

This is the documented search that DL-045 requires before a missing binding is written for an event family. It covers the seven agent coordination families of Step 9 batch 2, and gives a short out-of-batch note for `coordination.debug_mirror_exported`. It supports the owner prose on branch `plans/ea-s09-coordination-prep-20260925`: the Storage unit SP-320, the Orchestrator unit OSI-438 and the Contracts unit CV-353.

DL-045 (`Plans/Decision_Log.md` line 562) says: "Each event requires its own documented search scope, citations to existing partial contracts, and negative evidence that the required definition was not found within that scope." It also says: "Reuse an existing binding only when its owner defines the required role, version and scope; do not infer it from a sibling". Each family below therefore has its own section. A family's section cites that family's own owner lines. Siblings appear only as transition partners, never as evidence for the family.

This report admits nothing. It changes no registry row, checkpoint, validator or governance artifact. The seven families stay quarantined and absent from `Plans/event_family_registry.json` until each has its own Storage admission landing (DL-045: "one family per landing").
