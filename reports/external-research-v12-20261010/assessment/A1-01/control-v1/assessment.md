## Useful discoveries and alternatives

- **tus offset resource versus object-store numbered parts:** Discriminates server crash/persistence and staging burden from remote part retry/reconciliation; preserves both transports. [R01](evidence/index.md#r01), [R02](evidence/index.md#r02).

- **HTTP 200 completion embedded error:** Requires body/SDK error handling and authoritative reconciliation after timeout, instead of done-on-call. [R06](evidence/index.md#r06).

- **In-flight abort race plus configured lifecycle:** Assigns gateway convergence and orphan cleanup, separate from policy deadline and store lifecycle. [R05](evidence/index.md#r05), [R08](evidence/index.md#r08), [R11](evidence/index.md#r11).

- **Versioned MinIO aws-chunked report and unmerged proposed fix:** Tests frame encoding separately from part size; avoids pretending Go history proves Rust UploadPart compatibility. [R07](evidence/index.md#r07), [R09](evidence/index.md#r09), [R13](evidence/index.md#r13), [R14](evidence/index.md#r14).

- **Gateway-backed tus 1.0.0 — Retained alternative.** Offset/byte durability and backend bridging/staging versus uniform resumable HTTP interface. [R01](evidence/index.md#r01).

- **Gateway-owned native MPU with direct scoped part grants — Conditional first candidate.** Independent part retry/storage near destination versus exact provider/SDK/cleanup qualification. [R02](evidence/index.md#r02), [R07](evidence/index.md#r07), [R08](evidence/index.md#r08).

- **Proxy native multipart part bodies through existing gateway — Explicit conditional option.** Gateway can observe/drain requests at bandwidth cost when direct grant/drain boundary cannot be established. [R08](evidence/index.md#r08), [R11](evidence/index.md#r11).

- **Whole-file checksum comparison versus remote readback SHA-256 — Conditional integrity alternatives.** Algorithm/type availability governs metadata verification; readback costs a transfer but retains the declared digest goal. [R10](evidence/index.md#r10).

- **Snapshot/locking versus full rehash/spool — Owner decision; not asserted as already qualified.** Laptop scan/spool cost and exact source-byte identity; not an invented implementation result. .
