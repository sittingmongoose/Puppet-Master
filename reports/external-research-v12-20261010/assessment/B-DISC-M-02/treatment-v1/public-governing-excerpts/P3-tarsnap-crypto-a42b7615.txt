4: 0004: When a system is first registered with the Tarsnap server, the
5: 0005: tarsnap-keygen utility generates cryptographic keys for
6: 0006: the system to use.  These keys form the backbone of Tarsnap's
7: 0007: security: Without them, it is (given the current state of the art of
8: 0008: cryptography) infeasible for anyone to either decrypt or create
9: 0009: archives which will be recognized as valid.

18: 0018: A 2048-bit RSA key used for encrypting session keys.  All the data
19: 0019: which the Tarsnap client sends to the server to store is encrypted
20: 0020: with per-archive random AES-256 keys; those keys are encrypted with
21: 0021: this RSA key and attached to the stored data.
22: 0022: Cryptographers: RSAES-OAEP is used to encrypt the session keys,
23: 0023: using MGF1 and SHA256, and the padding verification performed when

26: 0026: incrementing nonces — generating a new AES-256 key for each
27: 0027: session ensures that a key-nonce pair will never be used twice.

42: 0042: of raw SHA256 hashes prevents any information from leaking via the
