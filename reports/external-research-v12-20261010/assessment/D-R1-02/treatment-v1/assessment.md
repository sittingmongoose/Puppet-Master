## Useful discovery, competing approaches and history

- **ADXL355 interface/default/timing mismatch can make a configured rate misleading.** Audit actual bus, effective timestamps, group delay and coherent sample reads before recurrence/location analysis. Evidence: [R01](https://www.analog.com/media/en/technical-documentation/data-sheets/adxl354_adxl355.pdf).

- **Concrete Linux/IIO missed-interrupt incident and unconfirmed FIFO proposal.** Recover actual software/platform versions and loss behavior, without generalizing a vendor defect or shipped fix. Evidence: [R03](https://ez.analog.com/linux-software-drivers/f/q-a/569014/eval-adxl355z-linux-command-line-for-setting-the-sample-frequency/493909).

- **Mount/base mass changes transfer; known-input bracket comparison isolates local response.** Test bracket hypothesis without interpreting temporal coincidence as causation. Evidence: [R02](https://www.ni.com/en/shop/data-acquisition/sensor-fundamentals/measuring-vibration-with-accelerometers.html), [R04](https://onlinelibrary.wiley.com/doi/10.1155/2017/1959286).

- **Simultaneous vehicle/track/soil and independent LVDT precedents.** Select the measured quantity and reference carefully; synchronized methods can transfer even when numerical results cannot. Evidence: [R04](https://onlinelibrary.wiley.com/doi/10.1155/2017/1959286), [R05](https://jzus.zju.edu.cn/article.php?doi=10.1631/jzus.A1600212).

- **Wagon placement/load precedent has limited and inconsistent rate evidence.** Compare placement and context but withhold cart band, impact capture and isolated load-effect conclusions. Evidence: [R06](https://pmc.ncbi.nlm.nih.gov/articles/PMC10574946/).

- **Wheel-order angular phase differs from route location; optical/IMU geometry has substantial setup prerequisites.** Keep optional analysis distinct from simpler surveyed markers/manual event mapping and avoid overbuilt geometry machinery. Evidence: [R07](https://manual.dewesoft.com/x/setupmodule/modules/machinery/ordertracking), [R08](https://arxiv.org/abs/2008.03763v1).

The comparison is consequential to this pilot: context/manual event mapping offers a low-intervention first step; bench bracket transfer and acquisition checks separate sensing artifacts; independent MEMS/IEPE, rigid-point and track-side measurements answer different physical questions; surveyed markers can be simpler than a camera/IMU geometry system; wheel-order analysis is conditional on a different rotational question. The final preserves these choices and their constraints rather than selecting a monitoring product.

Cart-specific installation and operating history is genuinely unavailable in this synthetic input. The pipeline nevertheless investigates an actual implementation failure, documentation changes and comparable sensing histories with settings, placement, speed/load and independent observations. It asks for installation dates/practices, actual firmware/rule changes and old hardware. This is useful bounded investigation, not a promise that unspecified cart behavior will eventually be researched.
