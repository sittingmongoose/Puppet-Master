61: Deleting your data¶
94: To check whether a submission has been edited, you can usually compare the _uuid field with the rootUuid field in the data table or exported data. The rootUuid value stays the same for the original submission, while the _uuid value changes each time the submission is edited. If the values are different, the submission has likely been edited.
