## Semantic families

### odoo

18.0 versioned docs: enable Barcode; scheduled picking and final Validate; WHIN new-instance exception; custom internal strings/GTIN allocation/opt-in lookup; optional lot/serial scan; first matching nomenclature rule and no automatic custom-field mapping; IoT/keyboard/default US QWERTY/ENTER keycode 28 conditions. No guaranteed offline queue. No numeric inventory unit/weight decision is made by the proposal.

### snipe

Rolling tag/label/import/custody docs support their stated path and guidance; v8.8.0 release date, beta app/sync and one Zebra template claim supported. Default QR path is not complete released capability (F1). qr_text → label2_title transition supported, QR symbol suppression not established (L1). Version tag resolved to exact commit.

### gs1

2024 guide supports structured IDs parsed offline vs URL retrieval, GTIN plus defined qualifiers, and other possible GS1 primary keys. 2024 redirect advice/303 scoped to Digital Link, not ordinary QR; analytics discussion not claim all shorteners track. Resolver 1.2.0 ratified Jan 2026 does not require identical linksets/targets and scopes supported keys. General Specs 23.0 page 317 defines ]Q3 for leading-FNC1 AI element strings, not every Digital Link URL QR.

### zxing

PR #1681 merge 557b5fcf0e22a6cf2541a54bd830116712fec51d changes RSS Expanded decoders/FieldParser.java; increased lengths plus legacy reduced/removed cases, shipped in 3.5.3 f0f1a94439db0300ff0c4618f4e0a41aa630aeac. PR #1839 change commit 34588d8, merge 8944e607789b0847625f9962e90aab9901c731cd adds symbology metadata in QRCodeMultiReader, shipped in 3.5.4 f651b0a0375676e47144f73397dddff8868b0e4c. No selected cooperative runtime or universal QR/GS1 parser capability inferred.
