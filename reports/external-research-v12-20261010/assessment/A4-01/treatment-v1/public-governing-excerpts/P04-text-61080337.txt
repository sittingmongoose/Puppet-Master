393: Lifecycle configuration to abort multipart uploads
394: You can use the Amazon S3 multipart upload REST API operations to upload large objects in
395: parts. For more information about multipart uploads, see Uploading and copying objects using multipart upload in Amazon S3.
396: By using an S3 Lifecycle configuration, you can direct Amazon S3 to stop incomplete
397: multipart uploads (identified by the key name prefix specified in the rule) if they
398: aren't completed within a specified number of days after initiation. When Amazon S3 aborts a
399: multipart upload, it deletes all the parts associated with the multipart upload. This
400: process helps control your storage costs by ensuring that you don't have incomplete
401: multipart uploads with parts that are stored in Amazon S3.
402: Note
403: When you use the AbortIncompleteMultipartUpload S3 Lifecycle action,
404: the rule cannot specify a tag-based filter.
