86: Project file
87: File – Save Project now saves a 3MF file containing all objects, settings, modifiers and their parameters. It’s essentially a complete snapshot of PrusaSlicer. When you open a project file on a different computer, it should still produce the same G-code. We chose 3MF over AMF, because it’s a modern format supported by Microsoft 3D Builder and Cura, but we still support AMF import. And yes, this feature was already present since Slic3r PE 1.40, but it was buried in the export menu as “Export plater as 3MF/AMF”.
