64: ## About this Specification
65: This 3MF materials and properties specification is an extension to the core 3MF specification. This document cannot stand alone and only applies as an addendum to the core 3MF specification. Usage of this and any other 3MF extensions follow an a la carte model, defined in the core 3MF specification.
66: 
67: Part I, “3MF Documents,” presents the details of the primarily XML-based 3MF Document format. This section describes the XML markup that defines the composition of 3D documents and the appearance of each model within the document.
68: 
69: Part II, “Appendixes,” contains additional technical details and schemas too extensive to include in the main body of the text as well as convenient reference information.
70: 
71: The information contained in this specification is subject to change. Every effort has been made to ensure its accuracy at the time of publication.
72: 
73: This extension MUST be used only with Core specification 1.2.
