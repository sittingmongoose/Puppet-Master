140: DESCRIPTION¶
141: aria2 is a utility for downloading files. The supported protocols are
142: HTTP(S), FTP, SFTP, BitTorrent, and Metalink. aria2 can download a
143: file from multiple sources/protocols and tries to utilize your maximum
144: download bandwidth. It supports downloading a file from HTTP(S)/FTP
145: /SFTP and BitTorrent at the same time, while the data downloaded from
146: HTTP(S)/FTP/SFTP is uploaded to the BitTorrent swarm. Using Metalink
147: chunk checksums, aria2 automatically validates chunks of data while
148: downloading a file.
188: -V, --check-integrity [true|false]¶
189: Check file integrity by validating piece hashes or a hash of entire
190: file.  This option has effect only in BitTorrent, Metalink downloads
191: with checksums or HTTP(S)/FTP downloads with
192: --checksum option.  If
193: piece hashes are provided, this option can detect damaged portions
194: of a file and re-download them.  If a hash of entire file is
195: provided, hash check is only done when file has been already
196: download. This is determined by file length. If hash check fails,
197: file is re-downloaded from scratch.  If both piece hashes and a hash
198: of entire file are provided, only piece hashes are used. Default:
199: false
956: --allow-piece-length-change [true|false]¶
957: If false is given, aria2 aborts download when a piece length is different
958: from one in a control file.
959: If true is given, you can proceed but some download progress will be lost.
960: Default: false
1290: --realtime-chunk-checksum [true|false]¶
1291: Validate chunk of data by calculating checksum while downloading a file if
1292: chunk checksums are provided.
1293: Default: true
