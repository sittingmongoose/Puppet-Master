43: CURLOPT_RESUME_FROM_LARGE - offset to resume transfer from
44: Synopsis
45: #include <curl/curl.h>
46: CURLcode curl_easy_setopt(CURL *handle, CURLOPT_RESUME_FROM_LARGE,
47: curl_off_t from);
48: Description
49: Pass a curl_off_t as parameter. It contains the offset in number of bytes that you want the transfer to start from. Set this option to 0 to make the transfer start from the beginning (effectively disabling resume). For FTP, set this option to -1 to make the transfer start from the end of the target file (useful to continue an interrupted upload).
50: When doing uploads with FTP, the resume position is where in the local/source file libcurl should try to resume the upload from and it appends the source file to the remote target file.
51: HTTP uploads using POST or PUT cannot be resumed. curl_easy_perform returns CURLE_BAD_FUNCTION_ARGUMENT when this option is set to a non-zero value for such an upload.
52: Default
53: 0, not used
54: Protocols
55: This functionality affects all supported protocols
56: Example
57: int main(void)
58: {
59: CURL *curl = curl_easy_init();
60: if(curl) {
61: CURLcode result;
62: curl_off_t resume_position = 1234; /* get it somehow */
63: curl_off_t file_size = 9876; /* get it somehow as well */
64: curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com");
65: /* resuming upload at this position, possibly beyond 2GB */
66: curl_easy_setopt(curl, CURLOPT_RESUME_FROM_LARGE, resume_position);
67: /* ask for upload */
68: curl_easy_setopt(curl, CURLOPT_UPLOAD, 1L);
69: /* set total data amount to expect */
70: curl_easy_setopt(curl, CURLOPT_INFILESIZE_LARGE, file_size);
71: /* Perform the request */
72: result = curl_easy_perform(curl);
73: curl_easy_cleanup(curl);
74: }
75: }
76: Availability
77: Added in curl 7.11.0
78: Return value
79: curl_easy_setopt returns a CURLcode indicating success or error.
80: CURLE_OK (0) means everything was OK, non-zero means an error occurred, see libcurl-errors.
