# Exact Goal binding guard v1

Small standard-library mechanics addition. Incident motivating this addition: a terminated Luna critic changed the frozen objective path `C-R1-01/treatment` to `C-R1-01-treatment` despite a verbatim instruction. The original failed run is preserved; no original stage, helper, transformer or incident file was changed. This package is common symmetric future mechanics, not technique/source assistance, a runner, or scientific qualification.

Root invokes `overlay.py` **only after existing stdSpec + clarifySpec**, only for an exclusively owned, unused, unexpired future stage. Pass an absolute stage directory. No existing stage overlay was run for this repair. No dispatch, delegation, provider call, account lookup or source/case inference is performed by either production script.

```text
python3 ER12_RUNTIME/mechanics/exact-goal-binding-guard-v1/overlay.py --stage-dir <ABSOLUTE_UNUSED_FUTURE_STAGE>
```

The overlay requires the existing `invocation-clarification-v1` marker and its exact four current artifact hashes. It appends the same pre-input instruction and fully expanded guard command to `request.json.args.task` (the first short task) and `assignment.md`. Only the runtime JSON response slot remains a placeholder. It embeds the existing frozen objective verbatim as a JSON string: no slash/hyphen replacement, trimming, case folding or normalization. The instruction activates ONE exact actual native Goal, immediately supplies its exact unmodified complete create_goal response (or immediately obtained get_goal response), and stops before ANY case/source reading or inference if activation/gating fails. The original failure and diagnostic must be preserved; a second/replacement Goal is forbidden.

```text
python3 ER12_RUNTIME/mechanics/exact-goal-binding-guard-v1/assert-active-goal.py --stage-dir <ABSOLUTE_STAGE> --json '<EXACT_COMPLETE_FRESH_NATIVE_RESPONSE>'
```

Use structured argv or correct shell quoting to supply the native response as ONE argument, without dropping fields. The checker is read-only. It accepts a Codex `goal` envelope with its `remainingTokens` and `completionBudgetReport` fields, and a Muse `goal_id` goal object either direct or inside `goal`. Required goal fields are `objective`, `status`, and an exposed nonempty native `threadId` or `goal_id`. Codex also requires its exposed `createdAt`, `updatedAt`, `tokensUsed`, and `timeUsedSeconds` fields; an extracted Codex goal without its envelope is rejected. Status must equal `active`, and objective must equal `freeze.json.native_goal_objective` exactly. It rejects invalid/truncated/concatenated JSON, duplicate keys, missing required fields, missing identity, inactive status, differing objectives, and symlink stage ancestry/members/freeze paths. Exit 0 means the supplied fields passed; exit 2 means stop. It does not create/synthesize a Goal, call providers, recover JSON from prose, or turn a failing observation into a replacement.

**Exact response provenance and freshness cannot be independently proved by this checker.** Completeness checks cover syntactic completeness, required goal fields and known Codex wrapper fields. Removal of unknown optional provider fields or an authored imitation cannot be distinguished from a real response offline. The caller must pass the complete exact fresh native response and preserve its actual tool receipt; this package does not attest native lifecycle execution or provider behavior.

The overlay follows the named v1 transformer's current request/freeze/input-map/assignment semantics, without importing, invoking or changing it. It saves all four original byte strings first in a read-only `.goal-guard-backup-*` directory. It verifies carried hashes/sizes and current request/assignment hashes; updates all actual changed assignment/request/input-map path/hash/size references across all three JSON objects in dependency order; rejects cyclic/self-hashing inputs. Route, deadlines, objective, service settings and arbitrary science/scope metadata remain unchanged. The v1 marker is preserved byte-for-byte and its digest is recorded in the new marker. Root uses the returned updated `args` for any later authorized dispatch, rather than an old cached request.

An identical retry validates the original clocks, unused state, carried hashes, v1 marker digest and updated four byte hashes, then returns `idempotent: true` without rewriting any byte. Dispatched/used/partial stages, source work, expired original clocks, changed retries and symlinks fail closed. An interrupted mutation retains the backup and restores the four originals. Root must own the stage exclusively throughout: this is not a concurrent dispatcher or transactional scheduler. Replay after use is forbidden. No original helper or v1 transformer upgrade is implied.

`checks.py` uses only newly authored synthetic fixtures in this directory, records results to `check-results.json`, and deletes its synthetic scratch afterward. It does not load live stage templates. Tests cover both supported wrapper shapes, exact-objective differences, inactive/missing identity/invalid/partial JSON, hashes in multiple artifact layouts, original backups, idempotence, changed retries, used/dispatch/source-work, marker requirements, expiry and symlinks. Public templates contain no private account IDs. Self native receipts are separately named `native-create.json`, `native-active.json`, and `native-complete.json`; their identity belongs to this mechanics task, never a leaf/campaign run.

Read-scope exception: a too-broad `rg` over the mechanics directory returned historical mechanics snippets in publication copies while looking for wrapper field names. That search was stopped and not repeated. No science/source/case document was opened, no historical stage was overlaid, and no snippet was copied into the fixtures. This exception is recorded rather than claiming the requested history-read boundary was perfectly maintained. Initial native activation preceded artifact work, and completion follows saved implementation, checks and documentation. The actual native tool transcript is the receipt provenance.
