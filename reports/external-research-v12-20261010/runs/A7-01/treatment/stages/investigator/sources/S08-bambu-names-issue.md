# S08 — PrusaSlicer cross-slicer name issue #15662

- **Source:** [Object names from BambuStudio 3MF are not imported](https://github.com/prusa3d/PrusaSlicer/issues/15662)
- **Version:** Reported on PrusaSlicer 3.0.0-alpha11; opened 2026-09-02 and converted to a discussion/locked 2026-09-03.
- **Access:** 2026-10-10T04:14:03Z, read-only issue review.
- **Locator:** Description and examples comparing Core model data with Metadata/model_settings.config.
- **Observed operation:** Read public issue; package not downloaded or tested.
- **Reported condition:** Bambu object labels were stored in vendor-specific metadata, not Core object name; PrusaSlicer showed unnamed/numeric entries and its saved project omitted the vendor label.
- **Applicability:** Demonstrates project metadata differences across applications. It does not show Core object names are unavailable or that the same behavior occurs in later stable versions.
