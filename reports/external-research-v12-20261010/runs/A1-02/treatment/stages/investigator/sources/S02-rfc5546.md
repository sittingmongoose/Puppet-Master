# S02 — RFC 5546 iTIP

- URL: https://www.rfc-editor.org/rfc/rfc5546.html
- Version: RFC 5546, Standards Track, December 2009.
- Access observation: 2026-10-10T04:00:20Z.
- Locators: §3.2.5 CANCEL, §3.7.1 Working With Recurrence Instances, §4.4.3 Cancel an Instance.

**Observed operation.** iTIP CANCEL is a scheduling message sent by an organizer to affected attendees. For one occurrence it uses UID plus RECURRENCE-ID; for the entire series it omits RECURRENCE-ID. The recurrence-instance discussion also uses original unmodified DTSTART in RECURRENCE-ID when organizer changes DTSTART/DTEND.

**Application.** This distinguishes attendee notification and organizer authority from editing an offline `.ics` snapshot. Do not invent an attendee-message workflow for the local importer/exporter.
