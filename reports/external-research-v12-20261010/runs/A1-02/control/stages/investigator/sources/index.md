## Governing interchange evidence

- **S01 — [RFC 5545](https://www.rfc-editor.org/rfc/rfc5545.html)**, September 2009. §3.2.19 and §3.3.5 make a named TZID reference explicit; local floating time is not the same thing as a time-zone-bound time. Ambiguous local values mean first occurrence; explicit nonexistent local date-time uses pre-gap offset, while recurrence-generated nonexistent local values are skipped and not counted (§3.3.10). Recurrence set: DTSTART/RRULE/RDATE, subtract EXDATE; exclusions take precedence; duplicate inclusions collapse; unsynchronized DTSTART/RRULE and multiple RRULEs are undefined (§3.8.5). UID is the persistent series/component identity; RECURRENCE-ID is the original slot and does not change after rescheduling (§3.8.4.4, .7). A VTIMEZONE referenced by a recurring component must provide valid rules for all recurrence instances (§3.6.5). Unknown X-name/IANA value-type payloads must be preserved without parsing (§3.2.20).

## Provider operation comparators (not offline interchange guarantees)

- **S02 — [Google recurring events guide](https://developers.google.com/workspace/calendar/api/guides/recurringevents)** and **S04 — [Google instances method](https://developers.google.com/workspace/calendar/api/v3/reference/events/instances)**: enumerate a series through `events.instances`, select an instance, then update the instance resource; cancellation is an individual instance with `status=cancelled` in the guide's examples. `recurringEventId` plus immutable `originalStartTime` distinguishes original slot from moved start (S02/S03). Cancelled recurring exceptions have special retention/field guarantees, unlike a deleted event (S03).
- **S05 — [Graph event resource v1.0](https://learn.microsoft.com/en-us/graph/api/resources/event?view=graph-rest-1.0)**, **S06 — [list instances](https://learn.microsoft.com/en-us/graph/api/event-list-instances?view=graph-rest-1.0)**, **S07 — [update](https://learn.microsoft.com/en-us/graph/api/event-update?view=graph-rest-1.0)**, **S08 — [cancel](https://learn.microsoft.com/en-us/graph/api/event-cancel?view=graph-rest-1.0)**, **S09 — [delete](https://learn.microsoft.com/en-us/graph/api/event-delete?view=graph-rest-1.0)**: Graph uses series-master/event IDs, `type`, and UTC `originalStart`; instance enumeration is time-windowed; PATCH targets an event ID. A recurrence exception moved across the adjacent-occurrence day boundary may be rejected. Cancel and Delete are distinct organizer/attendee operations with different communication effects. No provider requests were made.
