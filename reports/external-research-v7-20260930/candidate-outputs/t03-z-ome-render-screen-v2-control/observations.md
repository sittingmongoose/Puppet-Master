## Pass 4 — Mapping to brief and thin plan (UTC ≈2026-09-30T15:23Z)

- Discovery must handle three topologies: single image group (multiscales at root), bioformats2raw collections (series list or consecutively numbered groups), HCS plates (plate→row→well→fields). The plan's "lists the images it finds" is consistent, but the plan never mentions plates/wells/series — gap needing a plan/product decision (build HCS navigation, or state explicitly that HCS filesets are not displayable).
- Reader duty S003 L272 (SHOULD make users aware of >1 image; SHOULD NOT default to the first) independently justifies the plan's image-list requirement for collections.
- Calibration chain for the details panel: axes "unit" (SHOULD, may be absent) + per-dataset scale (MUST) + optional group-level scale applied after dataset transforms (L314–315); translation after scale (L311).
- Label overlay alignment: spec says label images are "usually" in the same coordinate system (L433) — not a MUST; layout comment allows size-1 dims (L106–108). Counterevidence to assuming alignment; runtime verification + mismatch surfacing needed.
- `omero` is optional (L426): absence is legal, so default rendering (colors, windows, initial t/z) is a product decision. Window `min`/`max` vs `start`/`end` semantics are circularly defined in the capture (L429–430); example (L411–416: min 0, max 65535, start 0, end 1500) suggests min/max = data bounds and start/end = display window — unresolved.
- Nothing mandates ≥2 pyramid levels; a 1-entry "datasets" list satisfies the text (L304–307) — interpretation from absence; plan's level-choosing needs a single-level fallback decision.
- Zarr feature freedom (L70–72) means codecs/chunk grids/dtypes vary; the viewer needs a supported-feature policy plus "cannot display" messaging (matches brief's explain-undisplayable requirement).
- Dead ends inside admitted scope: Implementations "See Tools" (L814); OMERO WebGateway doc (L424–425); `/latest/` (L819). The brief's "research actual reader implementations" cannot be satisfied from this corpus → UNEXECUTED proposed validation.
