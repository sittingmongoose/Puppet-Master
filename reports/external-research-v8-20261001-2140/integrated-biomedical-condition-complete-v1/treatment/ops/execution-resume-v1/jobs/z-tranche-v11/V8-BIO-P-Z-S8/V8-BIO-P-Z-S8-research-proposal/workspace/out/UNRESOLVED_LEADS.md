# UNRESOLVED LEADS — V8-BIO-P-Z-S8 research/proposal

Only consequential dependencies/uncertainties that remain open after the research captured in `out/PROPOSAL.md`. None of these are claimed resolved; none of the proposed tests have been executed.

1. **napari mouse-event coordinate space (affects B2 implementation).** The gate computes physical coordinates itself, but the cursor hook must know whether napari mouse events deliver world or data coordinates for multiscale layers, and how layer `affine` interacts with `scale`/`translate`. Lead: verify at implementation time with T2/T4 (assert reported index equals gate prediction at both levels). Captured evidence covers plugin metadata (S3), not napari event semantics.
2. **zarr-python 3.x reading of zarr-v2 NGFF 0.4 stores in all chunk layouts.** napari-ome-zarr v0.10.0 pins `zarr>=3.1.5`, which implies v2-store readability, but edge layouts (sharding is v3-only; mixed compressors in v2) were not investigated. Lead: run T1/T7 against a corpus including pre-#590 writer output and hand-written stores.
3. **Tolerance for label/image per-level scale match (P3).** 0.4 fixes only level-count parity (S1 L466–467); the 1e-6 relative tolerance is a product choice with no upstream precedent captured. Lead: survey real corpora; consider exact-rational comparison for pure 2^k pyramids.
4. **2D translation correctness of vizarr (comparison completeness).** Issue #271 confirms 3D translation breakage; 2D behavior was not separately verified in this stage. Does not affect the recommendation (napari stack chosen) but would matter if the web-embed fallback is revived.
5. **Mixed-writer corpora.** PR #590 means freshly generated pyramids carry per-level half-pixel translations while older ones do not; how often consumers must reconcile both conventions within one fileset is unknown. T6's warning mitigates display, not data.
6. **napari version churn.** napari adopted monthly releases (v0.9.2 notes); pin to a tested minor and re-run T1–T7 on upgrade. The plugin/napari/zarr compatibility triangle (napari≥0.6, zarr≥3.1.5, Python≥3.11) was captured from v0.10.0 metadata only, not exercised.
7. **Scale-semantic mixing on one axis (S1 L369).** A level's scale vector may contain absolute physical sizes for some axes and level-0-relative factors for others when calibration is partially unknown. The gate plan handles this per-axis, but no fixture in §7 exercises the mixed case yet (add F2: x in µm, y factor-only).
