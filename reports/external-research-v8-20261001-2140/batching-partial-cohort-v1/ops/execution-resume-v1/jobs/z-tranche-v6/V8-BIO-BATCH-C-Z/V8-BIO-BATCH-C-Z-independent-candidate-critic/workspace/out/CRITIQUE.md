**[SRC, verified both locators]** The proposal §8.2 cites "napari #139's report that default readers skip the scale metadata." `napari/napari#139` (fetched cap:9c2d…) is **"Idea: use namespace packages in conjunction with plugins"** (created 2018-11-24, closed 2021-05-18) — unrelated. The witness's justification itself does not depend on it — interpretation A is carried by the S1 MUST clauses (below) — so the witness stands after the citation fix.

### C2 — Arithmetic/consistency errors in §8.2's "level-invariance corroboration" paragraph (hand-reasoned check, UNEXECUTED)
Using the proposal's own fixture (level 0 scale `[1,1]`, level 1 scale `[2,2]`, multiscales-level translation `[100,10]`, probe level-1 voxel (7,4), same scene point at level-0 voxel (14,8)):
- Interpretation A level 1: 7×2+100=114.0, 4×2+10=18.0 → **(114.0, 18.0)** ✅; A level 0: 14×1+100=114.0, 8×1+10=18.0 → (114.0, 18.0) ✅ invariant. ✅
- Interpretation B level 1: **(14.0, 8.0)** ✅. But B **level 0** = (14×1.0, 8×1.0) = **(14.0, 8.0)** — identical. The proposal says B "shift[s] with the level": **false**. B consistently drops the multiscales-level offset and is therefore level-*invariant* but absolutely wrong at every level. Consequence: level-invariance alone cannot discriminate B; only the absolute-value probe does.
- Interpretation C level 1: (7+100)×2=214.0, (4+10)×2=28.0 → **(214.0, 28.0)** ✅. C **level 0** under the proposal's own definition of C, (index+translation)×scale, is (14+100)×1.0=114.0, (8+10)×1.0=18.0 → **(114.0, 18.0)**, **not "(228.0, 36.0)"** as printed. (228, 36) would require applying level 1's scale at level 0. So C does shift across levels ((214,28) vs (114,18)) — the qualitative claim survives — but the printed level-0 value is wrong, and it coincides with A's readout: a level-0-only probe would **not** discriminate A from C.
- **What survives:** the core discriminating claim is correct — at the single level-1 probe the three interpretations yield pairwise-distinct pairs {(114,18), (14,8), (214,28)}, so V1's proposed assertion `cursor(level=1,(7,4)) == (114.0, 18.0)` separates all three with one check. V2's expected (114.0, 18.0) under A is correct. **Supported correction:** rewrite the corroboration paragraph — B is invariant-but-offset-blind (discriminated only by V1/V2's absolute values, not by invariance), C's level-0 value is (114.0, 18.0), and the level-1 probe is the sole discriminator; V2 corroborates A's invariance but is not itself an A/B discriminator beyond the absolute value it asserts.
