# Reproduction boundary

The [protocol](protocol/README.md) supplies exact candidate TASK/METHOD inputs, shared synthetic briefs/plans, three-stage templates and prospective reservations. No actual candidate output or executed configuration is supplied yet; this checkpoint cannot reproduce an experiment result.

Future batches will bind immutable candidate inputs, actual outputs, sanitized runtime configurations and pinned reproducible code through authorized public projections. Required native subscriptions/account context can limit independent replay. Private conversations, evaluator keys, authentication material and raw large corpora stay outside this branch. Public claim verification must use permitted excerpts/locators and independent assessment; missing publishable bodies will be explicitly identified as a verification limit.

Planner candidate files and the prospective manifest are preserved from the planning freeze. The original manifest’s `../../AUTHORIZATION.json` locator belongs to the external lab layout; the public authority is [authority/AUTHORIZATION.json](authority/AUTHORIZATION.json). The manifest’s evaluator-only scope is intentionally not included in candidate/public inputs. Evaluator reservation metadata is sanitized to omit private lane paths. These layout differences prevent treating the public directory as a complete executable runtime mount.

[Code cohort v1](code-cohort-v1/README.md) exports exact public source where possible and path-sanitized source/review projections with original/public SHA separately. It preserves finite repair history but cannot reproduce a native result yet. Historical v7 engine dependencies remain external prerequisites rather than silently copied private host material.

[Route cohort v1](route-cohort-v1/README.md) includes the selected source/config closure and the two explicitly authorized historical public dependency copies. Full native replay still requires the existing authorized native application, executable build and operator/config acceptance; credentials/native CLI payloads are not bundled. The current caller repair2 is pending review and not exported as a qualified executable.
