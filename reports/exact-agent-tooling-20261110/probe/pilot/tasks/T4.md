
The Files panel lists folders and files as rows. A file row has small buttons at its right edge that appear while the
pointer is over the row. One of them is "Copy relative path". Some file rows do not have it.

## Required behaviour

A real mouse click on a file row's "Copy relative path" button shows a notification whose text contains
`cmd.file.copy_path -> <path> (relative)`, where `<path>` is that row's own path from the project root, for example
`web/src/routes/+page.svelte`. The notification must name the row that was clicked, not another row.
This must hold for every file row that is shown when the page opens and has the button.
