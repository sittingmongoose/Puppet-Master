## Findings

The two narrow necessary corrections are malformed semantic-marker noncrash (129) and preserving supported parser state across PTY read chunks (130/133, counted once). They follow existing stable parser/grid promises. This does not make every named protocol, fuzzing strategy or parser type necessary.

The optional capabilities add concrete accessibility text/range APIs, byte-loss receipts and pruned-range provenance, terminal-host diagnostics, protocol breadth, and external-agent recognition/continuation behavior. The choices include protocol test coverage, named architectures and confidence tiers, paste/clipboard defaults and trust boundaries, extraction budgets, and terminal import scope exclusions. Vendor reports and P0/P1 labels do not prove necessity.

Two additions occur in the otherwise source-preserving atomization: the seven-tab Orchestrator commitment (body156/012, counted once), and017’s exclusive creation-action policy. The latter conflicts with retained TTY-required and no-terminal dev-session creation routes. The source may have intended preservation and internal dispatch remains unknown; no extra user confirmation or verified runtime breakage is inferred. See [017 adjudication](reviews/adjudication-017.md).

091 remains a contextual restatement of the existing named-action taxonomy: its retained backlog and may-borrow qualifications do not establish twelve new shipping commitments. 036 does not expressly add a prospective branch preview;039 retains picker availability conditions. Cursor-following IME candidates (136) are a product choice because a functional fixed candidate panel is a compliant alternative. See [091 adjudication](reviews/adjudication-091.md) and [cross-review](reviews/cross-review-b-addendum.json).

## Limits and accounting

Classification and clause boundaries are evaluator judgments, not measured probabilities or a count of independent features. Necessary means logically needed by the frozen baseline, not a verified bug in an implementation. Optional does not mean undesirable. Product decisions are historical additions beyond this baseline and are not reopened questions for the current user. The audit does not inspect unseen owner documents, acquire new external evidence, or test a terminal runtime.

D4 was committed, verified and reported before D5 capture. Frozen declared input bytes and manifest references were checked; this is not an OS-level access-control proof. No researcher input, campaign, workflow, current Plan, ledger, index, shard, evidence lock or implementation was changed by this reference construction.

**Cost:** actual root/support/review cost and token usage are unknown and unmetered; zero new research jobs is not zero cost.

**Gate:** semantic cross-review and bounded evidence validation passed. This reference remains evaluator-only; no new research campaign was run.
