## The defect and the port

- **Where:** `scripts/pm-goal-gc-schema-closure.py` `walk()` at `c0482747da`. Lane GO found it (pm-mail `1115152853-9ecb`).
- **Cause:** a reach was keyed by `(location, ipath, (kind, depth, index) per context entry)`. Nothing in the key named the owner node. So a node reached through two different `if`/`then` (or `anyOf`/`oneOf`) at the same instance depth kept only its first reach, including that reach's empty domain, steps and owners.
- **Fix (commit `40f7fe64a7`):** `ctx_key()` keys each context entry as `(kind, depth, index, id(owner))`. This is the same key as GO's copy at `eb10b969cf`, and the code comment names that shared origin.
  - GO's second part, pins scoped to the branches a reach also takes, has no counterpart here. This tool keeps no value pins, so no `union_prefix`, `pinned` or `required_at` code exists to port.
  - The three static classes move into `static_class()` with unchanged logic. UNREACHABLE and SELECTOR_OR_NEGATED entries now also record `reaches`.
- **`--self-test`:** four trials. All pass on the fixed key. Trials 1 and 2 fail on the `c0482747da` key; that was checked with a probe copy, since deleted.
  1. GO's trial: two conditionals at the same depth reach one shared node, so there must be two reaches.
  2. **Negative (GO's standing trial in this tool's terms):** an item clause sits under `then` of D0, where the array has `maxItems: 0`, and under `then` of D1, where the array has no bound. D1 is live: `{"a":{"k2":"q","v":["abc"]}}` is accepted and `["ab"]` is refused. The clause must not classify UNREACHABLE. The old walk kept only the D0 reach and said UNREACHABLE.
  3. Positive control: with D0 only, the clause is UNREACHABLE.
  4. `--reach-audit` reports trial 2's change from UNREACHABLE to a witness-needing clause.
- **Reach audit (commit `a10b3f29c1`):** `--reach-audit` collects each checker's real roots. It then walks every root twice, once with the old key and once with the new key. For each node whose reach list grew, it lists every clause's static class under both walks.
